# Prompt ให้ ChatGPT: คู่มือการเล่นในเกม และย่อหน้าเรื่องรหัสหน้าครู

แผน: [guide-pin-plan.md](guide-pin-plan.md) · ตอนนี้ในเกมเป็นร่างของ Claude (`src/content/data/guide.json`, `draft: true`)

มี 2 ส่วน
1. ข้อความคู่มือการเล่น (JSON ชุดเดียว วางกลับในแชตให้ Claude ใส่เข้าเกม)
2. ย่อหน้าเพิ่มในคู่มือครู เรื่องรหัสเข้าหน้าครู (นำไปใส่ในเอกสารเอง)

## 1. คู่มือการเล่น

ผู้เล่นเป็นเด็กฝึกงานในร้านซ่อมคอม มี "พี่ช่าง" เป็นคนสอน คู่มือนี้เปิดได้จากปุ่ม "❓ วิธีเล่น" ในเกม แบ่งเป็นหัวข้อ กดเปิดทีละหัวข้อ

## 2. ย่อหน้าเพิ่มในคู่มือครู: รหัสเข้าหน้าครู

ใส่ในหัวข้อที่อธิบายหน้าครู (การรวมผลการเรียน) · คัดลอกกล่องไปวางใน ChatGPT แล้วนำย่อหน้าที่ได้ไปใส่ในเอกสารเอง

```
ช่วยเขียนย่อหน้าภาษาไทยแบบทางการ 1 ย่อหน้า (4–6 บรรทัด) สำหรับคู่มือครูของเกมการศึกษา WINSTALL เรื่อง "รหัสเข้าหน้าครู"
เนื้อหาที่ต้องมี
- หน้าครู (ลิงก์ "สำหรับครู" ที่หน้าแรกของเกม) ถามรหัสก่อนเข้า เพราะหน้าครูจำลิงก์ Google Sheet และรหัสครูไว้ในเครื่องที่ใช้ ถ้าใช้คอมในห้องเรียนร่วมกับนักเรียน รหัสนี้กันไม่ให้นักเรียนเปิดดูผลของทั้งห้อง
- ใส่รหัสครั้งเดียวต่อแท็บ ปิดแท็บแล้วต้องใส่ใหม่ และกด "🔒 ล็อกหน้าครู" เพื่อล็อกทันทีเมื่อลุกจากเครื่อง
- ใส่ผิด 5 ครั้งติดกัน ต้องรอ 30 วินาที
- รหัสได้จากผู้ดูแลเกม ห้ามบอกนักเรียน
- ผลการเรียนใน Google Sheet ยังป้องกันด้วย "รหัสครู" ของ Sheet อีกชั้นหนึ่งเหมือนเดิม
```
