## 3.1 จากสไลด์ตัวอย่าง (SimSpace PC Lab, 40 หน้า)

โครงที่ใช้: ปก → ประโยคเปิดปัญหา ("เรียนคอมแต่ประกอบคอมไม่เป็น") → ภาพปัญหา → เชื่อม SDG 4 → ความเป็นมา → ภาพรวม ADDIE → **A** วิเคราะห์สมรรถนะ (หลักสูตรอาชีวะ + มาตรฐานอาชีพ TPQI) และสมรรถนะที่ใช้ → **D** ออกแบบสื่อ (ผังขั้นตอนการเรียนรู้, ออกแบบด่าน) และออกแบบการสอน (MIAP) → **D** เครื่องมือที่ใช้ทำ + เว็บประกอบ + AI ที่ใช้ทำภาพ/วิดีโอ/เสียง → **I** ผู้เชี่ยวชาญประเมินคุณภาพสื่อ + นักเรียนประเมินความพึงพอใจ + คลิปทดลองใช้จริง → **E** ผลประเมิน (เนื้อหา 3 ท่าน x̄ 4.75, เทคนิค 3 ท่าน x̄ 4.5, พึงพอใจ x̄ 4.80 พร้อม S.D. และกราฟ) → ปัญหาและแนวทางแก้ → Q&A

**สิ่งที่ต้องเพิ่มในแผนของเรา (สำคัญ):** ขั้น I และ E ต้องมี**ผลจริง**
- ผู้เชี่ยวชาญ 3 ท่านด้านเนื้อหา + 3 ท่านด้านเทคนิค/สื่อ (เช่น อาจารย์ ครูพี่เลี้ยง) ประเมินด้วยแบบประเมิน 5 ระดับ
- นักเรียน (หรือเพื่อนที่เล่นแทนกลุ่มเป้าหมาย ถ้าหานักเรียนไม่ทัน ต้องบอกตามจริงในสไลด์) ทดลองเล่น + ทำแบบประเมินความพึงพอใจ + อัดคลิป
- Claude ทำแบบประเมินทั้ง 3 ชุด (พร้อมทำเป็น Google Form ได้) และคำนวณ x̄, S.D. ให้จากผลที่เก็บจริง **ไม่แต่งตัวเลข**
- ต้องเก็บผลให้เสร็จภายใน **1 พ.ย.** จึงต้องส่งเกมให้ผู้ประเมินภายใน 30–31 ต.ค.
