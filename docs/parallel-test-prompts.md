คัดลอกทั้งกล่องไปวางใน ChatGPT แล้วนำ JSON ที่ได้มาให้ Claude ใส่ในเกม

```
ช่วยออกแบบทดสอบหลังเรียน "ชุด ข" 10 ข้อ ให้เป็นแบบทดสอบคู่ขนาน (parallel form) กับชุด ก ด้านล่าง
ใช้กับนักเรียน ปวช. วิชา 21910-2001 เรื่องระบบปฏิบัติการและการติดตั้ง Windows 11 (เกม WINSTALL)
ชุด ก ใช้ก่อนเรียน ชุด ข ใช้หลังเรียน แล้วเทียบคะแนนกัน จึงต้องวัดเรื่องเดียวกันและยากใกล้เคียงกัน

กติกา
- ข้อละ 1 ข้อคู่กับชุด ก ทีละข้อ (ข้อ 1 คู่กับข้อ 1 ...) วัดวัตถุประสงค์เดียวกัน ทักษะเดียวกัน ระดับการคิดเดียวกัน
- ห้ามแค่สลับคำหรือสลับตัวเลือกของชุด ก ให้เปลี่ยนสถานการณ์ ตัวอย่าง หรือมุมที่ถาม แต่คำตอบยังมาจากเนื้อหาเดียวกัน
- ข้อละ 4 ตัวเลือก ถูก 1 ข้อ ตัวลวงต้องเป็นความเข้าใจผิดที่นักเรียนเจอจริง ห้ามใช้ "ถูกทุกข้อ" หรือ "ไม่มีข้อใดถูก"
- ตำแหน่งเฉลยกระจาย ไม่ซ้ำตำแหน่งเดิมของคู่ใน ชุด ก ทุกข้อ
- ภาษาไทยง่าย ชัด ศัพท์และชื่อเมนูเขียนภาษาอังกฤษตามจริง (BIOS, UEFI, TPM 2.0, Secure Boot, Partition, Product Key)
- ข้อมูลต้องถูกต้องตามจริง (ข้อกำหนด Windows 11: RAM 4 GB, ดิสก์ 64 GB, UEFI + Secure Boot, TPM 2.0, CPU ที่รองรับ)
- โจทย์ไม่เกิน 120 ตัวอักษร · ตัวเลือกข้อละไม่เกิน 85 · คำอธิบายเฉลยไม่เกิน 200 (บอกว่าทำไมข้อนี้ถูก และตัวลวงหลักผิดตรงไหน)
- id ของชุด ข = id ของคู่ใน ชุด ก ต่อท้าย -b เช่น os-meaning-b
- answer เป็นเลขตำแหน่งตัวเลือกที่ถูก เริ่มที่ 0
- ตอบเป็น JSON อย่างเดียว ตามรูปแบบนี้

ชุด ก (ก่อนเรียน)

1. id: os-meaning · วัตถุประสงค์ข้อ 1
   โจทย์: ข้อใดอธิบายความหมายของ "ระบบปฏิบัติการ (Operating System: OS)" ได้ถูกต้องที่สุด
   ก. โปรแกรมที่ใช้สำหรับพิมพ์งานและสร้างงานนำเสนอ
   ข. ซอฟต์แวร์ระบบที่เป็นตัวกลางเชื่อมโยงระหว่างผู้ใช้ ฮาร์ดแวร์ และซอฟต์แวร์ประยุกต์  ← เฉลย
   ค. อุปกรณ์ฮาร์ดแวร์ที่ทำหน้าที่ประมวลผลข้อมูลหลักของคอมพิวเตอร์
   ง. ระบบเครือข่ายที่ใช้สำหรับเชื่อมต่ออินเทอร์เน็ตทั่วโลก
   คำอธิบาย: ระบบปฏิบัติการเป็นซอฟต์แวร์ระบบที่ควบคุมและประสานงานระหว่างผู้ใช้ โปรแกรม และฮาร์ดแวร์ ส่วนโปรแกรมพิมพ์งานเป็นโปรแกรมประยุกต์ และหน่วยประมวลผลเป็นฮาร์ดแวร์

2. id: os-memory · วัตถุประสงค์ข้อ 1
   โจทย์: หน้าที่ในข้อใดของระบบปฏิบัติการที่จัดสรรและควบคุมการทำงานของหน่วยความจำหลัก (RAM) ไม่ให้โปรแกรมทำงานทับซ้อนกัน
   ก. Processor Management
   ข. Device Management
   ค. Memory Management  ← เฉลย
   ง. File Management
   คำอธิบาย: การจัดการหน่วยความจำ (Memory Management) จัดสรรและควบคุมพื้นที่ RAM ที่แต่ละโปรแกรมใช้ ส่วน Processor ดูแลเวลาของ CPU, Device ดูแลอุปกรณ์ และ File ดูแลไฟล์

3. id: os-no-boot · วัตถุประสงค์ข้อ 1
   โจทย์: หากเครื่องไม่มีระบบปฏิบัติการที่บูตได้ และไม่พบสื่อบูตอื่น โดยทั่วไปอาจเกิดผลอย่างไร
   ก. เปิดเครื่องได้ปกติและใช้งาน Microsoft Word ได้ทันที
   ข. เครื่องจะทำงานเร็วขึ้นเพราะไม่มีซอฟต์แวร์ส่วนเกิน
   ค. แสดงข้อความว่าไม่พบอุปกรณ์บูตที่เหมาะสม เช่น Reboot and Select proper Boot device  ← เฉลย
   ง. หน้าจอจะดับสนิทและไฟไม่เข้าเครื่องคอมพิวเตอร์
   คำอธิบาย: เครื่องยังเปิดได้ แต่เมื่อหาระบบปฏิบัติการที่บูตได้ไม่เจอ จะขึ้นข้อความว่าไม่พบอุปกรณ์บูต (ข้อความต่างกันตามรุ่นเครื่อง) และใช้งานโปรแกรมไม่ได้

4. id: os-server · วัตถุประสงค์ข้อ 2
   โจทย์: ระบบปฏิบัติการในข้อใดจัดเป็นระบบปฏิบัติการสำหรับเครื่องแม่ข่าย ที่ให้บริการเครื่องอื่นผ่านเครือข่าย
   ก. Windows 11 Home
   ข. macOS Sonoma
   ค. Windows Server 2022  ← เฉลย
   ง. Android 14
   คำอธิบาย: Windows Server ใช้กับเครื่องแม่ข่ายที่ให้บริการเครื่องอื่นผ่านเครือข่าย เช่น เก็บไฟล์หรือจัดการบัญชีผู้ใช้ ส่วน Windows 11 และ macOS ใช้กับคอมพิวเตอร์ส่วนบุคคล และ Android ใช้กับอุปกรณ์เคลื่อนที่

5. id: os-mobile · วัตถุประสงค์ข้อ 2
   โจทย์: สมาร์ตโฟนและแท็บเล็ตในปัจจุบันนิยมใช้ระบบปฏิบัติการประเภทใดมากที่สุด
   ก. Embedded OS (ระบบปฏิบัติการแบบฝังตัว)
   ข. Mobile OS (ระบบปฏิบัติการสำหรับอุปกรณ์เคลื่อนที่)  ← เฉลย
   ค. Multi-user OS (ระบบปฏิบัติการสำหรับผู้ใช้หลายคน)
   ง. Real-time OS (ระบบปฏิบัติการแบบทันทีทันใด)
   คำอธิบาย: สมาร์ตโฟนและแท็บเล็ตใช้ระบบปฏิบัติการสำหรับอุปกรณ์เคลื่อนที่ เช่น Android และ iOS ซึ่งออกแบบให้เหมาะกับหน้าจอสัมผัสและการพกพา

6. id: os-open-source · วัตถุประสงค์ข้อ 2
   โจทย์: ข้อใดเป็นระบบปฏิบัติการแบบโอเพนซอร์สที่สามารถศึกษาหรือดัดแปลงซอร์สโค้ดได้ตามเงื่อนไขสัญญาอนุญาต
   ก. Linux  ← เฉลย
   ข. Windows 11
   ค. macOS
   ง. iOS
   คำอธิบาย: Linux เป็นซอฟต์แวร์โอเพนซอร์ส ส่วน Windows, macOS และ iOS เป็นระบบที่มีสัญญาอนุญาตแบบกรรมสิทธิ์

7. id: w11-tpm · วัตถุประสงค์ข้อ 3
   โจทย์: ข้อใดเป็นข้อกำหนดด้านความปลอดภัยขั้นต่ำของ Windows 11
   ก. หน่วยความจำสำรอง (HDD) ต้องมีความจุ 500 GB ขึ้นไป
   ข. เครื่องต้องรองรับ TPM 2.0  ← เฉลย
   ค. หน้าจอต้องรองรับความละเอียดระดับ 4K
   ง. แรมขั้นต่ำต้องมีขนาด 16 GB
   คำอธิบาย: Windows 11 ต้องมี TPM 2.0 และเฟิร์มแวร์ UEFI ที่รองรับ Secure Boot ส่วนพื้นที่ขั้นต่ำคือ 64 GB และ RAM 4 GB จอขั้นต่ำ 720p

8. id: w11-setup-option · วัตถุประสงค์ข้อ 3
   โจทย์: ในหน้า Select setup option ของ Windows 11 Setup หากต้องการติดตั้งใหม่โดยยอมรับว่าข้อมูลจะถูกลบ ควรทำอย่างไร
   ก. เลือก Install Windows 11 และทำเครื่องหมายยอมรับว่าข้อมูล แอป และการตั้งค่าจะถูกลบ  ← เฉลย
   ข. เลือก Repair my PC เพื่อเข้าสู่เครื่องมือซ่อมแซม
   ค. ถอดแฟลชไดรฟ์ออกก่อนเลือกตัวเลือกติดตั้ง
   ง. ปิดเครื่องทันทีโดยไม่เลือกตัวเลือกใด
   คำอธิบาย: การติดตั้งใหม่ต้องเลือก Install Windows 11 แล้วติ๊กยอมรับว่าไฟล์ แอป และการตั้งค่าจะถูกลบ ส่วน Repair my PC ใช้ซ่อมระบบเดิม

9. id: w11-oobe · วัตถุประสงค์ข้อ 3
   โจทย์: หลังติดตั้งไฟล์ระบบ เครื่องเข้าสู่การตั้งค่าเริ่มต้น (OOBE) ข้อใดเป็นตัวอย่างของการตั้งค่าในขั้นตอนนี้
   ก. การเลือกภูมิภาคและคีย์บอร์ด รวมถึงการลงชื่อเข้าใช้บัญชีตามขั้นตอน  ← เฉลย
   ข. การแบ่งพาร์ทิชันฮาร์ดดิสก์และการฟอร์แมตไดรฟ์ C:
   ค. การตั้งค่าความเร็วของสัญญาณนาฬิกาซีพียู (Overclocking)
   ง. การติดตั้งโปรแกรมต้านไวรัสภายนอก (Third-party Antivirus)
   คำอธิบาย: การตั้งค่าเริ่มต้นเลือกประเทศ แป้นพิมพ์ เครือข่าย บัญชี และความเป็นส่วนตัว ส่วนการแบ่งพาร์ทิชันทำก่อนหน้านั้นในหน้าเลือกดิสก์ของ Setup

10. id: w11-before-delete · วัตถุประสงค์ข้อ 3
   โจทย์: ก่อนลบพาร์ทิชันเพื่อเตรียมติดตั้ง Windows 11 ควรทำสิ่งใดเป็นอันดับแรก
   ก. ตรวจสอบดิสก์เป้าหมายและยืนยันการสำรองข้อมูลที่ต้องเก็บกับเจ้าของเครื่อง  ← เฉลย
   ข. ลบพาร์ทิชันทุกดิสก์โดยไม่ตรวจสอบ
   ค. ถอดอุปกรณ์แสดงผลทันที
   ง. ปิดเครื่องระหว่างลบพาร์ทิชัน
   คำอธิบาย: การลบพาร์ทิชันทำให้ข้อมูลหายถาวร จึงต้องตรวจว่าเป็นดิสก์ที่ถูกต้อง และยืนยันกับเจ้าของเครื่องว่าสำรองข้อมูลแล้วก่อนเสมอ
```
