### หน้าเลือกพาร์ทิชัน (ข้อ 7)

ตารางเหมือนจริง เรียงตามที่ Setup แสดง (แฟลชไดรฟ์มักเป็น Disk 0):

| ชื่อ | ขนาดรวม | ชนิด |
|---|---|---|
| Disk 0 Partition 1: ESD-USB | 14.9 GB | Primary |
| Disk 1 Partition 1: System Reserved | 50 MB | System |
| Disk 1 Partition 2 | 465.6 GB | Primary |

- ปุ่ม **Refresh · Load Driver · Delete · Format** และ Next (ปุ่ม New ไม่มีใน Setup แบบใหม่ ⚠️ ต้องเช็ก)
- เลือกพาร์ทิชันของ Disk 1 → **ข้อความแดง** "Windows can't be installed to this disk. The selected disk has an MBR partition table. On EFI systems, Windows can only be installed to GPT disks." · Next กดไม่ได้
- **ทางถูก:** ถามลุงเรื่องสำรองข้อมูล → Delete พาร์ทิชันของ Disk 1 **ทีละอันจนหมด** (มีกล่องยืนยันทุกครั้ง) → เหลือ "Disk 1 Unallocated Space 465.7 GB" → เลือก → Next (Setup ทำดิสก์เป็น GPT เอง)
- **ปุ่มถามลูกค้า** อยู่ในกล่องข้อความด้านข้าง: "ถามลุง: ข้อมูลสำรองไว้แล้วใช่ไหม" → ลุง: "ก๊อปใส่แฟลชไดรฟ์แล้ว ลบได้เลย"

### ทางที่ผิด (กับดัก)

| ผู้เล่นทำ | ผล | นับพลาด |
|---|---|---|
| **ลบ/ฟอร์แมตก่อนถามลุงเรื่องสำรองข้อมูล** | ลุงตกใจ "เดี๋ยวๆ ยังไม่ได้ถามลุงเลยนะ" (ข้อมูลบังเอิญสำรองไว้แล้ว ทำต่อได้) | 1 (ดูข้อ 5) |
| **ลบพาร์ทิชันของแฟลชไดรฟ์ (Disk 0)** | ลบตัวติดตั้งทิ้ง Setup ไปต่อไม่ได้ → ต้องรีสตาร์ต และ**ทำ USB ใหม่ที่โน้ตบุ๊กร้าน** (Rufus จากเคส 2) | 1 (ดูข้อ 5) |
| ลบไม่หมด (เหลือ System Reserved) | Unallocated ยังขึ้นตัวแดง เพราะดิสก์ยังเป็น MBR | 0 (ยังไม่เสียหาย แค่ยังไม่ผ่าน) |
| Format แทน Delete | ตัวแดงยังอยู่ เพราะ Format ไม่เปลี่ยนตารางพาร์ทิชัน | 0 (แต่ถ้ายังไม่ได้ถามเรื่องสำรอง นับข้อแรก) |
| ไม่มีคีย์ แล้วเลือกรุ่นไม่ตรงใบงาน | ติดตั้งได้ แต่บันทึกช่างเตือนว่า Activate อัตโนมัติไม่ได้ | 0 (ดูข้อ 5) |

## 5. ต้องการให้ตัดสินใจ

| เรื่อง | ผมเสนอ | ทางเลือก |
|---|---|---|
| **ลบก่อนถามเรื่องสำรองข้อมูล** | นับพลาด 1 ครั้ง (ตรงวัตถุประสงค์ข้อ 9 ละเอียดรอบคอบ แม้ลุงจะบอกไว้แล้วตอนเข้าร้าน ช่างต้องยืนยันก่อนลบเสมอ) | ไม่นับพลาด แค่บันทึกช่างเตือน |
| **ลบพาร์ทิชันของแฟลชไดรฟ์** | นับพลาด + ต้องทำ USB ใหม่ใน Rufus (ใช้ของจากเคส 2 สอนให้ดูขนาดดิสก์ก่อนลบ) | นับพลาด แต่แค่ขึ้นข้อความผิดพลาดแล้วทำต่อได้เลย |
| **ไม่มีคีย์ เลือกรุ่นผิด** | ไม่นับพลาด บันทึกช่างเตือน (เคสนี้เน้นพาร์ทิชัน) | นับพลาด 1 ครั้ง |
| **ทางแก้อื่น** (diskpart clean + convert gpt / mbr2gpt ผ่าน Shift+F10) | ไม่ทำในขั้นนี้ ใช้ Delete ในหน้า Setup ทางเดียวตามหนังสือ น.55 (ส่วนสอน Shift+F10 เลื่อนไว้ตามที่ตกลงเดิม) | ทำ Shift+F10 ด้วย (ต้นแบบเดิมมี) |
| **เคส 1–2** | จบที่หน้าแรกของ Setup เหมือนเดิม | ให้ไล่ Setup ต่อจนถึง Install ทุกเคส (ยาวขึ้น ~2 นาที) |
| **มินิเกมพาร์ทิชัน** (ไฟล์เคสใส่ไว้) | ทำในขั้นมินิเกมตามแผนเดิม | ทำในขั้นนี้ด้วย |

## 7. ความเสี่ยงที่รู้อยู่

- **ข้อความหน้าจอบางจุดยังไม่ยืนยันคำต่อคำ** (⚠️ ในตารางข้อ 2 และกล่องยืนยันตอน Delete) · จะเพิ่มหัวข้อไว้ใน real-screens.md ถ้าครูถ่ายรูปหน้าเลือกพาร์ทิชันจากเครื่องแล็บได้จะแก้ให้ตรง
- **ตารางพาร์ทิชันบนมือถือแนวตั้ง 360 px**: 3 คอลัมน์ (ชื่อ · ขนาด · ชนิด) อาจแน่น จะย่อคอลัมน์ "Free space" ที่จอจริงมีออกบนจอเล็ก
- **Setup 9 หน้าอาจรู้สึกยาว** สำหรับเคสที่ปัญหาอยู่หน้า 7: หน้า 1–2 กด Next อย่างเดียว ถ้าลองแล้วน่าเบื่อจะให้พี่ช่างพูดสั้นๆ ว่าแต่ละหน้าคืออะไร (ได้วัตถุประสงค์ข้อ 1 เรียงขั้นตอนไปด้วย)
