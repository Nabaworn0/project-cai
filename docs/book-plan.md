# แผน: สมุดช่าง (ระยะ 2 ของรอบ "อยากกลับมาเล่น")

เขียนเมื่อ 1 พ.ย. 2026 · **อนุมัติแล้ว 1 พ.ย. 2026**: 16 ใบ · ไอคอน ChatGPT ทีละใบ · เปิดได้ตั้งแต่ใส่ชื่อ

**ผล (1 พ.ย. 2026, งาน A–D เสร็จ):**
- ต่างจากแผน: สมุดเปิดเป็นหน้าต่างทับหน้าเดิม ไม่ได้แยกเป็นหน้า `#/book` เพราะเปิดระหว่างทำเคสแล้วงานไม่หลุด
- การ์ดในแต่ละหมวดเรียงตามลำดับที่ได้ (เคส 1 ก่อนเคส 2)
- ข้อความและไอคอน 16 ภาพจาก ChatGPT ใส่แล้ว (ภาพต้นฉบับ `art-source/cards/` ย่อเป็น pixel ทีละภาพลง `src/assets/cards/`)
ต่อจากระยะ 1 (ใบประเมินงาน, docs/feedback-plan.md) · ข้อ 4 "คลังความรู้" ในแผน 31 ต.ค.

## ปัญหาตอนนี้
- ถ้าลืมว่า GPT ต่างจาก MBR อย่างไร หรือ TPM คืออะไร ต้องกลับไปดูคลิปทั้งคลิป หรือรอให้เคสสอนอีกรอบ
- ใบประเมินบอก "จำไว้" ได้แค่ประโยคเดียว ยังไม่มีที่ให้อ่านต่อ
- `cards.json` เป็นร่างเก่า (4 ใบ แนวกล่องสุ่ม) ยังไม่ได้ใช้ในเกม

## ผู้เล่นจะเจออะไร
1. **สมุดช่าง** เป็นสมุดสะสมการ์ดความรู้ประมาณ 16 ใบ แบ่ง 4 หมวดตามลำดับที่เรียน
   - การ์ดที่ได้แล้ว: ไอคอน ชื่อ สรุป 1–2 บรรทัด จุดสำคัญ 3–4 ข้อ "เจอในเคส…" และหน้าหนังสือ
   - การ์ดที่ยังไม่ได้: "???" พร้อมบอกวิธีได้ เช่น "ผ่านเคส 2 แล้วได้การ์ดนี้"
   - มีตัวนับ "สะสมแล้ว 9/16" และป้าย "ใหม่!" บนการ์ดที่ยังไม่ได้เปิดอ่าน
2. **ได้การ์ดตามที่เรียน** โดยเกมคิดจากความคืบหน้าที่บันทึกไว้แล้ว ไม่ต้องเก็บข้อมูลใหม่
   - ดูคลิปบทเรียนจบ → การ์ดของบทเรียนนั้น
   - เล่นเกมเรียงขั้นตอนจบ → การ์ด "ลำดับขั้นติดตั้ง"
   - ผ่านเคส → การ์ดของปัญหาในเคสนั้น
3. **เปิดได้ 3 ทาง**
   - ปุ่ม "สมุดช่าง" ในเมนู และบน HUD ในร้าน (มีจุดแดงเมื่อมีการ์ดใหม่)
   - **จากใบประเมิน:** ข้อที่ได้ ✗ มีลิงก์ "อ่านการ์ด: Boot Order" เปิดเป็นหน้าต่างทับร้าน ปิดแล้วกลับมาที่หน้าสรุปเหมือนเดิม
   - หน้าสรุปเคสบอก "ได้การ์ดใหม่ 2 ใบ!" ถ้าเคสนั้นทำให้ได้การ์ด

## ร่างรายการการ์ด (ให้ ChatGPT เขียนเนื้อหา)
| หมวด | การ์ด | ได้จาก |
|---|---|---|
| รู้จักระบบปฏิบัติการ | หน้าที่ของ OS · ประเภทของ OS · OS มีลิขสิทธิ์/ฟรี | คลิป 1, คลิป 2 |
| เตรียมก่อนติดตั้ง | ข้อกำหนด Windows 11 · TPM 2.0 · Secure Boot · สำรองข้อมูลก่อนลง | เคส 4, เคส 3 |
| ทำ USB และบูต | Rufus · GPT กับ MBR · UEFI, Legacy และ CSM · ลำดับบูตและ F10 · Boot Menu | เคส 1, 2, 5 |
| ติดตั้งและตั้งค่า | ลำดับขั้นติดตั้ง · พาร์ทิชันใน Setup · Product Key และรุ่น Windows · ตั้งค่าครั้งแรก (บัญชี/ความเป็นส่วนตัว) | เกมเรียงขั้นตอน, เคส 3, 5 |

ความผิดพลาดแต่ละแบบในใบประเมิน (9 แบบ) จะผูกกับการ์ด 1 ใบ เช่น ลบ USB ติดตั้ง → พาร์ทิชันใน Setup

## งานที่ต้องทำ
| # | งาน | ไฟล์ | ตรวจด้วย |
|---|---|---|---|
| A | schema การ์ดใหม่แทนของเก่า · ผูกการ์ดกับบทเรียน/เคส/ความผิดพลาด · validator ตรวจว่าทุกการ์ดได้แน่ และความผิดพลาดทุกแบบมีการ์ด | `cards.json`, `schema.ts`, `validate.ts`, `src/core/book.ts` | unit |
| B | หน้าสมุดช่าง `#/book` (ตาราง + เปิดอ่าน) + ปุ่มในเมนูและ HUD + ป้ายใหม่ | `src/ui/book/` | Playwright 4 ขนาด |
| C | ลิงก์จากใบประเมิน (หน้าต่างทับร้าน) + "ได้การ์ดใหม่" ในหน้าสรุป | `SummaryCard.tsx`, `CaseFlow.tsx` | Playwright |
| D | ใส่ข้อความและภาพไอคอนจาก ChatGPT | `cards.json`, `src/assets/cards/` | validator + ดูด้วยตา |

ข้อความใช้ร่างของ Claude ไปก่อน (`draft: true`) แล้วแทนด้วยของ ChatGPT ส่วนไอคอนใช้สัญลักษณ์ชั่วคราวจนกว่าจะได้ภาพจริง

## ไม่เปลี่ยน
ดาว เหรียญ ผลที่ส่งให้ครู และลำดับการเรียน (สมุดเป็นแหล่งอ่านเสริม ไม่ล็อกขั้นไหน)
