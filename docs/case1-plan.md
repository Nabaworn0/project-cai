# แผน: ทำเคส 1 (ป้าสมศรี) ให้เล่นได้ทั้งเส้น

รอบ 1 ขั้นที่ 2 · เขียนเมื่อ 24 ต.ค. 2026 · **อนุมัติแล้ว 24 ต.ค. 2026 ตามข้อเสนอทั้ง 4 ข้อในข้อ 6** (จบที่หน้าแรกของ Setup · ไม่จับเวลา · "Press any key" เหมือนจริงแต่ไม่นับพลาด · F8 ได้ดาวเต็ม)
อ้างอิง: [phase1-cases.md](phase1-cases.md) (เคส 1 และลำดับในแต่ละเคส) · [real-screens.md](real-screens.md) (ข้อความหน้าจอ) · `src/content/data/cases/c01-boot-order.json`

เป้าหมาย: นักเรียนเปิดเว็บแล้วเล่นเคส 1 ได้ตั้งแต่ป้าสมศรีเดินเข้าร้านจนเห็นหน้าสรุปดาว **บนคอมและมือถือ โดยไม่ต้องมีใครอธิบาย**
เคสนี้เป็นแม่แบบของเคส 2–5 ทุกชิ้นที่สร้าง (ลำดับเคส คะแนน หน้าจอจำลอง ปุ่มคีย์ลัด) จะใช้ซ้ำในเคสถัดไป

## 1. ผู้เล่นจะเจออะไร (ลำดับการเล่น)

| # | ช่วง | บนจอ | ผู้เล่นทำ |
|---|---|---|---|
| 1 | **ลูกค้าเข้าร้าน** | ป้าสมศรีเดินเข้ามาจากซ้าย ยืนหน้าเคาน์เตอร์ หน้า **worried** · กล่องบทพูดชื่อ "ป้าสมศรี" + บทพูดจากไฟล์เคส | แตะ "ต่อไป" |
| 2 | **ตั๋วเครื่อง** | การ์ดใบงาน: อาการ · BIOS คลาสสิก (AMI) · CPU / RAM / ดิสก์ (สุ่มจาก seed) · ต้องการ **Windows 11** · เก็บข้อมูลไหม: ไม่ต้อง | อ่านแล้วแตะ "รับงาน" |
| 3 | **เดาสาเหตุ** | 4 ตัวเลือกจากไฟล์เคส | เลือก 1 ข้อ · ผิด = เสีย 1 ดาว เห็นคำอธิบาย แต่ซ่อมต่อได้ · ป้าทำหน้า **worried** ต่อ |
| 4 | **ซ่อม** | แตะคอมบนเคาน์เตอร์ → หน้าจอจำลองเปิด (ข้อ 2 ด้านล่าง) | ทำตามขั้นจริงของหนังสือ น.48–51 · มีปุ่ม "คำใบ้" 2 ครั้ง |
| 5 | **ลูกค้าถาม** | ป้าหน้า **happy** (ถ้าบูต USB ได้แล้ว) ถาม "ทำไมเสียบแล้วมันไม่ไปเองล่ะคะ" · 3 ตัวเลือก | เลือก · ผิด = เสีย 1 ดาว เห็นคำอธิบาย |
| 6 | **สรุป** | ดาว 1–3 · เหรียญ · ความพอใจ · **บันทึกช่าง** (สิ่งที่เรียน + "หนังสือ น.48–51") · ป้าทำหน้าตามผล (3 ดาว happy · 2 neutral · 1 angry) แล้วเดินออก | "เล่นอีกครั้ง" (เคส 2–5 ยังไม่มีในขั้นนี้) |

## 2. หน้าจอจำลองในเคสนี้

ข้อความบนจอเป็นภาษาอังกฤษตามของจริง (ตาม real-screens.md) · คำอธิบายภาษาไทยอยู่ในกล่องคำใบ้เท่านั้น

```
เปิดเครื่อง ─► หน้า POST: "Press F2 to enter SETUP, F8 for Boot Menu"
   │
   ├─ ไม่กดอะไร / Enter ──► บูตเข้า Windows เดิม (จอฟ้า "Welcome") ─► ปิดเครื่อง ลองใหม่ (นับพลาด 1)
   │
   ├─ F2 ──► BIOS SETUP UTILITY (AMIBIOS 8 แบบหนังสือ)
   │          แท็บ Main · Advanced · PCIPnP · Boot · Security · Chipset · Exit
   │          Boot ► Boot Device Priority ► 1st Boot Device [HDD]
   │          Boot ► Hard Disk Drives ► 1st Drive ► เลือก USB  (หนังสือ น.49–50)
   │          กลับมา Boot Device Priority เห็น USB เป็นอันดับแรก (รูป 3.17)
   │          ├─ F10 ► "Save configuration changes and exit setup?" [Ok] ─► รีบูต ─► ✅
   │          └─ Esc (จากหน้าแรก) ► "Discard changes and exit setup?" [Ok] ─► เข้า Windows เดิม (กับดัก นับพลาด 1)
   │
   └─ F8 ──► Boot Menu "Please select boot device:"
              ├─ UEFI: USB Flash Drive ─► ✅ (ทางลัดที่ถูก ได้คะแนนเต็ม ตาม designNotes)
              └─ Windows Boot Manager ─► เข้า Windows เดิม (นับพลาด 1)

✅ = "Press any key to boot from CD or DVD...." ─► กดปุ่มใดก็ได้ ─► หน้าแรกของ Setup "Select language settings"
     ─► ผ่านเคส (Setup ทั้งเส้นทำในขั้นถัดไปของรอบ 1)
```

- **ปุ่มคีย์ลัดบนมือถือ** (และใช้กับเมาส์บนคอมได้): แถบล่างจอ `Esc F2 F8 F10 ← ↑ ↓ → Enter +/-` **แสดงครบทุกปุ่มเสมอ** ไม่บอกใบ้ว่าต้องกดอะไร · บนคอมใช้แป้นพิมพ์จริงได้ด้วย
- ค่าที่ตั้งใน BIOS แล้วไม่บันทึก จะหายจริงตอนรีบูต (ตรงกับปัญหา `bios-not-saved` ในหนังสือ น.51)
- ทุกหน้ายังมีป้าย "โหมดจำลอง · ไม่ได้ติดตั้งจริง" เหมือนเดิม

## 3. คะแนน (ตาม [shop-game-brief.md](../shop-game-brief.md) เรื่องดาวและคำใบ้)

| | กติกา |

## 5. ไม่อยู่ในขั้นนี้

Rufus · Setup ทั้งเส้น (หน้าเลือกพาร์ทิชัน) · หน้า "This PC can't run Windows 11" · เคส 2–5 · บทเรียนบท 4–6 · มินิเกม · บันทึกความคืบหน้า/เหรียญข้ามรอบเล่น · เสียง
(ทั้งหมดอยู่ในรายการรอบ 1 ข้อ 3–4 ของ HANDOFF ตามลำดับเดิม)

## 6. ต้องการให้ตัดสินใจ

| เรื่อง | ผมเสนอ | ทางเลือก |
|---|---|---|
| **เคส 1 จบตรงไหน** | จบที่หน้าแรกของ Setup ("บูต USB ได้แล้ว") เพราะปัญหาของเคสนี้คือลำดับบูต · Setup ทั้งเส้นต่อท้ายทุกเคสในขั้นถัดไป | ทำ Setup ทั้งเส้นในขั้นนี้เลย (งานเพิ่มเกือบเท่าตัว) |
| **จับเวลา** (ไฟล์เคสตั้ง 300 วินาที) | เคส 1 **ไม่จับเวลา** ให้เรียนรู้ปุ่ม BIOS ก่อน · เริ่มจับเวลาเคส 2 ขึ้นไป | จับเวลาแต่ไม่หักดาว แค่ลดความพอใจ |
| **"Press any key to boot from CD or DVD"** | ทำเหมือนจริง: ถ้าไม่กดใน 5 วินาที จะเข้า Windows เดิม **แต่ไม่นับว่าพลาด** มีบทพูดบอกให้ลองใหม่ | ข้ามหน้านี้ไปเลยในเคส 1 |
| **ทางลัด F8 Boot Menu** | ได้ 3 ดาวเท่ากัน (ถูกตามหนังสือ น.48 และ designNotes) | ได้ 2 ดาว เพราะเคสนี้อยากให้ฝึก BIOS |

## 7. ความเสี่ยงที่รู้อยู่

- จอมือถือแนวตั้งเตี้ย (เช่น 360×640) อาจมีที่ไม่พอสำหรับหน้าจอจำลอง + แถบปุ่มคีย์ลัด → ทดสอบในข้อ C ถ้าไม่พอจะย่อแถบปุ่มเป็น 2 แถว
- ข้อความ BIOS บางส่วนยังมีเครื่องหมาย ⚠️ ใน real-screens.md (แถบคำอธิบายปุ่ม กล่อง F10) ถ้าครูเห็นว่าต่างจากเครื่องจริง แก้ในไฟล์ `classic.json` ได้โดยไม่ต้องแก้โค้ด
