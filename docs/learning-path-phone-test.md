# เช็กลิสต์ลองเมนูและเส้นทางเรียนบนมือถือจริง

งาน D ของ [learning-path-plan.md](learning-path-plan.md) · เทสต์อัตโนมัติผ่านแล้วทุกขนาดจอ (มือถือจำลอง)
ใช้เวลาประมาณ 10 นาที · ถ้าเปิดแล้วไม่เจอหน้าเมนู: ปิดแท็บเกมแล้วเปิดใหม่ (มือถือเก็บเวอร์ชันเก่าไว้)
คนที่เคยเล่นแล้ว เหรียญเดิมจะย้ายมาให้ แต่ดาวของเคสที่เคยเล่นก่อนหน้านี้ไม่มี (เวอร์ชันเก่าไม่ได้เก็บไว้)

## ลองตามนี้

1. เปิดเกม → เจอหน้า "เส้นทางเด็กฝึกงาน" ฟอร์มชื่อ
2. กด "เริ่มเรียน" ทั้งที่ยังว่าง → ขึ้น "กรอกชื่อ-สกุล" · ใส่เลขที่ 0 → ขึ้น "เลขที่ต้องเป็นตัวเลข 1-99"
3. กรอกครบ → เห็นการ์ด 8 ขั้น (ขั้นที่ยังไม่ได้ทำขึ้น "เร็วๆ นี้") และเคส 1–5 (เคส 2–5 มีกุญแจ)
4. กด "ทำต่อ" → ป้าสมศรีเดินเข้าร้าน
5. กด "☰ เมนู" ตอนป้ายังพูดประโยคแรก → กลับเมนูทันที · กด "ทำต่อ" อีกครั้ง
6. รับเรื่อง แล้วกด "☰ เมนู" → ถาม "กลับไปที่เมนูตอนนี้…" → ลอง "ทำเคสต่อ" แล้วลองอีกครั้งด้วย "กลับเมนู" → ป้าเดินออก
7. เล่นเคส 1 จนจบ → การ์ดสรุปมี "กลับเมนู" กับ "รับลูกค้าคนถัดไป" → กด "กลับเมนู"
8. เคส 1 มีดาว เคส 2 เปิดแล้ว เหรียญขึ้น → ปิดแท็บแล้วเปิดใหม่ ชื่อ ดาว และเหรียญยังอยู่
9. "ผู้เรียนคนใหม่" → ยกเลิก (ยังอยู่) → ทำอีกครั้ง "ล้างและเริ่มใหม่" → กลับไปที่ฟอร์มชื่อ เหรียญเป็น 0
