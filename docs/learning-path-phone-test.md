# เช็กลิสต์ลองเมนูและเส้นทางเรียนบนมือถือจริง

งาน D ของ [learning-path-plan.md](learning-path-plan.md) · เทสต์อัตโนมัติผ่านแล้วทุกขนาดจอ (มือถือจำลอง)
ใช้เวลาประมาณ 10 นาที · ถ้าเปิดแล้วไม่เจอหน้าเมนู: ปิดแท็บเกมแล้วเปิดใหม่ (มือถือเก็บเวอร์ชันเก่าไว้)
คนที่เคยเล่นแล้ว เหรียญเดิมจะย้ายมาให้ แต่ดาวของเคสที่เคยเล่นก่อนหน้านี้ไม่มี (เวอร์ชันเก่าไม่ได้เก็บไว้)

## ลองตามนี้

1. เปิดเกม → เจอหน้า "เส้นทางเด็กฝึกงาน" ฟอร์มชื่อ
2. กด "เริ่มเรียน" ทั้งที่ยังว่าง → ขึ้น "กรอกชื่อ-สกุล" · ใส่เลขที่ 0 → ขึ้น "เลขที่ต้องเป็นตัวเลข 1-99"
3. กรอกครบ → เห็นการ์ด 8 ขั้น (ขั้นที่ยังไม่ได้ทำขึ้น "เร็วๆ นี้") และเคส 1–5 (เคส 2–5 มีกุญแจ)
4. กด "ทำต่อ" → ป้าสมศรีเดินเข้าร้าน
5. กด "☰ เมนู" ตอนป้ายังพูดประโยคแรก → กลับเมนูทันที · กด "ทำต่อ" อีกครั้ง
6. รับเรื่อง แล้วกด "☰ เมนู" → ถาม "กลับไปที่เมนูตอนนี้…" → ลอง "ทำเคสต่อ" แล้วลองอีกครั้งด้วย "กลับเมนู" → ป้าเดินออก
7. เล่นเคส 1 จนจบ → การ์ดสรุปมี "กลับเมนู" กับ "รับลูกค้าคนถัดไป" → กด "กลับเมนู"
8. เคส 1 มีดาว เคส 2 เปิดแล้ว เหรียญขึ้น → ปิดแท็บแล้วเปิดใหม่ ชื่อ ดาว และเหรียญยังอยู่
9. "ผู้เรียนคนใหม่" → ยกเลิก (ยังอยู่) → ทำอีกครั้ง "ล้างและเริ่มใหม่" → กลับไปที่ฟอร์มชื่อ เหรียญเป็น 0

## เพิ่ม 28 ต.ค.: หน้าเรียนแยก + คุยกับพี่ช่าง ([learning-page-plan.md](learning-page-plan.md))

ใช้ "ผู้เรียนคนใหม่" ก่อน เพื่อเริ่มแบบคนที่เพิ่งเข้ามาครั้งแรก

1. เปิดเกม → หน้าร้านจากด้านนอก ป้าย "ร้านซ่อมคอม" กระดานเส้นทางเรียนอยู่ใต้ป้าย (มือถือแนวนอน: กระดานอยู่ด้านขวา)
2. กด "ทำต่อ" → "กำลังไปที่ร้าน…" (ครั้งแรกเท่านั้น) → ในร้าน พี่ช่างลุกจากหน้าต่างห้องซ่อม (ในหน้าต่างเหลือเก้าอี้ว่าง) เดินมาข้างเด็กฝึกงาน
3. คุย 14 ประโยค (ต้อนรับ + เคส 1) คนพูดเปลี่ยนหน้าและกระโดด → "เริ่มงาน" → พี่ช่างเดินกลับไปนั่ง → ป้าสมศรีเดินเข้า
4. ตอนป้าเล่าอาการ กด "ฟังพี่ช่างอีกครั้ง" → พี่ช่างมาคุยเรื่องเคส 1 ป้ายังยืนอยู่
5. กด "☰ เมนู" → หน้าเรียน → "ดูฉากต้อนรับของพี่ช่างอีกครั้ง"
6. จบเคส 1 → "รับลูกค้าคนถัดไป" → พี่ช่างมาคุยเรื่องเคส 2 ก่อนน้องบีมเข้า

## เพิ่ม 29 ต.ค.: แบบทดสอบก่อน/หลังเรียน ([quiz-plan.md](quiz-plan.md))

**เปลี่ยนจากด้านบน:** ตอนนี้ "ทำต่อ" ครั้งแรกพาไปแบบทดสอบก่อนเรียน ร้านกับเคส 1 ล็อกจนกว่าจะทำเสร็จ (ข้อ 3–4 ส่วนแรก และข้อ 2 ส่วน 28 ต.ค. จึงต้องผ่านแบบทดสอบก่อน) · ใช้ "ผู้เรียนคนใหม่" ก่อน

1. กรอกชื่อ → การ์ด "แบบทดสอบก่อนเรียน" ขึ้น "ยังไม่ทำ" · "ฝึกงานที่ร้าน" และเคส 1–5 มีกุญแจ · ปุ่ม "ทำต่อ: แบบทดสอบก่อนเรียน"
2. กด "ทำต่อ" → หน้าเริ่ม (10 ข้อ ทำได้ครั้งเดียว) → "เริ่มทำแบบทดสอบ" → ป้ายเลื่อนขึ้นทับป้ายชื่อร้าน "ข้อ 1 จาก 10"
3. ตอบ 3 ข้อ (ลองกด "ข้อก่อนหน้า" แล้วเปลี่ยนคำตอบ 1 ครั้ง) → กด "☰ เมนู" → การ์ดขึ้น "ทำค้างไว้"
4. ปิดแท็บแล้วเปิดใหม่ → "ทำต่อ" → "ทำค้างไว้ 3 จาก 10 ข้อ" → "ทำต่อ" → อยู่ข้อ 4 · ย้อนดูข้อ 1–3 คำตอบเดิมยังเลือกอยู่
5. ตอบจนครบ → "ตรวจก่อนส่ง" → ลอง "กลับไปทบทวน" แล้วไปถึงข้อสุดท้ายอีกครั้ง → "ส่งคำตอบ"
6. ผลก่อนเรียน: คะแนนอย่างเดียว ไม่มีเฉลย → "ไปเรียนต่อ" → การ์ดขึ้น "ทำแล้ว x/10" กดซ้ำไม่ได้ · ร้านเปิด
7. แบบทดสอบหลังเรียน: เล่นเคส 1–5 ให้ครบ (หรือเปิด `?unlock=all` แล้วกดการ์ดแบบทดสอบหลังเรียน ครูลองได้เร็วกว่า แต่ถ้าเคยทำไว้แล้ว คะแนนจะไม่ถูกบันทึกทับ) → ทำให้จบ → ผลเทียบก่อน → หลัง ตารางแยกวัตถุประสงค์ และเฉลยทุกข้อ
