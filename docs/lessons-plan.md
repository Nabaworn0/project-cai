## คลิปการ์ตูนหน้าตาแบบไหน

2 บท บทละ 2–3 นาที (22 ประโยค) เป็นการ์ตูนพิกเซลสไตล์เดียวกับเกม พี่ช่างสอน เด็กฝึกงานฟังและมีปฏิกิริยา

**ตัวละครขยับ**
- **พี่ช่างพูด:** ปากขยับตามเสียง (ปิด · เปิดเล็ก · เปิดกว้าง) จังหวะปากมาจากเวลาของแต่ละคำที่ได้จากเครื่องสร้างเสียง กะพริบตาเป็นระยะ ตัวขยับขึ้นลงเบาๆ ตอนพูด
- **ท่าทางตามบท:** ยืนปกติ · ชี้ซ้าย · ชี้ขวา · กางมืออธิบาย · ชูนิ้วโป้ง · จับคางคิด · สีหน้า ปกติ ยิ้ม คิด เปลี่ยนตามประโยค
- **เด็กฝึกงาน:** อยู่ในฉากด้วย ทำหน้า ปกติ ยิ้ม ตกใจ คิด ตามบท (ไม่พูด เพราะเป็นตัวผู้เล่น)
- ตัวละครเป็นแบบครึ่งตัวเหมือนในร้าน (ไม่มีขา) จึงไม่เดินเป็นก้าว แต่เลื่อนเข้า-ออกฉากและขยับตัวขึ้นลงแบบเดียวกับตอนพี่ช่างเดินในร้าน

**ฉากและของขยับ**
- พื้นหลังแต่ละฉากเป็นภาพพิกเซลจาก ChatGPT
- ของในฉากเป็นสไปรต์ที่ขยับตามคำพูด: แผนภาพ 3 ชั้น ผู้ใช้ / โปรแกรม / ฮาร์ดแวร์ ซ้อนขึ้นมา มีข้อมูลวิ่งระหว่างชั้น · ไอคอน CPU RAM SSD USB (มีแล้ว) เด้งเข้ามาทีละตัว · มือถือ คอม เซิร์ฟเวอร์ ตู้ ATM เลื่อนเข้ามา
- กล้องซูมเข้าไปที่ของที่กำลังพูดถึง เลื่อนไปตามฉาก เปลี่ยนฉากด้วยการเลื่อนหรือประตูม้วน
- ชื่อและป้ายเป็นตัวหนังสือที่ผมวาดทับ (ไทยคมทุกขนาดจอ) · ไม่ใช้โลโก้จริงของ Windows Android ฯลฯ ใช้ไอคอนทั่วไปกับชื่อแทน (เครื่องหมายการค้า)

**ตัวเล่น**
- ซับไทยขึ้นตรงกับเสียง · ปุ่มเล่น/หยุด · ประโยคก่อนหน้า/ถัดไป · ความเร็ว 1× / 1.25× · ซับเปิด/ปิด · แถบความคืบหน้าแบ่งเป็นฉาก แตะเพื่อกระโดดไปฉากไหนก็ได้
- ปิดเสียงในเกม คลิปยังเดินต่อตามความยาวซับ ปากยังขยับ (ห้องแล็บที่ไม่มีลำโพงก็เรียนได้)
- ออกกลางคลิปแล้วกลับมา เริ่มที่ฉากเดิม
- คำถามทบทวนท้ายคลิปบทละ 2 ข้อ: พี่ช่างอ่านคำถาม คลิปหยุดให้ตอบ ตอบถูกพี่ช่างชูนิ้วโป้ง ตอบผิดพี่ช่างอธิบายแล้วให้ดูฉากนั้นซ้ำหรือไปต่อ · คำตอบครั้งแรกเก็บไว้ให้หน้าผลของครู (ข้อ 7)
- จบบท: ดูถึงฉากสุดท้ายและตอบคำถามครบ การ์ดในหน้าเรียนขึ้น ✓ ดูซ้ำได้ตลอด
- เครื่องที่ตั้งลดการเคลื่อนไหว: ไม่ซูม ไม่เด้ง ตัวละครยังเปลี่ยนท่าและขยับปาก
- หน้าเริ่มคลิปเขียนว่า "เสียงพากย์สร้างด้วย AI (Microsoft Edge TTS) ภาพสร้างด้วย AI (ChatGPT)" และระบุในเอกสารส่งงาน
- ที่อยู่ `#/lesson-os` `#/lesson-types` เปลี่ยนหน้าผ่านประตูม้วน · ใช้ Phaser แบบเดียวกับร้าน (เคลื่อนไหว กล้อง ซ้อนชั้นภาพ)

## สิ่งที่ต้องรู้ก่อน (ข้อจำกัดตามจริง)

- **ChatGPT มักวาดตัวเดิมไม่เหมือนเดิม** ทุกท่าจึงสั่งเป็น "แก้จากภาพ neutral" และผมล็อกส่วนหัวให้เหมือนภาพ neutral ทุกพิกเซลด้วยเครื่องมือเดิม (`--same-rows`) ปากที่ขยับจึงวางทับได้ทุกท่า แต่แขนและมือยังอาจเพี้ยน ท่าไหนดูไม่เนียนต้องขอ ChatGPT วาดใหม่
- **ปากขยับตามจังหวะคำ ไม่ใช่ตามเสียงสระจริง** (3 รูปปาก) แบบการ์ตูนพิกเซลทั่วไป
- **งานใหญ่ราว 2–3 เท่าของแบบแอนิเมชันอธิบาย** เพราะต้องมีระบบท่าทาง ปาก และภาพเพิ่มอีกมาก จึงทำฉากตัวอย่างให้ดูก่อนลงมือทั้งบท (งาน C)

## ตรวจบทแล้ว (30 ต.ค.)

บทของ ChatGPT ใช้ได้ดี ภาษาพูดลื่น คำอังกฤษเขียนเป็นคำอ่านไทยในคำพูด เหมาะกับเสียง AI · ผมเทียบกับข้อสอบก่อน/หลังเรียนข้อของวัตถุประสงค์ 1–2 (`test.json`) แล้วเจอเรื่องที่ควรแก้ก่อนทำเสียง

**ข้อสอบถามแต่บทยังไม่ได้สอน (ควรเพิ่ม)**
1. ข้อสอบใช้คำว่า **Memory Management** · ข้อความบนจอของหน้าที่ทั้ง 5 ข้อควรมีชื่ออังกฤษด้วย: Process Management · Memory Management · Device Management · File Management · User Management & Security (คลิป 1 ฉาก 7 9 10 12 14 20)
2. ข้อสอบถามว่าเครื่องแม่ข่าย **ให้บริการเครื่องอื่นผ่านเครือข่าย** · คลิป 2 ฉาก 11 บอกแค่ว่า "การใช้งานแตกต่างออกไป" ควรบอกว่าเครื่องแม่ข่ายให้บริการอะไร
3. ข้อสอบใช้คำว่า **Mobile OS** · คลิป 2 ฉาก 8 ข้อความบนจอควรมี (Mobile OS)
4. ข้อสอบถามว่าโอเพนซอร์ส **ศึกษาหรือดัดแปลงซอร์สโค้ดได้ตามเงื่อนไขสัญญาอนุญาต** · คลิป 2 ฉาก 15–16 บอกว่า Linux เป็นโอเพนซอร์ส แต่ไม่ได้บอกว่าโอเพนซอร์สคืออะไร

**ถ้อยคำ**
5. คลิป 2 ฉาก 3 นิยามวนกลับ ("ระบบที่ใช้กับคอมพิวเตอร์สำหรับการใช้งานส่วนบุคคล") ควรบอกว่าเป็นเครื่องแบบไหน เช่น คอมตั้งโต๊ะและโน้ตบุ๊กที่ใช้ทำงานทั่วไป
6. คลิป 2 ฉาก 4 ประโยคค้าง ("ที่เราสามารถพบได้")
7. คลิป 1 ฉาก 4 ซ้ำคำ ("เมื่อเราเปิดเครื่อง … จะเริ่มทำงานในขั้นตอนเปิดเครื่อง")
8. คลิป 2 ฉาก 16–17 ข้อความบนจอเหลื่อมกับคำพูด: ฉาก 17 พูดว่า "ไม่ใช่การแบ่งสามประเภท" แต่จอขึ้น "Windows / macOS = Proprietary" ที่ควรอยู่ฉาก 16

**ให้เล่นเป็นการ์ตูนได้**
9. ทุกประโยคต้องบอกท่าและสีหน้า (ท่าพี่ช่าง 6 ท่า · สีหน้าพี่ช่าง 3 แบบ · สีหน้าเด็กฝึกงาน 4 แบบ ตามชุดภาพ)
10. คำถามทบทวนท้ายคลิปยังเป็นคำถามปลายเปิดไม่มีเฉลย ในเกมจะให้ตอบจริง จึงต้องเป็นปรนัย 3 ตัวเลือก มีเฉลย คำชม และคำอธิบายเมื่อผิด (พี่ช่างยังอ่านคำถามออกเสียงเหมือนเดิม)

**ภาพบนจอที่ผมจะทำแบบประยุกต์** (ตัวละครเป็นครึ่งตัว ท่ามีจำกัด): "หยิบแรม" "หยิบอุปกรณ์" = ของเด้งขึ้นมาข้างมือในท่ากางมือ · "กดปุ่มเปิดเครื่อง" "กดบันทึก" = ปุ่มบนจอกระพริบ เด็กฝึกงานหน้าตั้งใจ · "นั่งหน้าเครื่อง" = ยืนหน้าเครื่อง · "พาเดินไปมุมเครื่องแม่ข่าย" = กล้องเลื่อนไปมุมนั้น

## สิ่งที่ต้องติดตั้ง

- `edge-tts` (แพ็กเกจ Python โอเพนซอร์ส) บนเครื่องนี้ ใช้แค่ตอนสร้างไฟล์เสียง ไม่ได้อยู่ในเกม · ตอนสร้างต้องต่ออินเทอร์เน็ต ข้อความถูกส่งไปให้บริการเสียงของ Microsoft แปลงเป็นเสียง
- `edge-tts` ไม่ใช่เครื่องมือทางการของ Microsoft แค่เรียกบริการเสียงเดียวกับเบราว์เซอร์ Edge ใช้ในงานโรงเรียนได้ ถ้าจะเผยแพร่เชิงพาณิชย์ควรเปลี่ยนเป็นบริการที่มีสัญญาใช้งานชัดเจน

**2. แก้บทพูด** (ส่งในแชตเดิมที่ ChatGPT เขียนบทไว้):

```
ช่วยแก้บททั้ง 2 คลิปตามนี้ แล้วส่งตารางใหม่ทั้งหมด ยังคงกติกาเดิม (ภาษาพูด ประโยคสั้น คำอังกฤษในคำพูดเขียนเป็นคำอ่านไทย
```
