| 5 | แล้วระบบปฏิบัติการต่างจากโปรแกรมประยุกต์อย่างไร ลองดูโปรแกรมที่เราใช้ทำรายงานกัน | พี่ช่างเปิดโปรแกรมทำรายงาน | Application Software | ชี้ขวา | ยิ้ม | ปกติ |

| 9 | ข้อที่สอง คือการจัดการหน่วยความจำ ระบบปฏิบัติการดูแลการใช้หน่วยความจำของโปรแกรมที่กำลังทำงาน | พี่ช่างหยิบแรม พร้อมแสดงแถบหน่วยความจำ | 2. Memory Management | ชี้ซ้าย | ปกติ | ปกติ |
| 10 | ข้อที่สาม คือการจัดการอุปกรณ์ ระบบปฏิบัติการติดต่อกับอุปกรณ์ต่าง ๆ ผ่านซอฟต์แวร์ที่เรียกว่าไดรเวอร์ | คอมพิวเตอร์เชื่อมเครื่องพิมพ์ มีไอคอนไดรเวอร์ตรงกลาง | 3. Device Management / Drivers | ชี้ขวา | ปกติ | คิด |
| 11 | ไดรเวอร์ช่วยให้ระบบปฏิบัติการทำงานร่วมกับอุปกรณ์ได้ เช่น ตอนที่เราส่งคำสั่งไปยังเครื่องพิมพ์ | พี่ช่างชี้เส้นทางคำสั่งไปยังเครื่องพิมพ์ | OS → Driver → Printer | ชี้ขวา | ยิ้ม | ปกติ |
| 12 | ข้อที่สี่ คือการจัดการไฟล์ ระบบปฏิบัติการช่วยดูแลการบันทึกและเรียกใช้ไฟล์ต่าง ๆ ในเครื่อง | จอแสดงโฟลเดอร์และไฟล์รายงาน | 4. File Management | ชี้ซ้าย | ปกติ | ปกติ |
| 13 | อย่างเวลาที่เราบันทึกรายงาน หรือเปิดไฟล์รายงานขึ้นมาใช้อีกครั้ง ระบบปฏิบัติการก็มีส่วนช่วยจัดการไฟล์เหล่านี้ | เด็กฝึกงานกดบันทึก แล้วเปิดไฟล์รายงาน | Save / Open Files | ชี้ขวา | ยิ้ม | ยิ้ม |
| 14 | ข้อที่ห้า คือการจัดการบัญชีผู้ใช้และความปลอดภัย ระบบปฏิบัติการดูแลการเข้าใช้งานเครื่อง และการเข้าถึงข้อมูล | หน้าจอเข้าสู่บัญชีผู้ใช้ มีไอคอนกุญแจ | 5. User Management & Security | กางมืออธิบาย | ปกติ | ปกติ |
| 15 | ทีนี้เรามาดูตัวอย่างจริงกัน สมมติว่าเด็กฝึกงานทำรายงานเสร็จแล้ว และต้องการสั่งพิมพ์ออกมา | เด็กฝึกงานเปิดรายงานที่ทำเสร็จบนจอ | Print a Report | ชี้ขวา | ยิ้ม | ปกติ |
| 16 | เมื่อเรากดสั่งพิมพ์จากโปรแกรม คำสั่งจะถูกส่งผ่านระบบปฏิบัติการ แล้วระบบปฏิบัติการจะประสานงานกับเครื่องพิมพ์ผ่านไดรเวอร์ | ลูกศรแสดงเส้นทางจากโปรแกรมไปยังเครื่องพิมพ์ | Application → OS → Driver → Printer | ชี้ขวา | ปกติ | คิด |
| 17 | เมื่อเครื่องพิมพ์รับคำสั่งและทำงานได้ถูกต้อง รายงานก็จะถูกพิมพ์ออกมา นี่คือตัวอย่างการประสานงานของระบบปฏิบัติการ | เครื่องพิมพ์พิมพ์รายงาน เด็กฝึกงานยืนดู | OS Coordinates Printing | ชูนิ้วโป้ง | ยิ้ม | ยิ้ม |

| 19 | ดังนั้น ระบบปฏิบัติการจึงเป็นซอฟต์แวร์ระบบที่สำคัญ เพราะช่วยควบคุมและประสานงานระหว่างผู้ใช้ โปรแกรม และฮาร์ดแวร์ | พี่ช่างแสดงภาพรวม OS ตรงกลาง | OS Coordinates Users, Apps, Hardware | กางมืออธิบาย | ยิ้ม | ปกติ |

| 21 | คำถามทบทวนข้อที่หนึ่ง ระบบปฏิบัติการคืออะไร และแตกต่างจากโปรแกรมประยุกต์อย่างไร | พี่ช่างชี้กระดานคำถาม เด็กฝึกงานยืนคิด | Quiz 1: OS vs. Applications | ชี้ขวา | ยิ้ม | คิด |

### คลิป 1: ระบบปฏิบัติการคืออะไร
วัตถุประสงค์: อธิบายความหมายเกี่ยวกับระบบปฏิบัติการได้

| ฉากที่ | คำพูด (สำหรับเสียง AI) | ภาพบนจอ | ข้อความบนจอ |
|---|---|---|---|
| 1 | ยินดีต้อนรับสู่ร้านซ่อมคอม วันนี้พี่จะพาเรามารู้จักระบบปฏิบัติการ ก่อนเริ่มงานซ่อมเครื่องกัน | พี่ช่างยืนต้อนรับเด็กฝึกงานหน้าโต๊ะซ่อมคอม | ระบบปฏิบัติการคืออะไร? |
| 2 | ระบบปฏิบัติการ หรือโอเอส คือซอฟต์แวร์ระบบ ที่ทำหน้าที่ควบคุมการทำงานของคอมพิวเตอร์ | พี่ช่างชี้ไปที่จอคอมพิวเตอร์ มีไอคอน OS ปรากฏ | OS = ซอฟต์แวร์ระบบ |
| 3 | ระบบปฏิบัติการยังช่วยประสานงานระหว่างผู้ใช้ โปรแกรม และฮาร์ดแวร์ เพื่อให้ทุกส่วนทำงานร่วมกันได้ | จอแสดงตัวละครผู้ใช้ โปรแกรม และอุปกรณ์ เชื่อมกับ OS | ผู้ใช้ ↔ OS ↔ โปรแกรม ↔ ฮาร์ดแวร์ |
| 4 | เมื่อเราเปิดเครื่อง ระบบปฏิบัติการจะเริ่มทำงานในขั้นตอนเปิดเครื่อง จากนั้นเราจึงใช้งานโปรแกรมต่าง ๆ ได้ | เด็กฝึกงานกดปุ่มเปิดเครื่อง จอแสดงการเริ่มระบบ | เปิดเครื่อง → เริ่มระบบปฏิบัติการ |
| 5 | แล้วระบบปฏิบัติการต่างจากโปรแกรมประยุกต์อย่างไร ลองดูโปรแกรมที่เราใช้ทำรายงานกัน | พี่ช่างเปิดโปรแกรมทำรายงานบนคอมพิวเตอร์ | โปรแกรมประยุกต์ |
| 6 | โปรแกรมประยุกต์ใช้ทำงานเฉพาะอย่าง เช่น ทำรายงาน ส่วนระบบปฏิบัติการคอยจัดการเครื่อง และช่วยให้โปรแกรมทำงานกับฮาร์ดแวร์ได้ | จอแบ่งสองฝั่ง แสดง OS และโปรแกรมทำรายงาน | OS ≠ โปรแกรมประยุกต์ |
| 7 | ระบบปฏิบัติการมีหน้าที่สำคัญห้าข้อ ข้อแรก คือการจัดการหน่วยประมวลผล | พี่ช่างชี้ไปที่ชิปซีพียูบนโต๊ะซ่อม | 1. จัดการหน่วยประมวลผล |
| 8 | เมื่อมีหลายโปรแกรมทำงาน ระบบปฏิบัติการจะจัดสรรการใช้หน่วยประมวลผล ให้โปรแกรมเหล่านั้นทำงานได้ | จอแสดงโปรแกรมหลายหน้าต่าง เชื่อมไปยังซีพียู | CPU |
| 9 | ข้อที่สอง คือการจัดการหน่วยความจำ ระบบปฏิบัติการดูแลการใช้หน่วยความจำของโปรแกรมที่กำลังทำงาน | พี่ช่างหยิบแรมขึ้นมา พร้อมแสดงแถบหน่วยความจำบนจอ | 2. จัดการหน่วยความจำ |
| 10 | ข้อที่สาม คือการจัดการอุปกรณ์ ระบบปฏิบัติการติดต่อกับอุปกรณ์ต่าง ๆ ผ่านซอฟต์แวร์ที่เรียกว่าไดรเวอร์ | เครื่องพิมพ์เชื่อมกับคอมพิวเตอร์ มีไอคอนไดรเวอร์ตรงกลาง | 3. จัดการอุปกรณ์ผ่าน Driver |
| 11 | ไดรเวอร์ช่วยให้ระบบปฏิบัติการทำงานร่วมกับอุปกรณ์ได้ เช่น ตอนที่เราส่งคำสั่งไปยังเครื่องพิมพ์ | พี่ช่างชี้เส้นทางคำสั่งจาก OS ผ่านไดรเวอร์ไปยังเครื่องพิมพ์ | OS → Driver → Printer |
| 12 | ข้อที่สี่ คือการจัดการไฟล์ ระบบปฏิบัติการช่วยดูแลการบันทึกและเรียกใช้ไฟล์ต่าง ๆ ในเครื่อง | หน้าจอแสดงโฟลเดอร์และไฟล์รายงาน | 4. จัดการไฟล์ |
| 13 | อย่างเวลาที่เราบันทึกรายงาน หรือเปิดไฟล์รายงานขึ้นมาใช้อีกครั้ง ระบบปฏิบัติการก็มีส่วนช่วยจัดการไฟล์เหล่านี้ | เด็กฝึกงานกดบันทึก แล้วเปิดไฟล์รายงาน | บันทึกและเรียกใช้ไฟล์ |
| 14 | ข้อที่ห้า คือการจัดการบัญชีผู้ใช้และความปลอดภัย ระบบปฏิบัติการดูแลการเข้าใช้งานเครื่อง และการเข้าถึงข้อมูล | หน้าจอเข้าสู่บัญชีผู้ใช้ มีรูปกุญแจ | 5. บัญชีผู้ใช้และความปลอดภัย |
| 15 | ทีนี้เรามาดูตัวอย่างจริงกัน สมมติว่าเด็กฝึกงานทำรายงานเสร็จแล้ว และต้องการสั่งพิมพ์ออกมา | เด็กฝึกงานนั่งหน้าเครื่อง เปิดรายงานที่ทำเสร็จแล้ว | ตัวอย่าง: พิมพ์รายงาน |
| 16 | เมื่อเรากดสั่งพิมพ์จากโปรแกรม คำสั่งจะถูกส่งผ่านระบบปฏิบัติการ แล้วระบบปฏิบัติการจะประสานงานกับเครื่องพิมพ์ผ่านไดรเวอร์ | แสดงลูกศรจากโปรแกรม ไปยัง OS ไดรเวอร์ และเครื่องพิมพ์ | โปรแกรม → OS → Driver → Printer |
| 17 | เมื่อเครื่องพิมพ์รับคำสั่งและทำงานได้ถูกต้อง รายงานก็จะถูกพิมพ์ออกมา นี่คือตัวอย่างการประสานงานของระบบปฏิบัติการ | เครื่องพิมพ์พิมพ์รายงานออกมา เด็กฝึกงานยืนดู | ระบบปฏิบัติการประสานงาน |
| 18 | แต่ถ้าเครื่องไม่มีระบบปฏิบัติการที่บูตได้ เครื่องอาจไม่เข้าสู่หน้าจอใช้งาน และแจ้งว่าหาอุปกรณ์บูตไม่เจอ | จอคอมพิวเตอร์สีดำ แสดงข้อความแจ้งข้อผิดพลาด | Reboot and Select proper Boot device |
| 19 | ดังนั้น ระบบปฏิบัติการจึงเป็นซอฟต์แวร์ระบบที่สำคัญ เพราะช่วยควบคุมและประสานงานระหว่างผู้ใช้ โปรแกรม และฮาร์ดแวร์ | พี่ช่างยืนข้างคอมพิวเตอร์ แสดงภาพรวม OS ตรงกลาง | OS ควบคุมและประสานงาน |

### prompt ที่ใช้ (สรุป)

คลิป 1: OS เป็นซอฟต์แวร์ระบบ ควบคุมและประสานงานผู้ใช้ โปรแกรม ฮาร์ดแวร์ · เริ่มทำงานเมื่อเปิดเครื่อง · ต่างจากโปรแกรมประยุกต์ · หน้าที่ 5 ข้อ (หน่วยประมวลผล หน่วยความจำ อุปกรณ์ผ่านไดรเวอร์ ไฟล์ บัญชีผู้ใช้และความปลอดภัย) · ตัวอย่างสั่งพิมพ์ · ไม่มี OS ที่บูตได้ขึ้น "Reboot and Select proper Boot device"
คลิป 2: 3 ประเภทตามการใช้งาน (คอมพิวเตอร์ส่วนบุคคล อุปกรณ์เคลื่อนที่ เครื่องแม่ข่าย) · Linux โอเพนซอร์ส Windows/macOS กรรมสิทธิ์ · ดูจากระบบที่ติดตั้งและการใช้งาน ไม่ใช่รูปร่าง · ใช้คำว่า "เครื่องแม่ข่าย" ไม่ใช้ "Network OS"
รูปแบบ: ฉากละ 1–2 ประโยค · คำพูดเขียนอังกฤษเป็นคำอ่านไทย (วินโดวส์) ข้อความบนจอเป็นอังกฤษ (Windows) · ปิดท้ายด้วยคำถามทบทวน 2 ข้อ ไม่เฉลย · ห้ามเพิ่มเนื้อหานอกจากที่ให้
