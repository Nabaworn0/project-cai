# แผน: หน้าจอติดตั้ง Windows 11 ให้เหมือนของจริงที่สุด

เขียนเมื่อ 25 ต.ค. 2026 · **อนุมัติแล้ว 25 ต.ค. 2026 ตามข้อเสนอในข้อ 4 ทุกข้อ** · ผู้ใช้ขอ: "สร้างหน้าจอคอมการลง Windows ของจริง ให้เหมือนของจริงที่สุด"
ใช้กับ: เคส 3 (Setup ทั้งเส้น), เคส 4 (หน้า "can't run"), เคส 2 (กับดัก CSM), เคส 5 และคลิปสอนตอนท้าย
ภาพอ้างอิงที่ดูมาเก็บไว้นอกโปรเจกต์ ใช้ดูเทียบเท่านั้น ไม่ใส่ในเกม

---

## 1. ของจริงต่างจากที่เกมทำไว้ตรงไหน

| เรื่อง | เกมตอนนี้ | ของจริง (Windows 11 Setup 24H2) |
|---|---|---|
| พื้นหลังทั้งจอ | ไล่สีน้ำเงิน-ม่วง | **ดำล้วน** |
| หน้าต่าง | การ์ดขาวมุมมน มีเงา | **หน้าต่างแบบ Windows รุ่นเก่า**: ขอบฟ้าอ่อนหนา แถบชื่อ "Windows 11 Setup" มีไอคอนตัวติดตั้ง และปุ่ม ย่อ / ขยาย / ปิด (ปุ่มปิดสีแดง) · กว้างราว 70% ของจอ |
| หัวข้อ | ดำ ตัวหนา | **ฟ้า ตัวบาง ใหญ่** (Segoe UI Light) |
| ช่องเลือก | ป้ายอยู่บน ช่องอยู่ล่าง | **ป้ายซ้าย ช่องขวา** (ดรอปดาวน์แบบ Windows) |
| ท้ายหน้าต่าง | มีแค่ Back / Next | **ซ้าย:** โลโก้ Microsoft (สี่เหลี่ยม 4 สี) · Support · Legal · **ขวา:** Back / Next (Next เป็นสีเทาเมื่อกดไม่ได้) |
| Select setup option | มีแค่ตัวเลือก | ข้อความอธิบาย "Install the latest version of Windows 11, or repair your PC. If you're installing Windows 11, please note your files, apps, and settings will be deleted." · ป้าย **"I would like to"** · ลิงก์ **"Previous Version of Setup"** |
| Product key | ช่องเดียว | "The product key should be with the box the DVD came in or on your email receipt." · "It looks similar to this: XXXXX-XXXXX-XXXXX-XXXXX-XXXXX" · ป้าย "Enter Product key" · ช่องแบบมีเส้นใต้ ข้อความจาง "Dashes will be added automatically" · ลิงก์ "I don't have a product key" และ "Privacy statement" |
| Select Image | ปุ่มเลือก | หัวข้อ **"Select Image"** · "Please select the image you want to install." · **กล่องรายการ** หัวรายการ "Operating System:" มีแถบเลื่อน · รายการ: Home, Home N, Home Single Language, Education, Education N, Pro, … · ชื่อที่เลือกขึ้นใต้กล่อง |
| เลือกพาร์ทิชัน | 4 ปุ่มข้อความ | **7 เครื่องมือมีไอคอน** 2 แถว: Refresh · Load Driver · Bring Disk Online / Delete Partition · Format Partition · Create Partition · Extend Partition (อันที่ใช้ไม่ได้เป็นสีเทา) · ตารางกรอบเดียว หัวคอลัมน์ Name · Total Size · Free Space · Type · แถวที่เลือกเป็น**แถบน้ำเงินตัวขาว** · พื้นที่ว่างชนิด "Unallocated Space" · **ไม่มีปุ่ม Back** มีแค่ Next |
| Ready to install | รายการธรรมดา | "You won't be able to use your PC during installation. Save and close your files before you begin." · "To recap, you've chosen to:" · ✓ Install Windows 11 Home · ✓ Keep nothing · หมายเหตุเรื่องข้อกำหนด + ลิงก์ "Check device specifications" · Back / **Install** |

## 2. ที่ยังไม่เจอภาพของจริง (ทำตามรูปแบบเดียวกัน แล้วติด ⚠️ ไว้)

- หน้า **Applicable notices and license terms** (ชื่อหน้ายืนยันแล้ว หน้าตายังไม่เห็น)
- หน้า **กำลังติดตั้ง** (แถบความคืบหน้า)
- **ตัวแดงเรื่อง MBR** ในหน้าเลือกพาร์ทิชัน: อยู่ตรงไหนของหน้าต่าง
- **กล่องยืนยัน** ตอนกด Delete / Format
- หน้า **"This PC can't run Windows 11"** (ข้อความยืนยันแล้ว หน้าตาจะใช้กรอบเดียวกัน)
- ถ้าครูถ่ายรูปจากเครื่องแล็บได้ระหว่างลงจริง จะแก้ให้ตรงทุกจุด

## 3. งานที่ต้องทำ

| # | งาน | ไฟล์ | ตรวจด้วย |
|---|---|---|---|
| A | **กรอบหน้าต่าง Setup** ใช้ร่วมทุกหน้า: พื้นดำ หน้าต่างขอบฟ้า แถบชื่อ + ไอคอน + 3 ปุ่ม · หัวข้อฟ้าตัวบาง · ท้ายหน้าต่าง (โลโก้ Microsoft · Support · Legal · Back/Next) | `SetupScreen.tsx`, `sim.css` | ภาพเทียบของจริงทีละหน้า |
| B | **เนื้อหาแต่ละหน้า** ตามตารางข้อ 1 (ข้อความ วางตำแหน่ง ดรอปดาวน์ กล่องรายการรุ่น ช่องคีย์แบบเส้นใต้) · หน้า "can't run" ใช้กรอบเดียวกัน | `SetupScreen.tsx`, `screens.tsx`, `setup.ts` (รายชื่อรุ่น) | unit test + ภาพ |
| C | **หน้าเลือกพาร์ทิชัน** แบบจริง: 7 เครื่องมือพร้อมไอคอนวาดเอง · ตารางแถบน้ำเงิน · ไม่มี Back · คอลัมน์ Type ของพื้นที่ว่าง = "Unallocated Space" | `SetupScreen.tsx`, `sim.css` | ภาพ + เทสต์เดิมของเคส 3 |
| D | **บนมือถือ** (ข้อ 4) | `sim.css` | ภาพ 4 ขนาดจอ · ปุ่มกดได้ |
| E | **ตรวจทั้งหมด**: เทสต์เคส 2–4 ที่อ้างถึงข้อความเดิม (เช่น ปุ่ม "✕ Delete" → "Delete Partition") · ภาพเทียบของจริงเคียงกันทุกหน้า · `npm run check` | tests | `npm run check` + ดูภาพเอง |

| F | **หน้าตั้งค่าเริ่มต้นหลังติดตั้ง (OOBE)** (เพิ่ม 25 ต.ค. 2026 ผู้ใช้อยากให้มี เหมือนวิดีโอสอนลง Windows 11 ช่วงหลังติดตั้ง): ประเทศ · คีย์บอร์ด · เน็ต · ชื่อเครื่อง · บัญชี / PIN · ความเป็นส่วนตัว · เดสก์ท็อป · **ตกลง 25 ต.ค. 2026:** อยู่ใน**เคส 5** (ลงจนถึงเดสก์ท็อปทั้งเส้น) และ**เคส 6 เริ่มที่เดสก์ท็อป** (ไม่ทำซ้ำ) · เคส 3–4 จบเหมือนเดิม · หน้าลงชื่อบัญชี Microsoft: **ช่างยื่นเครื่องให้ลูกค้าลงชื่อเอง** ถ้าช่างกรอกแทนหรือขอรหัสผ่านลูกค้า เสียคะแนน (ความเป็นส่วนตัว · วัตถุประสงค์ข้อ 10) | ยังไม่เริ่ม | — |

| G | **ลูกค้าซื้อคีย์แท้จากร้าน** (เสนอโดยผู้ใช้ 25 ต.ค. 2026 · ยังไม่ได้ออกแบบ): ลูกค้าไม่มีคีย์แต่อยากได้ของแท้ → ช่างแนะนำรุ่นให้ตรงการใช้งาน (Home / Pro) → ขายคีย์ (เหรียญในเกม ไม่อ้างราคาจริง) → ใส่คีย์ในหน้า Product key หรือ Activate ทีหลังใน Settings · สอนเรื่องคีย์แท้กับคีย์ราคาถูกผิดกฎหมาย ผูกกับวัตถุประสงค์ข้อ 10 (ซื่อสัตย์) · **ตกลง 25 ต.ค. 2026:** เป็น**ปัญหาในคลังของระบบลูกค้าสุ่ม** (เช่น ลูกค้าซื้อเครื่องมือสองที่ไม่มีลิขสิทธิ์) ทำพร้อมแผนลูกค้าสุ่ม | ยังไม่เริ่ม | — |

ไม่เปลี่ยน: ตรรกะของ Setup และกฎการให้คะแนน (เคส 3–4 เล่นเหมือนเดิม เปลี่ยนแค่หน้าตาและข้อความ) · หน้าจอ BIOS (ตามหนังสือ) · Rufus (เหมือนจริงอยู่แล้ว)

## 4. ต้องการให้ตัดสินใจ

| เรื่อง | ผมเสนอ | ทางเลือก |
|---|---|---|
| **บนมือถือแนวตั้ง** (หน้าต่างจริงกว้าง ถ้าย่อทั้งหน้าต่าง ปุ่มจะเล็กราว 15 px กดยาก) | หน้าตาเหมือนจริง (สี กรอบ ฟอนต์ ข้อความ ไอคอน) แต่**จัดวางใหม่ให้พอดีจอแคบ**: ป้ายขึ้นบนช่อง เครื่องมือพาร์ทิชันเรียง 2 คอลัมน์ ตารางซ่อนคอลัมน์ Free Space ปุ่มสูงอย่างน้อย 32 px · จอคอมและมือถือแนวนอนวางเหมือนจริงทุกพิกเซล | ย่อหน้าต่างจริงทั้งบาน (เหมือนจริงที่สุด แต่กดยากบนมือถือ) |
| **โลโก้และชื่อ Microsoft** | ใส่ตามจริง (ครูอนุมัติการใช้ชื่อ/หน้าจอ Microsoft แล้วเมื่อ 24 ต.ค.) · วาดด้วยโค้ด ไม่ใช้ไฟล์ภาพของไมโครซอฟต์ | ใส่แค่คำว่า Microsoft ไม่มีโลโก้ |
| **หน้าจอโลโก้ Windows + วงหมุน** หลังกดปุ่มใดก็ได้ (ของจริงขึ้นราว 2–3 วินาทีก่อน Setup) | ใส่ 1.5 วินาที ให้รู้สึกเหมือนเครื่องกำลังโหลด | ไม่ใส่ (เข้า Setup ทันที) |
| **ลำดับงาน** | ทำแผนนี้ก่อน แล้วค่อยกลับไปทำเคส 4 งาน C–E ต่อ (หน้าตาใหม่จะได้ใช้ในเคส 4 เลย) | ทำเคส 4 ให้จบก่อน |
