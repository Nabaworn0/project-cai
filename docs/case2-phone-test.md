## ลองทุกทาง

- [ ] **ทางที่ถูก:** โน้ตบุ๊กร้าน → SELECT → `Win11_24H2_Thai_x64.iso` → Partition scheme = GPT → START → OK → OK → รอแถบเขียว → "ไปที่เครื่องลูกค้า" → F8 → UEFI: USB → กดปุ่มใดก็ได้
- [ ] **กับดัก MBR ซ้ำ:** ทำ USB ใหม่แต่ไม่เปลี่ยนเป็น GPT → F8 ยังไม่เห็น USB
- [ ] **กับดักไฟล์ผิด:** เลือก Windows 10 หรือ Ubuntu → บูตได้แต่ขึ้นหน้าผิด น้องบีมทัก
- [ ] **กับดัก CSM:** เข้า BIOS → Boot → Boot Settings Configuration → CSM Support = Enabled → F10 → ขึ้น "This PC can't run Windows 11"
- [ ] **ติ๊กยกเลิกตรวจ TPM** ในกล่อง Customize → ลงได้ ไม่เสียดาว แต่หน้าสรุปมีบันทึกช่างเตือน
