# คู่มือสไตล์ภาพ ร้านซ่อมคอม (Pixel Art 16-bit)

ตัดสินใจเมื่อ 23 ต.ค. 2026: เปลี่ยนจากการ์ตูนแบนเป็น **พิกเซลอาร์ต 16-bit** (แบบเกมยุค SNES)
ใช้คู่มือนี้คุมภาพทุกชิ้นให้เป็นสไตล์เดียวกัน พรอมต์สำเร็จรูปอยู่ใน [art-prompts.md](art-prompts.md)

## 1. อะไรเป็นพิกเซล อะไรไม่ใช่

| ส่วน | สไตล์ | เหตุผล |
|---|---|---|
| ฉากร้าน ตัวละคร อะไหล่ การ์ด มินิเกม | **พิกเซล 16-bit** | ตัวเกม |
| กรอบ UI (ป้าย ปุ่ม กล่องข้อความ) | ขอบพิกเซล มุมตัด เงาแข็ง | ให้เข้ากับฉาก |
| ตัวหนังสือไทยทั้งหมด | ฟอนต์ปกติ (Chakra Petch / Noto Sans Thai) | ฟอนต์ไทยแบบพิกเซลอ่านยากบนมือถือ |
| หน้าจอจำลอง (Windows Setup, BIOS, Device Manager) | **เหมือนของจริง** ไม่ใช่พิกเซล | นักเรียนต้องจำหน้าจอจริงได้ |

## 2. ขนาดพิกเซล

- เกมวาดบนผืนเล็กประมาณ **210 พิกเซลด้านสั้น** (มือถือแนวตั้ง ~216×480, คอม ~320×200) แล้วขยายเป็นจำนวนเต็มเท่า ทุกพิกเซลจึงเป็นสี่เหลี่ยมคม
- **ห้ามย่อหรือขยายภาพพิกเซลแบบไม่เต็มเท่า** ห้ามหมุน ห้ามใช้ภาพสองขนาดพิกเซลปนกัน
- ขนาดมาตรฐาน:

| ชิ้น | ขนาด (พิกเซลอาร์ต) |
|---|---|
| ตัวละคร (ครึ่งตัว หลังเคาน์เตอร์) | 32×50 (ช่าง ย่อจาก 40×63 เมื่อ 24 ต.ค. ผู้ใช้เลือกจาก 54/52/50) |
| ลูกค้า (เต็มตัว ยืนหน้าเคาน์เตอร์) | สูง 77–84 (ป้าสมศรี 34×77, คนอื่น 82–84) |
| ไอคอนอะไหล่ | ~16–20 ด้านยาว |
| ภาพในการ์ดสะสม | 48×48 |
| ของประกอบฉาก | จอ 40×34, หน้าต่าง 72×61, ชั้นวาง 71×80 |

**ทุกตัวละครต้องหัวกว้างราว 30–34 พิกเซล** (ช่างกับลูกค้ายืนข้างกัน ถ้าหัวไม่เท่ากันจะดูแปลก) ภาพใหม่ให้แนบ somsri-neutral.png เป็นตัวอย่างขนาด แล้วย่อด้วยอัตราเดียวกับป้าสมศรี (19.5 พิกเซลต้นฉบับ = 1 พิกเซลอาร์ต)

## 3. กฎการวาด

- ใช้เฉพาะ **ชุดสี 32 สี** ด้านล่าง (ไฟล์ [palette.hex](palette.hex) นำเข้า Aseprite / Piskel / Lospec ได้)
- เส้นขอบ 1 พิกเซล สี navy `#1b2a4a` รอบตัวละครและของชิ้นหลัก
- แสงมาจาก **ซ้ายบน** เงาใช้สีเฉดเข้มของสีนั้นในชุดสี (เช่น teal → teal shade)
- ไม่มี anti-aliasing ไม่มี gradient ไม่มี dithering หนาแน่น (ใช้ได้นิดหน่อยในพื้นหลัง)
- หน้าตัวละครใหญ่ อ่านอารมณ์ได้จากตาและปาก 2–3 พิกเซล
- **ห้ามมี**: โลโก้หรือเครื่องหมายการค้าจริง ตัวหนังสือในภาพ ลายน้ำ

## 5. ตัวละครหลัก: ช่าง (ผู้เล่น)

- เสื้อโปโล teal คอครีม ป้ายชื่อเหลืองที่อกขวา ผมสั้นสีเข้ม หูฟังพร้อมไมค์ navy ปลายไมค์ coral
- ครึ่งตัว หันหน้าตรง (ช่วงล่างถูกเคาน์เตอร์บัง)
- **สีหน้าที่ต้องมี (ชื่อไฟล์ต้องตรง)**: `neutral` ปกติ · `happy` ดีใจ · `thinking` กำลังคิด · `surprised` ตกใจ
- ทุกสีหน้าต้องตำแหน่ง ขนาด กรอบเท่ากันทุกพิกเซล เปลี่ยนแค่หน้า

ถ้าสีหน้าไหนยังไม่มีไฟล์ เกมจะใช้หน้า neutral แทนไปก่อน (ไม่สลับไปใช้ภาพคนละแบบ) และเทสต์จะไม่ยอมถ้าเฟรมในชุดเดียวกันขนาดไม่เท่ากัน
ภาพชั่วคราวที่วาดด้วยโค้ดอยู่ใน `src/game/art/technician.ts` (32×39) เปิดเกมแล้วแตะตัวช่างเพื่อดูทุกสีหน้า

## 6. ลูกค้า

- สไตล์และชุดสีเดียวกัน แยกกันด้วยทรงผม สีเสื้อ อายุ
- สีหน้า: `neutral` · `worried` กังวล · `happy` พอใจ · `angry` ไม่พอใจ
- ลูกค้าคนแรก: ป้าสมศรี (ผมสั้นดัดสีเทา แว่นตา เสื้อสีม่วงลายดอก)

## 7. จากภาพ ChatGPT สู่ตัวเกม

ภาพ "พิกเซลอาร์ต" จาก ChatGPT มักไม่ใช่พิกเซลจริง (ขนาดพิกเซลไม่เท่ากัน ขอบเบลอ สีเพี้ยน พื้นหลังสีขาว)
สคริปต์ `npm run pixelize` แก้ให้:

1. ลบพื้นหลัง (ใช้ความโปร่งใสถ้ามี ถ้าไม่มีจะลบสีพื้นจากขอบเข้ามา สีขาวในตัวภาพ เช่น ตา จะไม่ถูกลบ)
2. หาว่ากี่พิกเซลของภาพเป็น 1 พิกเซลอาร์ต แล้วเสนอความสูงที่เหมาะสม
3. ย่อลงตารางพิกเซลจริง แต่ละช่องเลือกสีที่พบมากที่สุด แล้วบังคับเป็นสีในชุดสี 32 สี
4. ภาพชุดเดียวกัน (เช่น `tech-*.png`) ใช้กรอบตัดเดียวกัน สีหน้าจึงไม่ขยับ
5. ได้ PNG ขนาดจริงใน `src/assets/sprites/` และภาพขยาย 8 เท่าไว้ตรวจใน `art-source/preview/`

```
npm run pixelize -- "art-source/tech-*.png" --height 50 --same-rows 0-12,32- --same-cols 0-3,27-
```

- `--same-rows` / `--same-cols` คัดลอกแถว/คอลัมน์ที่กำหนดจากภาพ neutral ไปใส่ภาพสีหน้าอื่น
  ใช้กับส่วนที่ไม่ควรเปลี่ยน (ผม หูฟัง ตัว) เพราะ ChatGPT มักวาดส่วนนั้นต่างกันเล็กน้อยทุกภาพ ทำให้เวลาสลับสีหน้าแล้วเสื้อหรือผมกระพริบ
  ตัวเลขข้างบนใช้กับช่างขนาด 32×50 (หน้าอยู่แถว 13–31 คอลัมน์ 4–26) ตัวละครอื่นต้องหาตำแหน่งหน้าใหม่
- ไอคอนแผ่นรวม: `npm run pixelize -- art-source/icons-sheet.png --grid 4x2 --names ram,ssd,usb,screwdriver,cpu,motherboard,tpm,magnifier`

ถ้าสคริปต์เตือนว่า "close call" มาก แปลว่าความสูงที่เดาไม่ตรง ให้ใส่เองด้วย `--height 40`

## 8. ข้อควรระวัง

- ตรวจเงื่อนไขการใช้ภาพที่สร้างด้วย AI ของ OpenAI ก่อนเผยแพร่ในโรงเรียน
- เก็บภาพต้นฉบับจาก ChatGPT ไว้ใน `art-source/` (ไม่เข้าไปในตัวเกม) เพื่อแก้หรือสร้างเพิ่มภายหลัง
