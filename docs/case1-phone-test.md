# เช็กลิสต์ลองเคส 1 บนมือถือจริง

งาน G ของ [case1-plan.md](case1-plan.md) · เทสต์อัตโนมัติผ่านแล้วทุกขนาดจอ (มือถือจำลอง) แต่ยังไม่เคยลองบนเครื่องจริง
ใช้เวลาประมาณ 10–15 นาที ถ้าได้ลองกับนักเรียน 1–2 คนจะดีที่สุด (ดูว่าเขาติดตรงไหนโดยไม่บอกใบ้)

## เปิดเกมบนมือถือ

**วิธี A (ยังไม่ต้อง push):** คอมกับมือถือต้องต่อ Wi-Fi เดียวกัน

```
npm run build
npm run preview -- --host
```

เปิดลิงก์ `Network: http://192.168.x.x:4173` ที่ขึ้นมา ในเบราว์เซอร์ของมือถือ (ถ้าเปิดไม่ได้ ให้อนุญาต Node.js ผ่าน Windows Firewall)

**วิธี B:** push ขึ้น GitHub แล้วเปิด https://nabaworn0.github.io/project-cai/ (รอ Actions ราว 2 นาที)

## ลองทั้ง 3 เส้นทาง

- [ ] **ตามหนังสือ:** F2 → Boot → Hard Disk Drives → 1st Drive = USB → F10 → Ok → กดปุ่มใดก็ได้ → หน้า Setup
- [ ] **ทางลัด:** F8 → UEFI: USB → กดปุ่มใดก็ได้
- [ ] **กับดัก:** ไม่กดอะไรตอนจอดำ / ออก BIOS ด้วย Esc → ป้าพูดว่าขึ้นหน้าเดิม · ลองพลาด 2 ครั้งแล้วดูว่าเสียดาว

## ดูทีละข้อ (จด ✓ หรือปัญหาที่เจอ)

| | เรื่อง | ✓ / ปัญหา |
|---|---|---|
| 1 | แนวตั้ง: เห็นหน้าป้ากับช่างตลอด ไม่ถูกกล่องข้อความบัง | |
| 2 | แนวนอน: กล่องข้อความอยู่ขวา จอคอมอ่านตัวหนังสือ BIOS ได้ | |
| 3 | ปุ่มบนจอ (F2, ลูกศร, Enter) กดง่าย ไม่กดพลาดปุ่มข้างๆ ตอบสนองทันที | |
| 4 | **8 วินาทีตอนจอดำ พอให้กด F2/F8 ทันไหม** (ถ้าไม่พอ ปรับได้ที่ `SCREEN_TIMEOUT_MS`) | |
| 5 | ตัวหนังสือไทยคมชัด ขนาดอ่านสบาย | |
| 6 | หมุนจอกลางเคส แล้วทุกอย่างยังอยู่ที่เดิม | |
| 7 | กดปุ่ม Back ของมือถือ / ปัดกลับ: เกิดอะไรขึ้น (ยังไม่ได้จัดการเรื่องนี้) | |
| 8 | เล่นจบ 1 เคสใช้เวลากี่นาที (แผนตั้งไว้ 3–5 นาที) | |
| 9 | นักเรียนเข้าใจเองไหมว่าต้องกด F2/F8 ตอนจอดำ (ยังไม่มีบทเรียนก่อนเล่น) | |
| 10 | สนุกไหม อยากเล่นเคสต่อไปไหม | |
