## ลองทุกทาง

- [ ] **ทางที่ถูก:** ถามเรื่องสำรองข้อมูล → เปิดเครื่อง → รอ POST → กดปุ่มใดก็ได้ → Next, Next → ติ๊ก I agree → Next → ใส่คีย์ (แตะช่อง) หรือ I don't have a product key + เลือก Windows 11 Home → Next → Accept → Delete Disk 1 Partition 2 → Delete Disk 1 Partition 1 → เลือก Unallocated Space → Next → Install
- [ ] **กับดักลบก่อนถาม:** ยังไม่กดถามเรื่องสำรองข้อมูล แล้ว Delete พาร์ทิชันของ Disk 1 → ลุงทัก นับพลาด 1 ครั้ง
- [ ] **กับดักลบ USB:** Delete "Disk 0 Partition 1: ESD-USB" → Setup ขึ้นข้อผิดพลาด → ปุ่มโน้ตบุ๊กร้านโผล่ → ทำ USB ใหม่ใน Rufus (Windows 11, GPT) → กลับเครื่องลุง → ติดตั้งต่อ
- [ ] **ลองผิดที่ไม่นับพลาด:** Format แทน Delete (ตัวแดงยังอยู่) · ลบแค่ Partition 2 (ตัวแดงยังอยู่) · Decline ใน License (กลับหน้าแรก)
