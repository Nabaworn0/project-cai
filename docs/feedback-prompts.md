# Prompt ให้ ChatGPT: ข้อความในใบประเมินงาน (feedback.json)

คัดลอกทั้งกล่องไปวางใน ChatGPT แล้วนำ JSON ที่ได้มาให้ Claude ใส่ในเกม

```
ช่วยเขียนข้อความภาษาไทยสำหรับ "ใบประเมินงานของพี่ช่าง" ในเกมสอนติดตั้ง Windows 11 สำหรับนักเรียน ปวช. (วิชา 21910-2001)
ผู้เล่นเป็นเด็กฝึกงานในร้านซ่อมคอม มี "พี่ช่าง" เป็นคนสอน ใบประเมินขึ้นหลังจบงานซ่อมแต่ละเคส

กติกา
- ภาษาเป็นกันเอง แบบพี่สอนน้อง สุภาพ ไม่ดุ ไม่ใช้คำหยาบหรือศัพท์วัยรุ่นเกินไป
- ชื่อปุ่ม เมนู และแป้นให้เขียนตามจริงเป็นภาษาอังกฤษ เช่น F10, Boot Menu, Secure Boot, TPM, GPT, Rufus
- ห้ามเกินจำนวนตัวอักษรที่กำหนด (นับรวมช่องว่าง)
- ตอบเป็น JSON อย่างเดียว ตามโครงด้านล่าง ห้ามเปลี่ยนชื่อ key

1) criteria: ชื่อเกณฑ์ 3 ข้อ แต่ละข้อมี title (ไม่เกิน 20 ตัวอักษร) ok (ข้อความเมื่อผ่าน ไม่เกิน 40) miss (ข้อความเมื่อไม่ผ่าน ไม่เกิน 40)
   - diagnose = เดาสาเหตุก่อนลงมือซ่อม
   - repair = ลงมือซ่อมบนหน้าจอจำลอง
   - explain = อธิบายให้ลูกค้าเข้าใจ
2) freeSlip: ข้อความเมื่อพลาดแค่ 1 ครั้ง ซึ่งยังไม่เสียดาว (ไม่เกิน 45)
3) slips: การพลาดแต่ละแบบ มี th (เกิดอะไรขึ้น สั้นๆ ไม่เกิน 45) และ tip (ประโยค "จำไว้" ว่าครั้งหน้าต้องทำอย่างไร ไม่เกิน 110)
   - booted-old-windows = เครื่องบูตเข้า Windows ตัวเดิม เพราะ USB ไม่ได้อยู่ลำดับแรก หรือแก้ BIOS แล้วไม่ได้กด F10 บันทึก (ใช้ Boot Menu เลือก USB ครั้งเดียวก็ได้)
   - no-boot-device = เครื่องหาอุปกรณ์บูตไม่เจอ เพราะเอาฮาร์ดดิสก์ออกจากลำดับบูต หรือ USB บูตแบบนั้นไม่ได้
   - wrong-image = USB ไม่ใช่ตัวติดตั้ง Windows 11 (เป็น Windows 10 หรือ Ubuntu) ต้องเลือกไฟล์ ISO ให้ถูกใน Rufus
   - legacy-boot = บูตแบบ Legacy (เปิด CSM) ซึ่ง Windows 11 ไม่รองรับ ต้องปิด CSM ใช้ UEFI และ USB แบบ GPT
   - still-cant-run = ขึ้น "This PC can't run Windows 11" ด้วยเหตุผลเดิม ยังไม่ได้เปิด TPM หรือ Secure Boot หรือแก้แล้วไม่ได้บันทึก
   - no-backup-check = ลบพาร์ทิชันของลูกค้าก่อนถามเรื่องสำรองข้อมูล
   - deleted-installer = ลบพาร์ทิชันของแฟลชไดรฟ์ติดตั้งเอง ต้องไปทำ USB ใหม่ (ดูขนาดและชื่อไดรฟ์ก่อนลบ)
   - typed-for-customer = ช่างพิมพ์บัญชี Microsoft แทนลูกค้า (บัญชีเป็นของลูกค้า ต้องยื่นเครื่องให้ลูกค้าพิมพ์เอง)
   - asked-password = ช่างขอรหัสผ่านลูกค้า (ช่างไม่ควรรู้รหัสผ่านของลูกค้า)
4) bonus: เหรียญเสริม มี noHints (ไม่ใช้คำใบ้เลย ไม่เกิน 30) oneHint (ใช้คำใบ้ 1 ครั้ง ไม่เกิน 30) privacy (ถามลูกค้าเรื่องตั้งค่าความเป็นส่วนตัว ไม่เกิน 35)
5) retry: ข้อความบนปุ่มลองเคสเดิมอีกรอบ (ไม่เกิน 22)
6) retryFocus: ประโยคที่พี่ช่างพูดตอนเริ่มรอบใหม่ ต้องมีคำว่า {items} ตรงที่เกมจะใส่รายการเรื่องที่ต้องระวัง (ไม่เกิน 70 ไม่รวม {items})
7) focusLabels: ชื่อสั้นของเรื่องที่ต้องระวัง สำหรับใส่ใน {items}: diagnose และ explain (ไม่เกิน 25 ต่อข้อ) · ส่วนลงมือซ่อมใช้ title ของ criteria.repair

โครง JSON:
{
  "criteria": {
    "diagnose": { "title": "", "ok": "", "miss": "" },
    "repair": { "title": "", "ok": "", "miss": "" },
    "explain": { "title": "", "ok": "", "miss": "" }
  },
  "freeSlip": "",
  "slips": {
    "booted-old-windows": { "th": "", "tip": "" },
    "no-boot-device": { "th": "", "tip": "" },
    "wrong-image": { "th": "", "tip": "" },
    "legacy-boot": { "th": "", "tip": "" },
    "still-cant-run": { "th": "", "tip": "" },
    "no-backup-check": { "th": "", "tip": "" },
    "deleted-installer": { "th": "", "tip": "" },
    "typed-for-customer": { "th": "", "tip": "" },
    "asked-password": { "th": "", "tip": "" }
  },
  "bonus": { "noHints": "", "oneHint": "", "privacy": "" },
  "retry": "",
  "retryFocus": "",
  "focusLabels": { "diagnose": "", "explain": "" }
}
```
