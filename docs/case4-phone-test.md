# เช็กลิสต์ลองเคส 4 (พี่ต้น · ลง Windows 11 ไม่ผ่าน) บนมือถือจริง

งาน E ของ [case4-plan.md](case4-plan.md) · เทสต์อัตโนมัติผ่านแล้วทุกขนาดจอ (มือถือจำลอง) แต่ยังไม่เคยลองบนเครื่องจริง
ใช้เวลาประมาณ 10 นาที · ถ้าได้ลองกับนักเรียนจะดีที่สุด (ดูว่าเขารู้ไหมว่าข้อไหนดูจากใบงานได้ ข้อไหนต้องดูใน BIOS)

## เปิดเกม

- **เข้าเคส 4 ตรงๆ:** https://nabaworn0.github.io/project-cai/?case=c04-security-chip
  - ปิดแค่ TPM: เพิ่ม `&seed=s1` · ปิดทั้ง TPM และ Secure Boot: เพิ่ม `&seed=s3` (ไม่ใส่ seed = สุ่ม)
- **หรือเล่นตามลำดับ:** ป้าสมศรี → น้องบีม → ลุงชัย → พี่ต้น

## ลองทุกทาง

- [ ] **ตารางเทียบข้อกำหนด:** CPU / RAM / ดิสก์ = ผ่าน · Secure Boot / TPM = ต้องดูใน BIOS · ลองตอบผิดสักข้อ ดูคำอธิบาย
- [ ] **ทางที่ถูก:** เปิดเครื่อง → รอ POST → กดปุ่มใดก็ได้ → หน้า "This PC can't run Windows 11" → รีสตาร์ตเครื่อง → F2 → Advanced → Trusted Computing → Security Device Support = Enabled → (ถ้าสุ่มได้: Security → Secure Boot → Enabled) → F10 → Ok → บูตใหม่ → เข้า Setup = ซ่อมสำเร็จ
- [ ] **กับดัก Esc:** เปิด TPM แล้วออกด้วย Esc (ไม่บันทึก) → หน้าเดิมด้วยเหตุผลเดิม พี่ต้นทัก นับพลาด
- [ ] **กับดัก CSM:** Boot → Boot Settings Configuration → CSM Support = Enabled → F10 → เครื่องเข้า Windows 10 เดิม นับพลาด
