# เช็กลิสต์ลองหน้าสะท้อนผลบนมือถือจริง

งาน C ของ [reflect-plan.md](reflect-plan.md) · เทสต์อัตโนมัติผ่านแล้วทุกขนาดจอ (มือถือจำลอง)
ใช้เวลาประมาณ 10 นาที · ถ้าเปิดแล้วไม่เจอการ์ด: ปิดแท็บเกมแล้วเปิดใหม่ (มือถือเก็บเวอร์ชันเก่าไว้)
**ส่งได้ครั้งเดียว** ถ้าจะลองหลายรอบ ให้ใช้ลิงก์ครูด้านล่าง หรือกด "ผู้เรียนคนใหม่" ในเมนูเพื่อล้างแล้วเริ่มใหม่

## เปิดเกม

- **ปกติ:** https://nabaworn0.github.io/project-cai/ (การ์ด "สะท้อนผลและประเมินความพึงพอใจ" เปิดหลังทำแบบทดสอบหลังเรียน)
- **ครูสาธิต เปิดทุกขั้น:** https://nabaworn0.github.io/project-cai/?unlock=all (ครูทำซ้ำได้ ไม่ทับของที่ผู้เรียนส่งไว้)

## ลองตามนี้

1. เข้าการ์ด → พี่ช่างพูดเปิด "พี่อยากรู้ว่าเราได้เรียนรู้อะไรบ้าง…"
2. ให้ดาวข้อแรก 4 ดาว → ดาวติด 4 ดวง ใต้ดาวขึ้น "ทำได้เกือบทั้งหมด"
3. กด "ตรวจและส่ง" ทั้งที่ยังไม่ครบ → ขึ้น "ยังไม่ได้ตอบ … ข้อ" ข้อที่เหลือมีกรอบแดง หน้าเลื่อนไปข้อแรกที่เหลือ
4. ตอบไปบางข้อ แล้วกด "☰ เมนู" → เข้าใหม่ คำตอบยังอยู่ครบ
5. พิมพ์ช่องเขียนตอบสั้นๆ แค่ 2–3 ตัวอักษร แล้วกดส่ง → ขึ้น "เขียนอย่างน้อย 5 ตัวอักษร"
6. ตอบครบ → กดส่ง → ถาม "ส่งแล้วจะกลับมาแก้ไม่ได้" → "กลับไปทบทวน" แล้วลองส่งอีกครั้ง → "ส่งคำตอบ"
7. พี่ช่างยิ้มขอบคุณ → "กลับเส้นทางเรียน" → การ์ดเป็นเสร็จแล้ว กดเข้าอีกไม่ได้
