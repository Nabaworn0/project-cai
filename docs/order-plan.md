# แผนข้อ 4: เรียงขั้นตอนการติดตั้ง Windows 11 · อนุมัติ 29 ต.ค. 2026 (ทุกข้อตามที่เสนอ)

เป้าหมาย: วัตถุประสงค์ข้อ 3 "อธิบายขั้นตอนการติดตั้ง Windows 11 ได้" ฝึกลำดับก่อนเข้าร้าน (เส้นทางเรียนขั้นที่ 4) ให้เห็นภาพรวมทั้งงานก่อนลงมือทีละหน้าจอในเคส
รูปแบบ (ผู้ใช้เลือก 29 ต.ค.): **ผสม** · ช่วงเรียนเป็นการเรียงแบบสีบอกใบ้ (แนวเกมทายคำรายวัน) · ด่านบอสเป็นสายพานงานซ่อม (แนวอาร์เคดจับของ) · กติกาของเราเอง ไม่ลอกเกมใดเกมหนึ่ง
เวลาประมาณ 1.5 วัน · เล่นบนป้ายประกาศของหน้าเรียน ไม่ต้องโหลดร้าน

## ช่วงที่ 1: จัดลำดับ (สีบอกใบ้) · 2 รอบ

- **รอบ 1 ภาพรวมทั้งงาน (8 ขั้น)** ตามใบเนื้อหา: ตรวจสเปกเครื่อง → สำรองข้อมูล → สร้าง USB ติดตั้งด้วย Rufus (GPT + UEFI) → ตั้ง BIOS ให้บูตจาก USB → ติดตั้งผ่าน Windows Setup → รีสตาร์ตและรอติดตั้งไฟล์ → ตั้งค่าเริ่มต้น (OOBE) → อัปเดตและติดตั้งไดรเวอร์
- **รอบ 2 ในหน้า Windows Setup (7 ขั้น)** ตรงกับหน้าจอในเคส: ภาษาและแป้นพิมพ์ → Select setup option (Install Windows 11) → Product key → เลือกรุ่น (Select image) → ยอมรับข้อตกลงใบอนุญาต → เลือกตำแหน่งติดตั้ง (ดิสก์/พาร์ทิชัน) → Install
- แตะการ์ดเพื่อวางลงช่องถัดไป แตะการ์ดที่วางแล้วเพื่อเอาออก (ไม่ลากวาง: จอเล็กลากพลาดง่าย และใช้คีย์บอร์ดได้)
- วางครบ กด **"ตรวจลำดับ"** แต่ละช่องขึ้นสี: 🟩 ถูกตำแหน่ง · 🟨 ห่างไป 1 ช่อง · ⬜ ห่างกว่านั้น · การ์ดอยู่ที่เดิมให้สลับต่อเอง
- ทายได้ **5 ครั้งต่อรอบ** ด้านบนมีตารางสีของแต่ละครั้ง (แคปจอเทียบกับเพื่อนได้) · ครั้งที่ 3 เป็นต้นไป พี่ช่างให้คำใบ้ขั้นแรกที่ยังผิด (รูปหน้าพี่ช่าง + กล่องข้อความ)
- ถูกครบ หรือครบ 5 ครั้ง → พี่ช่างเฉลยทั้งลำดับพร้อมเหตุผลสั้นๆ ทีละขั้น → รอบถัดไป

## ช่วงที่ 2: บอส "สายพานงานซ่อม"

- ใช้ลำดับเต็ม **14 ขั้น** (ภาพรวม 8 ขั้นที่ขั้น "ติดตั้งผ่าน Windows Setup" แตกเป็น 7 ขั้นของรอบ 2)
- การ์ดไหลบนสายพานในร้านทีละหลายใบ: ขั้นที่ต้องทำต่อไป ปนกับขั้นที่ยังไม่ถึง และ **การ์ดกับดัก** ที่ไม่ควรทำ (เช่น "ถอด USB ระหว่างติดตั้ง", "ลบพาร์ทิชันก่อนสำรองข้อมูล")
- แตะขั้นที่ต้องทำต่อไปก่อนมันไหลตกขอบ · แตะผิดหรือปล่อยขั้นที่ถูกตก เสียหัวใจ 1 ดวง (มี 3 ดวง) พี่ช่างบอกเหตุผลสั้นๆ · ต่อถูกติดกันได้คอมโบ · สายพานเร็วขึ้นทีละนิด
- **โหมดช้า** (สวิตช์บนหน้าจอ) สำหรับคนที่ไม่ถนัดเกมเร็ว · ถ้าเครื่องตั้งให้ลดการเคลื่อนไหว เริ่มที่โหมดช้า
- หัวใจหมด → เริ่มบอสใหม่ได้ทันที (ไม่ต้องทำช่วงที่ 1 ซ้ำ)

## ผลและเส้นทางเรียน

- ดาว: ⭐ จบบอส · ⭐ ทั้ง 2 รอบของช่วงที่ 1 ถูกภายใน 3 ครั้ง · ⭐ จบบอสโดยเสียหัวใจไม่เกิน 1 ดวง · ไม่มีเหรียญ (เหรียญเป็นของร้าน)
- จบแล้วการ์ดในเส้นทางขึ้น "ทำแล้ว ★★" → ร้านเปิด (บทเรียน 1–2 ยังเป็น "เร็วๆ นี้" จึงไม่ล็อก) · เล่นซ้ำได้เพื่อทบทวน เก็บดาวที่ดีที่สุด
- บันทึกจำนวนครั้งที่ทายของรอบแรกที่เล่น และหัวใจที่เสียในบอส ไว้ให้หน้าสรุปผลครู (ข้อ 7)

## เนื้อหาและภาพ

- ข้อความการ์ด คำใบ้ เหตุผล และการ์ดกับดัก อยู่ใน `src/content/data/order.json` ตรวจด้วย schema (รหัสไม่ซ้ำ ทุกขั้นมีคำใบ้และเหตุผล ขั้น Setup ในรอบ 1 มีอยู่จริง) และแสดงในหน้าดูเนื้อหา (`?view=content`)
- **ข้อความ:** ChatGPT เขียนคำใบ้ เหตุผล และการ์ดกับดัก (ภาษาพี่ช่าง สั้น 1 บรรทัด) ผมเตรียม prompt ให้ ระหว่างรอใส่ร่างจากใบเนื้อหาไว้ก่อน
- **ภาพ:** ChatGPT เจนสายพานในร้าน (แถบสายพานต่อกันได้ + ฉากหลังมุมโต๊ะช่าง) แล้ว `npm run pixelize` · ระหว่างรอใช้สายพานวาดด้วย CSS ไปก่อน · การ์ดเป็น HTML (ตัวหนังสือไทยคมชัด)
