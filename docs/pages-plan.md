## 1. ทุกหน้ามีที่อยู่ของตัวเอง

| หน้า | ที่อยู่ |
|---|---|
| เส้นทางเรียน (ฟอร์มชื่อครั้งแรก) | `#/learn` |

- `?case=` และ `?view=content` ทำงานเหมือนเดิม

## 2. ประตูม้วนร้าน (เปลี่ยนหน้า)

- กดไปหน้าอื่น → ประตูเหล็กม้วนลายพิกเซลเลื่อนลงปิดจอ (~0.3 วินาที) · บนประตูมีป้าย "กำลังไปที่ <ชื่อหน้า>…" กับเฟืองพิกเซลหมุน → เปลี่ยนหน้าหลังประตู → ม้วนขึ้นเปิดหน้าใหม่ (~0.35 วินาที)
- ไปร้านครั้งแรก (ต้องโหลดฉากร้าน): ประตูค้างไว้จนร้านพร้อม แทนจอ "กำลังไปที่ร้าน…" เดิม
- เครื่องที่ตั้งลดการเคลื่อนไหว: จางเข้า-จางออกแทน · กดซ้ำระหว่างประตูเคลื่อน ไม่ซ้อนกัน
- ประตูวาดด้วย CSS ลายพิกเซลสีเดียวกับเกม (ไม่ต้องรอภาพ)

## 3. ฉากของแต่ละหน้า

| หน้า | ฉาก |
|---|---|
| เส้นทางเรียน | หน้าร้าน (ภาพเดิม) |
| เรียงขั้นตอน | **ห้องสายพาน** (ภาพจาก ChatGPT ที่ได้แล้ว) เต็มหน้า · ด่านบอสใช้ภาพนี้แทนสายพาน CSS: ลายสายพานที่เลื่อนวางทับผิวสายพานในภาพพอดี การ์ดออกจากช่องที่ผนังตามภาพ |
| แบบทดสอบก่อน/หลังเรียน | **มุมโต๊ะในห้องหลังร้าน** (ChatGPT วาดเพิ่ม 1 ภาพ prompt ด้านล่าง) · ระหว่างรอใช้หน้าร้าน |
| ร้าน | ฉากในร้าน (Phaser เดิม) |

- ภาพทุกภาพผ่าน `npm run pixelize -- --keep-bg --out src/assets/scenes` ให้อยู่ในชุดสี 32 สีเดียวกัน และมีภาพแนวตั้ง/แนวนอนตามจอ (ภาพเดียวตัดกลางได้ถ้ามุมสำคัญอยู่ตรงกลาง)
