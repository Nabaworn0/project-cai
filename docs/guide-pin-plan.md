# คู่มือการเล่นในเกม และรหัสเข้าหน้าครู

อนุมัติ 1 พ.ย. 2026 (ผู้ใช้: "Yes, start") · เว็บหลักย้ายไป https://project-cai.vercel.app (Vercel build เองทุกครั้งที่ push `main`)

## งาน G: รหัสเข้าหน้าครู (`?view=teacher`)

ทำไม: หน้าครูเก็บลิงก์ Sheet และรหัสครูไว้ในเครื่องที่ใช้ ถ้าครูเปิดบนคอมในห้องเรียน นักเรียนที่เปิดหน้าครูบนเครื่องเดียวกันจะดึงผลทั้งห้องได้ทันที

- เปิดหน้าครูแล้วเจอช่องใส่รหัสก่อน ใส่ถูกจึงโหลดหน้าครู (โค้ดหน้าครูโหลดหลังใส่รหัสถูก)
- จำว่าปลดล็อกแล้วเฉพาะแท็บนั้น (`sessionStorage`) ปิดแท็บแล้วต้องใส่ใหม่ · ในหน้าครูมีปุ่ม "🔒 ล็อกหน้าครู" ล็อกทันที
- ผิด 5 ครั้งติด ต้องรอ 30 วินาที
- รหัสไม่อยู่ในโค้ด เก็บเฉพาะค่าแฮช PBKDF2-SHA256 (200,000 รอบ + salt) ใน `src/teacher/pin.json` · ตั้งหรือเปลี่ยนรหัสด้วย `npm run teacher-pin` (พิมพ์รหัสในเครื่องตัวเอง ไม่ต้องบอกใคร) แล้ว commit + push
- ยังไม่ตั้งรหัส: หน้าครูเปิดได้เหมือนเดิม แต่ขึ้นแถบเตือนให้ตั้งรหัส
- ข้อจำกัด (บอกตรง ๆ ในคู่มือครู): เว็บเป็นไฟล์นิ่ง คนที่แกะโค้ดในเบราว์เซอร์ได้ข้ามได้ รหัสนี้กันนักเรียนทั่วไป ส่วนผลของนักเรียนใน Sheet ยังป้องกันด้วยรหัสครูที่ Google ตรวจเองเหมือนเดิม
- เทสต์: build ของ Playwright ใช้รหัสทดสอบ (`VITE_TEACHER_PIN_TEST`) build จริงไม่มีค่านี้ ใช้ `pin.json`

## งาน H: คู่มือการเล่นในเกม

- หน้าต่างแบบสมุดช่าง เปิดจากปุ่ม "❓ วิธีเล่น" ที่หน้าแรก เมนูเส้นทางเรียน และเมนูเล่นอิสระ ปิดแล้วกลับที่เดิม (Esc ปิดได้)
- หัวข้อพับ/กางได้ทีละหัวข้อ: เริ่มเล่น · เส้นทางเรียน · งานหนึ่งชิ้นในร้าน · ปุ่มบนจอ · ดาว เหรียญ ความพอใจ · สมุดช่าง · เล่นอิสระ · ปัญหาที่พบบ่อย
- ชื่อขั้นในเส้นทางเรียนดึงจากเกม (`STEP_INFO`) ข้อความอื่นอยู่ใน `src/content/data/guide.json` (ร่างของ Claude `draft: true` → ChatGPT เขียนใหม่ผ่าน prompt ใน `docs/guide-prompts.md`)
- validator: id ไม่ซ้ำ · ทุกหัวข้อมีอย่างน้อย 1 ข้อ · ข้อละไม่เกิน 140 ตัวอักษร · เตือนถ้ายังเป็นร่าง
- ไม่ใช้ภาพใหม่ ใช้อีโมจิและไอคอนที่มีในเกม
