# ตั้ง Google Sheet รับผลของนักเรียน (สำหรับครู)

ทำครั้งเดียว ราว 10 นาที ในบัญชี Google ของครูเอง ผลของนักเรียนทุกห้องจะเข้ามาใน Sheet นี้ แล้วครูดูสรุปทั้งห้องได้ที่หน้าครูของเกม

> ร่างนี้เขียนให้ตรงกับโค้ด (`apps-script/Code.gs`) · ภาษาจะให้ ChatGPT ขัดเกลาเป็นคู่มือครูฉบับเต็ม · ชื่อเมนูภาษาไทยของ Google อาจต่างเล็กน้อย จึงใส่ชื่อภาษาอังกฤษไว้ในวงเล็บ

## สิ่งที่ต้องมี

- บัญชี Google (Gmail หรือบัญชีของโรงเรียน) · คอมพิวเตอร์ที่มีเบราว์เซอร์ (ตั้งค่าบนมือถือไม่สะดวก)
- โค้ด Apps Script: ที่หน้าครูของเกม https://nabaworn0.github.io/project-cai/?view=teacher มีปุ่ม **คัดลอกโค้ด Apps Script** และ **ดาวน์โหลดโค้ด (Code.gs)** (โค้ดเดียวกับ [`apps-script/Code.gs`](../apps-script/Code.gs))
- รหัสครูที่จะตั้งเอง: ยาวอย่างน้อย 8 ตัว ไม่ซ้ำกับรหัสผ่านอื่นของครู · นักเรียนไม่ต้องรู้รหัสนี้

## ขั้นที่ 1 สร้าง Sheet

1. เปิด https://sheets.new (สร้าง Google Sheet ใหม่)
2. ตั้งชื่อไฟล์ที่มุมซ้ายบน เช่น `ผลเกมร้านซ่อมคอม 2569`
3. ไม่ต้องสร้างแท็บหรือหัวตารางเอง แท็บของแต่ละห้องจะเกิดเองเมื่อนักเรียนห้องนั้นส่งผลครั้งแรก

## ขั้นที่ 2 วางโค้ด

1. เมนู **ส่วนขยาย (Extensions) → Apps Script** จะเปิดแท็บใหม่
2. ตั้งชื่อโปรเจ็กต์ที่มุมซ้ายบน เช่น `รับผลเกมร้านซ่อมคอม`
3. เปิดหน้าครูของเกมอีกแท็บ กด **คัดลอกโค้ด Apps Script**
4. กลับมาที่ไฟล์ `Code.gs` ลบโค้ดเดิม (`function myFunction() {}`) ให้หมด แล้ววาง (Ctrl+V)
5. กด **บันทึก** (รูปแผ่นดิสก์ หรือ Ctrl+S)

## ขั้นที่ 3 ตั้งรหัสครู

1. แถบซ้าย กดรูปเฟือง **การตั้งค่าโปรเจ็กต์ (Project Settings)**
2. เลื่อนลงไปที่ **พร็อพเพอร์ตี้ของสคริปต์ (Script Properties)** → **เพิ่มพร็อพเพอร์ตี้ของสคริปต์ (Add script property)**
3. ช่อง Property พิมพ์ `TEACHER_KEY` (ตัวพิมพ์ใหญ่ทั้งหมด) · ช่อง Value พิมพ์รหัสครู
4. กด **บันทึกพร็อพเพอร์ตี้ของสคริปต์ (Save script properties)**

ถ้ายังไม่ได้ตั้งรหัส นักเรียนส่งผลได้ แต่จะไม่มีใครดึงผลออกไปได้ รวมถึงครูด้วย

## ขั้นที่ 4 Deploy เป็น Web app

1. มุมขวาบน **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดรูปเฟืองข้าง "เลือกประเภท (Select type)" → **เว็บแอป (Web app)**
3. ตั้งค่า:
   - คำอธิบาย: อะไรก็ได้ เช่น `รุ่น 1`
   - **ดำเนินการในฐานะ (Execute as): ฉัน (Me)**
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access): ทุกคน (Anyone)** ← ต้องเป็น "ทุกคน" นักเรียนจึงส่งได้โดยไม่ต้องล็อกอิน Google
4. กด **ทำให้ใช้งานได้ (Deploy)**
5. ครั้งแรก Google จะขอสิทธิ์: **ให้สิทธิ์เข้าถึง (Authorize access)** → เลือกบัญชีของครู → ถ้าขึ้นว่า "Google ไม่ได้ยืนยันแอปนี้" กด **ขั้นสูง (Advanced)** → **ไปที่ รับผลเกมร้านซ่อมคอม (ไม่ปลอดภัย)** → **อนุญาต (Allow)**
   - เป็นเรื่องปกติของสคริปต์ที่ครูสร้างเอง สคริปต์นี้ขอสิทธิ์แค่แก้ Sheet ไฟล์นี้ ไม่ได้ส่งข้อมูลไปที่อื่น
6. คัดลอก **URL ของเว็บแอป (Web app URL)** ที่ลงท้ายด้วย `/exec`

## ขั้นที่ 5 ลองว่าใช้ได้

1. วาง URL ของเว็บแอปในเบราว์เซอร์ จะเห็นข้อความประมาณ `{"ok":true,"app":"shop-sheet","note":"เว็บแอปรับผลของเกมร้านซ่อมคอมทำงานอยู่"}`
2. เปิดหน้าครูของเกม: https://nabaworn0.github.io/project-cai/?view=teacher
3. ส่วน **เชื่อมกับ Google Sheet ของครู**: วาง URL ของเว็บแอป ใส่รหัสครู กด **บันทึก**
4. ส่วน **ลิงก์เกมสำหรับห้อง**: พิมพ์ชื่อห้อง เช่น `ปวช.1/2` จะได้ลิงก์และ QR ของห้องนั้น
5. ส่วน **ดึงผลของห้อง**: กด **ดูห้องใน Sheet** ตอนนี้จะขึ้นว่ายังไม่มีผลส่งเข้ามา (ถูกต้อง เพราะยังไม่มีนักเรียนส่ง)

## ใช้ในห้องเรียน

- ให้นักเรียนสแกน QR หรือเปิดลิงก์ของห้อง แล้วกรอกชื่อ ชั้น เลขที่ · เกมส่งผลเข้า Sheet เองทุกครั้งที่ทำขั้นไหนเสร็จ นักเรียนไม่ต้องกดส่ง
- นักเรียนเปิดลิงก์ห้องครั้งเดียวพอ ครั้งต่อไปเปิดเกมจากลิงก์ปกติ เครื่องนั้นก็ยังส่งเข้าห้องเดิม
- เน็ตหลุด: เกมจำไว้แล้วส่งใหม่เอง · หน้า "สรุปผลการเรียน" ของนักเรียนบอกว่าส่งถึงครูแล้วหรือยัง
- ทางสำรอง: นักเรียนดาวน์โหลดไฟล์ผลจากหน้าสรุปผล แล้วครูลากไฟล์มาวางในหน้าครู

## ใน Sheet มีอะไร

- แท็บละห้อง ชื่อแท็บตามชื่อห้องในลิงก์ · ถ้าครูมีแท็บของตัวเองชื่อเดียวกันอยู่แล้ว แท็บนั้นจะไม่ถูกแตะ ห้องนั้นจะได้แท็บชื่อ `ชื่อห้อง (เกม)` แทน
- 1 แถวต่อนักเรียน 1 คน (ชั้น + เลขที่) · ส่งซ้ำแล้วเขียนทับแถวเดิม ไม่เพิ่มแถว
- คอลัมน์: ห้อง · เลขที่ · ชื่อ-สกุล · ก่อนเรียน · หลังเรียน · เคสที่เล่น · ดาวเคสรวม · ส่งล่าสุด · ข้อมูลเต็ม
- **คอลัมน์ "ข้อมูลเต็ม" อย่าแก้** หน้าครูใช้คอลัมน์นี้คิดผลทั้งหมด (ถ้าเผลอแก้ หน้าครูจะบอกว่าแถวไหนอ่านไม่ได้ และเมื่อนักเรียนคนนั้นส่งใหม่ แถวจะกลับมาถูกเอง)
- ลบแถวของนักเรียนที่ส่งผิดห้องได้ตามปกติ · อย่าแก้หัวตาราง (แถวที่ 1) เพราะสคริปต์ใช้หัวตารางจำว่าแท็บไหนเป็นของห้อง

## แก้โค้ดภายหลัง (เมื่อมีรุ่นใหม่)

วางโค้ดใหม่แล้วบันทึก จากนั้น **การทำให้ใช้งานได้ (Deploy) → จัดการการทำให้ใช้งานได้ (Manage deployments)** → กดรูปดินสอ → เวอร์ชัน (Version): **เวอร์ชันใหม่ (New version)** → ทำให้ใช้งานได้

ห้ามใช้ "การทำให้ใช้งานได้รายการใหม่" ซ้ำ เพราะจะได้ URL ใหม่ และลิงก์ห้องกับ QR เดิมจะส่งไปที่เก่า

## ข้อจำกัด (บอกตรงๆ)

- ต้องมีอินเทอร์เน็ตตอนส่ง (ถ้าไม่มี เกมจะลองส่งใหม่เองเมื่อกลับมาออนไลน์)
- ใครที่รู้ลิงก์ห้องก็ส่งผลเข้ามาได้ ระบบนี้ไม่ได้กันโกงแบบระบบสอบ ครูควรดูชื่อและเลขที่ในตาราง
- Sheet มีชื่อนักเรียน ครูไม่ควรแชร์ Sheet หรือรหัสครูให้คนอื่น
- ลืมรหัสครู: เข้าไปดูหรือตั้งใหม่ได้ที่ขั้นที่ 3 (เปลี่ยนรหัสแล้วไม่ต้อง Deploy ใหม่)

## ร่องรอยการตรวจฝั่งผู้พัฒนา

- `tools/apps-script.test.ts` รัน `Code.gs` จริงกับ Sheet จำลอง (เซลล์ + บริการที่ Apps Script มีให้) แล้วใช้โค้ดฝั่งเกม (`payload`) ส่ง และโค้ดหน้าครู (`sheetClasses` / `sheetFiles` / `readResultsFile`) อ่านกลับ
- เมื่อแก้ `Code.gs` หน้าครูได้โค้ดใหม่เองตอน build (นำเข้าแบบข้อความ) · ครูที่ติดตั้งไว้แล้วต้องวางโค้ดใหม่และ Deploy เวอร์ชันใหม่ตามหัวข้อ "แก้โค้ดภายหลัง"
