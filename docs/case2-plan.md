## 1. ผู้เล่นจะเจออะไร

ลำดับเหมือนเคส 1 ทุกช่วง (เข้าร้าน → ใบงาน → เดาสาเหตุ → ซ่อม → ลูกค้าถาม → สรุป) ต่างกันแค่ช่วงซ่อม:

| # | ช่วง | บนจอ |
|---|---|---|
| 1 | ลูกค้าเข้าร้าน | **น้องบีม** เดินเข้ามา หน้า worried "ผมทำ USB เองครับพี่ ทำตามคลิปเป๊ะเลย แต่กด Boot Menu แล้วไม่มี USB ให้เลือก…" |
| 2 | ใบงาน | เครื่องแรง (Ryzen 5 / i5 รุ่น 12, RAM 16–32 GB) · BIOS คลาสสิก · ลง Windows 11 · ไม่ต้องเก็บข้อมูล · **อุปกรณ์ที่ลูกค้าให้มา: แฟลชไดรฟ์ 16 GB (ทำมาแล้ว)** |
| 3 | เดาสาเหตุ | 4 ตัวเลือกในไฟล์เคส (ข้อถูก: USB ทำแบบ MBR แต่เครื่องบูตแบบ UEFI) |
| 4 | **ซ่อม** | มีเครื่อง 2 เครื่อง (ข้อ 2) |
| 5 | ลูกค้าถาม | "แล้วคลิปที่ผมดูผิดเหรอครับ" |
| 6 | สรุป | ดาว · เหรียญ · บันทึกช่าง (หนังสือ น.45–48) |

**กดรับลูกค้าคนถัดไปหลังเคส 1 จะได้เคส 2** (ตอนนี้กดแล้วได้เคส 1 ซ้ำ) · หลังเคส 2 วนสุ่มระหว่างเคสที่ทำเสร็จแล้ว จนกว่าเคส 3 จะเสร็จ

## 2. ช่วงซ่อม: 2 เครื่อง

1. **เครื่องลูกค้า** (คอมบนเคาน์เตอร์ แบบเคส 1): เสียบ USB ของน้องบีมอยู่แล้ว ลองได้เหมือนเดิม กด F8 จะ**ไม่เห็น USB** ในเมนู (ระบบทำไว้แล้ว เทสต์ผ่านแล้ว) ช่วยให้ผู้เล่นเห็นอาการเอง
2. **คอมของร้าน** (ใหม่ วางบนเคาน์เตอร์อีกฝั่ง): เปิด Rufus ทำ USB ใหม่ แล้วเอากลับไปเสียบเครื่องลูกค้า กด F8 เลือก USB → Setup = ผ่าน

### หน้าจอ Rufus (จำลอง ใช้นิ้วแตะ/เมาส์ ไม่ใช้แถบปุ่มคีย์บอร์ด)

ข้อความตามโปรแกรมจริงรุ่น 4.15 (real-screens.md) ไม่มีโลโก้

```
Drive Properties
  Device            [ CCCOMA_X64FRE_TH-TH_DV9 (E:) [16 GB] ▾ ]
  Boot selection    [ Disk or ISO image (Please select) ▾ ]  [SELECT]
                       └─ แตะ SELECT → หน้าต่างเลือกไฟล์ (โฟลเดอร์ Downloads):
                          Win11_24H2_Thai_x64.iso ✅ · Win10_22H2_Thai_x64.iso · ubuntu-24.04-desktop-amd64.iso
  Partition scheme  [ MBR ▾ ]   ← ค่าที่น้องบีมเลือกมาจากคลิป (Rufus จำค่าเดิม)
  Target system     [ BIOS (or UEFI-CSM) ▾ ]   ← เปลี่ยนตามช่องบนเอง: GPT → UEFI (non CSM)
Format Options
  Volume label · File system [NTFS] · Cluster size [4096 bytes (Default)]
Status  [ READY ]                                  [START] [CLOSE]
```

กด START → กล่อง **Customize Windows installation?** (ตัวเลือกยกเลิกการตรวจ TPM/Secure Boot ฯลฯ เฉพาะไฟล์ Windows) → กล่องเตือน **"WARNING: ALL DATA ON DEVICE … WILL BE DESTROYED"** [OK/Cancel] → แถบความคืบหน้าราว 4 วินาที → READY (ลำดับกล่องตาม Rufus จริง)

### ทางที่ผิด (กับดัก) และผลที่ได้

| ผู้เล่นทำ | ผล | นับพลาด |
|---|---|---|
| ทำ USB ใหม่แต่ยังเป็น **MBR** | USB ยังไม่ขึ้นใน Boot Menu เหมือนเดิม | นับตอนบูตไม่สำเร็จ (เลือก Windows Boot Manager = เข้า Windows เดิม) เหมือนเคส 1 |
| เลือก ISO **Windows 10** | บูตได้ แต่ขึ้น "Windows 10 Setup" · น้องบีม: "เอ๊ะ นี่มัน 10 นี่พี่" | 1 |
| เลือก ISO **Ubuntu** | บูตได้ แต่ขึ้นเมนู GNU GRUB "Try or Install Ubuntu" · น้องบีมงง | 1 |
| เข้า BIOS เปิด **CSM Support** ให้เครื่องบูต USB แบบ MBR ได้ (ทางลัดที่ผิด) | บูตถึง Setup แต่ขึ้น **"This PC can't run Windows 11"** เพราะ Windows 11 ต้องบูตแบบ UEFI | 1 (ดูข้อ 5) |
| ติ๊ก "Remove requirement for … TPM 2.0" ในกล่อง Customize | ทำ USB ได้ แต่ไม่ได้นับพลาด มีบันทึกช่างบอกว่าเป็นการติดตั้งที่ไมโครซอฟต์ไม่รองรับ (ดูข้อ 5) | 0 |

## 5. ต้องการให้ตัดสินใจ

| เรื่อง | ผมเสนอ | ทางเลือก |
|---|---|---|
| **ภาษาของ Rufus** | **อังกฤษ** ตามหนังสือ น.45–48 · ทำให้สลับไทยได้ทีหลัง (real-screens.md มีคำแปลไทยของจริงครบแล้ว) | ทำปุ่มสลับไทย/อังกฤษในขั้นนี้เลย (เครื่องนักเรียนที่เป็น Windows ไทยจะเห็น Rufus ภาษาไทย) |
| **คอมของร้านในฉาก** | ผมวาดโน้ตบุ๊กแบบพิกเซลด้วยโค้ดไปก่อน (สีจากพาเลตเดิม) ถ้าอยากได้สวยกว่านี้ค่อยขอภาพจาก ChatGPT แล้วแทนทีหลัง | ขอภาพจาก ChatGPT ก่อนเริ่มข้อ D (ผมเขียนพรอมต์ให้) |
| **ทางลัดเปิด CSM** | นับพลาด 1 ครั้ง และขึ้นหน้า "This PC can't run Windows 11" แบบสั้น (หน้าเต็มทำในขั้นของเคส 4 ตามแผนเดิม) | ไม่ทำทางนี้ในเคส 2 (ไม่ว่าเปิด CSM หรือไม่ ผลเหมือนเดิม) |
| **ติ๊กยกเลิกตรวจ TPM ใน Rufus** | ไม่นับพลาด แต่บันทึกช่างเตือน (เครื่องน้องบีมผ่านข้อกำหนดอยู่แล้ว การติ๊กไม่ทำให้เสียหาย) | นับพลาด 1 ครั้ง |
| **จับเวลา** (แผนเคส 1 เคยบอกว่าเริ่มเคส 2) | ยังไม่จับเวลา ดูผลลองในห้องเรียนก่อน | จับเวลา หักแค่ความพอใจ ไม่หักดาว |
| **มินิเกมจับคู่ MBR/GPT** (ไฟล์เคสใส่ไว้) | ไม่อยู่ในขั้นนี้ ทำในขั้นมินิเกมตามแผนเดิม แล้วค่อยแทรกก่อนเปิด Rufus | ทำในขั้นนี้ด้วย |

## 6. ไม่อยู่ในขั้นนี้

Setup ทั้งเส้น (หน้าเลือกพาร์ทิชัน) · หน้า "This PC can't run Windows 11" แบบเต็ม · เคส 3–5 · บทเรียนบท 4–6 · มินิเกม (ทั้งหมดตามลำดับเดิมใน HANDOFF)

## 7. ความเสี่ยงที่รู้อยู่

- **Rufus บนมือถือแนวตั้งจอเล็ก (360×640)**: หน้าต่าง Rufus จริงสูงกว่ากว้าง ต้องย่อให้พอดีแบบเดียวกับหน้าจอ BIOS ถ้าตัวหนังสือเล็กเกินอ่าน จะให้หน้าต่างเลื่อนขึ้นลงได้แทนการย่อ
- **รายการตัวเลือกแบบดรอปดาวน์บนมือถือ**: ใช้กล่องเลือกของเกมเอง ไม่ใช้ของเบราว์เซอร์ เพื่อให้หน้าตาเหมือน Windows และกดง่าย
- **ชื่อไฟล์ ISO** ใช้รูปแบบชื่อไฟล์จริงที่ไมโครซอฟต์และ Ubuntu ตั้ง (ไม่มีโลโก้) ถ้าครูอยากให้ตรงกับไฟล์ในแล็บ แก้ในไฟล์เคสได้
