# แผนปรับเกมตามหนังสือเรียน

**สถานะ (24 ต.ค. 2026):** ผู้ใช้อนุมัติแผนแล้ว
- ✅ ทำแล้ว: ข้อกำหนดแยก Windows 10/11 ในตรรกะเกม, `targetOs` ในเคส, วัตถุประสงค์ LO1–LO6 ชุดใหม่, ปัญหาใหม่ตามหนังสือ (usb-wrong-scheme, bios-not-saved, no-product-key, missing-display-driver), ป้ายที่มา (หนังสือ น.xx / เพิ่มสำหรับ Win 11 / นอกหนังสือ), BIOS แบบคลาสสิกเป็นยี่ห้อแรก, ตัวอย่างเคส Windows 10 (c04), หน้าดูเนื้อหาแสดงทั้งหมดนี้
- ⏭️ รอบ 1: บทเรียนบท 4–6, ลูกค้าและ 5 เคสจริง, หน้าจอจำลอง, มินิเกม 3 อย่าง
- ⏭️ รอบ 2: บทเรียนที่เหลือ, ข้อสอบ A/B เขียนใหม่, หน้าจอติดตั้ง Windows 10, เคสข้อจำกัดฮาร์ดแวร์

อ้างอิง: หนังสือ **ระบบปฏิบัติการเบื้องต้น รหัสวิชา 20204-2001** (หลักสูตร ปวช. 2562)
https://online.anyflip.com/uosag/cuqu/mobile/index.html
ใช้เฉพาะส่วนการลง Windows: **หน่วย 3.3 การติดตั้ง Windows 10 (หน้า 45–60)** และ **หน่วย 4 การติดตั้งไดรเวอร์ (หน้า 72–93)** พร้อมแบบทดสอบของสองหน่วยนี้

การตัดสินใจ (24 ต.ค. 2026):
1. เรียนตามลำดับและหัวข้อของหนังสือ และมี **ทั้ง Windows 10 และ 11**
   - **Windows 11 เป็นหลัก** (รุ่นล่าสุดที่แนะนำ) เกมใช้หน้าจอติดตั้ง Windows 11 ก่อน
   - **Windows 10 ตามหนังสือ** ใช้ในบทเรียน (เทียบทีละขั้นว่า 11 ต่างอย่างไร) และในเกมเป็นทางเลือกเมื่อเครื่องลง 11 ไม่ได้
   - ต้องบอกนักเรียนชัดๆ ว่า **Windows 10 หมดการอัปเดตความปลอดภัยฟรีแล้ว (14 ต.ค. 2025)** ไม่ใช่รุ่นที่แนะนำ
2. รวมเรื่องไดรเวอร์หลังติดตั้ง (dxdiag, Device Manager) เครื่องพิมพ์ทำแค่ภาพรวม
3. BIOS เริ่มจากแบบคลาสสิก (พื้นเทา/น้ำเงิน แบบ AMI) ตามหนังสือ ยี่ห้ออื่นค่อยเพิ่ม
4. มีส่วน **"เรียนก่อนเล่น"** อธิบายอุปกรณ์ หน้าที่ และขั้นตอนตามหนังสือ ก่อนเข้าเกม

> หน้าจอและข้อความของ Windows 11 ในเอกสารนี้เขียนจากความรู้ทั่วไปของรุ่น 24H2
> **ต้องเทียบกับ ISO รุ่นล่าสุดบนเครื่องจริงในห้องปฏิบัติการก่อนใช้สอน** (เหมือนกับหน้า BIOS)

## 3. ส่วน "เรียนก่อนเล่น"

### ลำดับของนักเรียน

```
แบบทดสอบก่อนเรียน  →  เรียนก่อนเล่น  →  เล่นเกม (เคส)  →  แบบทดสอบหลังเรียน
```

แนะนำให้ทำแบบทดสอบก่อนเรียน **ก่อน** บทเรียน จะได้วัดความรู้เดิมจริงๆ แล้วเทียบกับหลังเรียน (ครูดูพัฒนาการได้)

### รูปแบบ

- **ช่าง (ตัวละครผู้เล่น) เป็นคนเล่า** สลับสีหน้าตามเนื้อหา (ตกใจตอนเรื่องลบข้อมูล ดีใจตอนทำถูก)
- แต่ละบทสั้น 2–4 นาที เป็นหน้าๆ ปัดหรือกดถัดไปได้ มือถือใช้สะดวก
- ภาพอุปกรณ์เป็น **พิกเซลอาร์ต** (ใช้ไอคอนที่มีแล้ว: USB, RAM, SSD, CPU, เมนบอร์ด, ชิป TPM, ไขควง, แว่นขยาย)
- หน้าจอ Rufus, BIOS, Windows Setup เป็น **หน้าจอจำลองแบบเดียวกับในเกม** ให้ลองกดจริงในจุดสำคัญ เช่น กด F2 เข้า BIOS, เลื่อน USB ขึ้นอันดับแรก, กด F10
- ทุกบทมี **"ดูในหนังสือหน้า …"** และกล่อง **"ต่างจากหนังสือ (Windows 11)"** ตรงจุดที่ต่าง
- จบบทมีคำถามเช็กความเข้าใจ 1–2 ข้อ (ไม่นับคะแนน แต่บันทึกว่าตอบถูกไหม ติดแท็ก LO)
- กลับมาอ่านซ้ำได้ตลอดจากเมนู **"คู่มือช่าง"** ในร้าน
- เนื้อหาบทเรียนเก็บเป็น JSON แยกจากโค้ด (`lessons/*.json`) และผ่านตัวตรวจเหมือนเนื้อหาอื่น ครูแก้ได้

## 4. สิ่งที่ต้องปรับในเนื้อหาและเกม

### รุ่น Windows ในเคส

- ทุกเคสระบุว่าลูกค้าต้องการลงรุ่นไหน (`targetOs`: `win11` หรือ `win10`) และตั๋วเครื่องแสดงให้เห็น
- ข้อกำหนดในตรรกะเกม (`src/core/win11.ts` → แยกเป็นข้อกำหนดตามรุ่น) เช็กตามตารางข้อ 1
  เช่น โหมด Legacy + MBR เป็นปัญหาสำหรับ 11 แต่ไม่ใช่ปัญหาสำหรับ 10
- ตัวตรวจเนื้อหาพิสูจน์ว่าทุกเครื่องที่สุ่มได้ซ่อมได้ **สำหรับรุ่นที่เคสกำหนด**
- เคสแบบ **"ลง 11 ไม่ได้"** มีสองแบบ:
  - **แก้ได้** (รอบ 1): TPM/Secure Boot ถูกปิด, เครื่องตั้งเป็น Legacy → แก้ใน BIOS แล้วลง 11
  - **ข้อจำกัดฮาร์ดแวร์** (รอบ 2): ไม่มีชิป TPM 2.0 หรือ CPU ไม่อยู่ในรายชื่อ → ผู้เล่นต้องเลือกและอธิบายให้ลูกค้า:
    ลง 10 พร้อมแจ้งว่าไม่มีอัปเดตความปลอดภัย / เปลี่ยนอะไหล่ (เช่น ใส่ชิป TPM ถ้าเมนบอร์ดมีช่อง) / แนะนำเปลี่ยนเครื่อง
    คะแนนดูจากการตัดสินใจที่เหมาะกับความต้องการลูกค้าและการอธิบายความเสี่ยง ไม่ใช่มีคำตอบเดียว

### มินิเกม 6 อย่าง

| มินิเกม (เดิม) | ปรับตามหนังสือ |
|---|---|
| 1 ลำดับบูต USB / Legacy–UEFI | คง: BIOS คลาสสิก Boot Device Priority + F10 |
| 2 จับคู่ MBR/GPT กับโหมดบูต | คง และใช้กับการเลือก Partition scheme ใน Rufus ด้วย |
| 3 ข้อกำหนด Windows 11 หาจุดผิดปกติ | ขยายเป็น **"เครื่องนี้ลงรุ่นไหนได้"** เทียบสเปกกับข้อกำหนด 10 และ 11 |
| 4 เตรียม USB/ISO แบบ "แตะตามจังหวะ" | **เปลี่ยนเป็น "ตั้งค่า Rufus ให้ถูก"** ตามหนังสือหน้า 45–48 |
| 5 พาร์ทิชันและ NTFS | คง (หน้า 55) |
| 6 ไดรเวอร์ Device Manager | คง + dxdiag (หน่วย 4) |
| การ์ดเรียงขั้นตอน | ใช้ลำดับขั้นตอนของหนังสือที่ปรับเป็น Windows 11 |

### หน้า BIOS

- เพิ่มยี่ห้อ `classic` (แบบ AMI ในหนังสือหน้า 49–51) เป็น **ยี่ห้อแรกที่ใช้ในรอบ 1** แทน ASUS
- เมนูเพิ่ม Boot Mode / Secure Boot / TPM ไว้ในแท็บ Boot และ Security เพราะ Windows 11 ต้องใช้
- ASUS / Acer / HP เก็บไว้ใช้รอบถัดไปตามแผนเดิม

### แบบทดสอบก่อน/หลังเรียน

- แบบทดสอบในหนังสือ (หน่วย 3 และ 4) ใช้ประเด็นเดียวกันทั้งก่อนและหลังเรียน และมีข้อเรื่อง Ubuntu ที่ไม่เกี่ยวกับเกม
- ข้อเสนอ: เขียนข้อสอบ A/B ใหม่ **ด้วยถ้อยคำของเราเอง** ครอบคลุมประเด็นเดียวกับหนังสือ (Rufus, ตั้งค่า BIOS ก่อน, Install now, License, Language, dxdiag, Device Manager, .inf, Plug and Play) + ประเด็น Windows 11 ที่เพิ่ม
  ข้อ "32 หรือ 64 บิตขึ้นกับ RAM" ยังใช้ได้ในบริบท Windows 10 และเพิ่มข้อคู่กันว่า "Windows 11 มีแบบ 32 บิตไหม / ต้องมี RAM เท่าไหร่"
- เหตุผลที่ไม่คัดลอกข้อสอบจากหนังสือตรงๆ: repo เกมเป็นสาธารณะ ถ้าจะใช้ข้อสอบเดิมควรขออนุญาตผู้เขียน/ครูเจ้าของหนังสือก่อน

### สิ่งที่ย้ายรอบ

- รอบ 1 เดิม: ฉากร้าน + 5 เคส + มินิเกม 3 อย่าง + ดาว/คำใบ้/เหรียญ
- ข้อเสนอรอบ 1 ใหม่:
  - **ส่วนเรียนก่อนเล่น บท 4–6** (Rufus, BIOS, ขั้นตอนติดตั้ง) เทียบ Windows 10 ตามหนังสือกับ Windows 11 ด้วยข้อความและภาพ
  - ฉากร้าน + 5 เคส ลง **Windows 11** บนหน้าจอติดตั้งจำลอง Windows 11 (มีเคส "ลง 11 ไม่ได้ แต่แก้ได้")
  - มินิเกม 3 อย่าง (MBR/GPT, เครื่องนี้ลงรุ่นไหนได้, พาร์ทิชัน) + ดาว/คำใบ้/เหรียญ
- รอบ 2:
  - บทเรียนบท 1–3, 7–8 + แบบทดสอบก่อน/หลังเรียน (เดิมอยู่รอบ 2 อยู่แล้ว)
  - **หน้าจอติดตั้ง Windows 10 ที่เล่นได้จริง** (มีหน้าเลือก 32/64 บิต และ Custom/Upgrade ตามหนังสือ)
  - เคสข้อจำกัดฮาร์ดแวร์ที่ต้องเลือกลง 10 / เปลี่ยนอะไหล่
- หน้าจอ BIOS, Rufus, Device Manager ใช้ร่วมกันทั้งสองรุ่น ส่วนหน้าจอติดตั้งและตั้งค่าหลังติดตั้งต้องทำแยก 2 ชุด

## 5. ต้องการจากผู้ใช้ / ครู

- ยืนยันวัตถุประสงค์ LO1–LO6 ชุดใหม่ (หรือแก้)
- ยืนยันรายการบทเรียน 8 บท และการแบ่งรอบ
- ภาพหน้า BIOS จากเครื่องจริงในห้องปฏิบัติการ (ยังต้องการเหมือนเดิม) และ **ภาพหน้าจอติดตั้ง Windows 11 รุ่นล่าสุดและ Windows 10 จากเครื่องจริง** เพื่อเทียบข้อความ
- เครื่องในห้องปฏิบัติการลง Windows 11 ได้ทุกเครื่องไหม (ถ้ามีเครื่องที่ลงไม่ได้ จะใช้เป็นตัวอย่างในเคสข้อจำกัดฮาร์ดแวร์ได้)
- ถ้าจะใช้ข้อสอบจากหนังสือตรงๆ ต้องได้รับอนุญาตก่อน
