# เช็กลิสต์ลองบทเรียนคลิปการ์ตูนบนมือถือจริง

งาน V4 ของ [lessons-plan.md](lessons-plan.md) · เทสต์อัตโนมัติผ่านแล้วทุกขนาดจอ (มือถือจำลอง)
ใช้เวลาประมาณ 15 นาที (ดูคลิป 1 จนจบราว 3 นาที) · ใช้เน็ตราว 9 MB ต่อคลิป ถ้าใช้เน็ตมือถือ แนะนำต่อ Wi-Fi
ถ้าเปิดแล้วไม่เจอบทเรียน: ปิดแท็บเกมแล้วเปิดใหม่ (มือถือเก็บเวอร์ชันเก่าไว้)

## เปิดเกม

- **ปกติ:** https://nabaworn0.github.io/project-cai/ (ทำแบบทดสอบก่อนเรียนก่อน การ์ดบทเรียนจึงเปิด)
- **ครูสาธิต เปิดทุกขั้น:** https://nabaworn0.github.io/project-cai/?unlock=all

## ลองตามนี้

1. ทำแบบทดสอบก่อนเรียนให้เสร็จ → การ์ด "บทเรียน: ระบบปฏิบัติการคืออะไร" เปิด → กด "ทำต่อ"
2. เห็นคลิปพร้อมปุ่มเล่น · ใต้คลิปมีข้อความ "ภาพสร้างด้วย AI…" และ "ดูคลิปให้จบ แล้วตอบคำถามทบทวน 2 ข้อด้านล่าง"
3. กดเล่น → มีเสียงพี่ช่าง ซับไทยอยู่ในภาพ · ลองกดเต็มจอ แล้วกลับมา
4. ดูจนถึงท้ายคลิป (หรือเลื่อนแถบไปช่วงท้าย) → คำถาม 2 ข้อขึ้นใต้คลิป
5. ข้อ 1 เลือกข้อที่ผิด → ขึ้น "ยังไม่ถูก" พร้อมคำอธิบาย · กด "▶ ดูช่วงนั้นในคลิปอีกครั้ง" → คลิปกระโดดไปช่วงที่พูดเรื่องนั้นแล้วเล่นต่อ
6. เลือกข้อที่ถูก → ขึ้น "ถูกต้อง!" ข้อนั้นกดไม่ได้แล้ว · ตอบข้อ 2 ให้ถูก → ขึ้น "จบบทเรียนแล้ว เก่งมาก!"
7. กด "กลับเส้นทางเรียน" → การ์ดบทเรียนเป็นเสร็จแล้ว · ทำซ้ำกับ "บทเรียน: ประเภทของระบบปฏิบัติการ"
8. ลองอีกครั้งกับบทที่ยังไม่จบ: ดูจนคำถามขึ้น ยังไม่ตอบ กด "☰ เมนู" แล้วเข้าใหม่ → คำถามขึ้นทันที ไม่ต้องดูซ้ำ
