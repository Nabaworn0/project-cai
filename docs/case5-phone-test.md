# เช็กลิสต์ลองเคส 5 (ครูวิไล · อัปเครื่องแล็บเป็น Windows 11) บนมือถือจริง

งาน E ของ [case5-plan.md](case5-plan.md) · เทสต์อัตโนมัติผ่านแล้วทุกขนาดจอ (มือถือจำลอง)
ใช้เวลาประมาณ 15 นาที (เคสนี้ยาวที่สุด) · **ช่วยจับเวลาตั้งแต่กด "รับเรื่อง" จนถึงหน้าสรุป** เพื่อปรับเวลาของเคส
ถ้ามือถือยังไม่มีเคส 5: ปิดแท็บเกมแล้วเปิดใหม่ (มือถือเก็บเวอร์ชันเก่าไว้ เหมือนตอนลองเคส 4)

## เปิดเกม

- **เข้าเคส 5 ตรงๆ:** https://nabaworn0.github.io/project-cai/?case=c05-lab-upgrade
  - Legacy อย่างเดียว: เพิ่ม `&seed=s1` · ไม่มี Product Key ด้วย: `&seed=s3` · ปิด TPM ด้วย: `&seed=s5` (ไม่ใส่ seed = สุ่ม)
- **หรือเล่นตามลำดับ:** ป้าสมศรี → น้องบีม → ลุงชัย → พี่ต้น → ครูวิไล
- **ดูแค่หน้าตั้งค่าเริ่มต้น:** หน้าดูเนื้อหา `?view=content#sims` ข้อ 5 ติ๊ก "ข้ามไปหน้าตั้งค่าเริ่มต้นเลย"

## ทางที่ถูก (seed s1)

1. รับเรื่อง → ตารางข้อกำหนด (CPU / RAM / ดิสก์ = ผ่าน · Secure Boot / TPM = ต้องดูใน BIOS) → รับงาน
2. ดูรูปที่ครูถ่ายมา → เดาสาเหตุ "ตั้งค่าไว้สำหรับ Windows 10 แบบ Legacy ต้องเปลี่ยนเป็น UEFI"
3. เปิดเครื่อง → รอ POST → กดปุ่มใดก็ได้ → หน้า "This PC can't run Windows 11" (ไม่นับพลาด)
4. รีสตาร์ตเครื่อง → F2 → Boot → Boot Settings Configuration → CSM Support = Disabled → Esc → Security → Secure Boot = Enabled → F10 → Ok
5. เครื่องบูตไม่ขึ้น ("Reboot and Select proper Boot device") ครูทัก ไม่นับพลาด
6. โน้ตบุ๊กร้าน → Rufus: Win11 · Partition scheme **GPT** → START → OK → OK → ไปที่เครื่องลูกค้า
7. บูต USB → Setup: Next → Next → ติ๊กยอมรับ → Next → แตะช่องคีย์ → Next → Accept → ตัวแดง MBR → Delete Partition ทั้ง 2 อัน (ไม่ต้องถามเรื่องสำรองข้อมูล) → Next → Install
8. ติดตั้งเสร็จ เครื่องรีสตาร์ตเอง → "Press any key" ปล่อยให้หมดเวลา → หน้าตั้งค่าเริ่มต้น
9. Thailand → Yes → Yes → Add layout → Thai Kedmanee → Add layout → **เสียบสายแลน** → Next → ชื่อเครื่อง LAB-PC01 → Next → Set up for personal use → Next
10. **ยื่นเครื่องให้ครูวิไลลงชื่อเอง** → รอครูพิมพ์และตั้ง PIN → **ถามครูวิไลเรื่องความเป็นส่วนตัว** → Accept → Skip → Skip → Only save files to this PC → เดสก์ท็อป = ซ่อมสำเร็จ
11. กลับไปคุยกับลูกค้า → ตอบคำถามครู 2 ข้อ → สรุป

## กับดักที่ลองได้

- [ ] แก้ใน BIOS แล้วออกด้วย Esc (ไม่บันทึก) → หน้า "can't run" เดิม นับพลาด
- [ ] ปิด CSM แล้วบูตซ้ำโดยยังไม่ทำ USB ใหม่ → "ไม่มีอุปกรณ์บูต" ครั้งที่สอง นับพลาด
- [ ] หน้าบัญชี: แตะช่องอีเมล → "พิมพ์ให้เลย" หรือ "ขอรหัสผ่าน" → ครูไม่สบายใจ นับพลาดอย่างละครั้ง
- [ ] ข้ามแป้นพิมพ์ไทย / ตั้งชื่อเครื่องอื่น / ไม่ถามเรื่องความเป็นส่วนตัว → ไม่หักดาว แต่บันทึกช่างบอก
- [ ] seed s3: กด "I don't have a product key" แล้วเลือกรุ่นไม่ตรงใบงาน (ใบงานเป็น Pro) → บันทึกช่างบอก

## ที่รู้อยู่แล้วว่ายังไม่มี / ยังไม่ตรงของจริง

- ข้อความบางหน้าของหน้าตั้งค่าเริ่มต้นยังไม่ยืนยันคำต่อคำ (⚠️ real-screens.md ข้อ 3.5) · ตั้งชื่อเครื่องแล้วของจริงจะรีสตาร์ตหนึ่งครั้ง ในเกมไม่มี
