# Prompt ให้ ChatGPT: คู่มือครู (ข้อ 7 งาน D)

วิธีใช้: เปิดแชตใหม่ใน ChatGPT แนบไฟล์ `docs/sheet-setup.md` แล้ววางข้อความในกรอบด้านล่าง · ได้ผลแล้วส่งกลับมาให้ Claude ตรวจว่าตรงกับเกม ก่อนนำไปใช้

```text
ช่วยเขียน "คู่มือครู" ภาษาไทย สำหรับเกมการศึกษา "ร้านซ่อมคอม" (รายวิชา 21910-2001 ระบบปฏิบัติการเบื้องต้น ระดับ ปวช.) ผู้เรียนเป็นเด็กฝึกงานในร้านซ่อมคอม เรียนการติดตั้ง Windows 11 ตามลำดับ: แบบทดสอบก่อนเรียน → บทเรียนวิดีโอ 2 คลิป (มีคำถามท้ายคลิป) → เกมเรียงขั้นตอน → เคสลูกค้า 5 เคส → แบบทดสอบหลังเรียน → สะท้อนผลและความพึงพอใจ → สรุปผลการเรียน

ผู้อ่าน: ครูผู้สอนที่ใช้คอมพิวเตอร์ทั่วไปได้ แต่ไม่ใช่โปรแกรมเมอร์ · เขียนสั้น ชัด เป็นขั้นตอน ประโยคละเรื่อง ไม่ใช้ศัพท์เทคนิคเกินจำเป็น (ถ้าต้องใช้ ให้อธิบายในวงเล็บ) · ห้ามเพิ่มฟีเจอร์ ปุ่ม หรือเมนูที่ไม่มีในข้อมูลด้านล่างหรือในไฟล์แนบ · ชื่อปุ่มให้ใช้ตามที่เขียนไว้ทุกตัวอักษร

ไฟล์แนบ sheet-setup.md คือขั้นตอนตั้งค่าที่ถูกต้องตามโค้ดแล้ว ให้คงขั้นตอน ลำดับ ชื่อเมนู และค่าทุกค่าไว้ (เช่น TEACHER_KEY, "ทุกคน (Anyone)", "ฉัน (Me)", New version) ปรับแค่ภาษาให้อ่านง่าย · ส่วน "เช็กลิสต์ลองจริงครั้งแรก" และ "ร่องรอยการตรวจฝั่งผู้พัฒนา" ไม่ต้องใส่ในคู่มือครู

คู่มือมี 4 ส่วน:
1. ตั้งค่าครั้งแรก (จากไฟล์แนบ)
2. เก็บผลในห้องเรียน: ใช้หน้าครู (ลิงก์ https://nabaworn0.github.io/project-cai/?view=teacher) ส่วน "เชื่อมกับ Google Sheet ของครู" (วางลิงก์ Web app + รหัสครู กด "บันทึก") → ส่วน "ลิงก์เกมสำหรับห้อง" (พิมพ์ชื่อห้อง ได้ลิงก์และ QR ปุ่ม "คัดลอกลิงก์") → นักเรียนสแกน QR กรอกชื่อ ชั้น เลขที่ เกมส่งผลเองทุกครั้งที่ทำขั้นไหนเสร็จ · เน็ตหลุดเกมส่งใหม่เอง · ทางสำรอง: นักเรียนกด "ดาวน์โหลดไฟล์ผล" ในหน้าสรุปผล แล้วส่งไฟล์ให้ครู · ใส่คำแนะนำการใช้ในคาบเรียน 1 ย่อหน้าสั้นๆ
3. รวมผล: ส่วน "ดึงผลของห้อง" กด "ดูห้องใน Sheet" → เลือกห้อง → "ดึงผล" · หรือลากไฟล์ผล (.json) หลายไฟล์มาวาง · นักเรียนส่งหลายครั้งใช้ครั้งล่าสุด · ไฟล์ที่ถูกแก้หลังดาวน์โหลดจะมีคำเตือนพร้อมเลขที่ · แถวที่อ่านไม่ได้บอกเลขแถว · ปุ่ม "ดาวน์โหลด CSV (Excel)" และ "พิมพ์หน้านี้"
4. อ่านผล (อธิบายสั้นๆ ว่าแต่ละส่วนบอกอะไร และครูเอาไปใช้ทำอะไร เช่น สอนซ้ำ เขียนรายงาน):
   - คะแนนก่อน/หลังเรียน x̄ (S.D.) และค่าเฉลี่ยที่เพิ่มขึ้น
   - E1/E2 เกณฑ์ 80/80: E1 = ร้อยละเฉลี่ยของผลระหว่างเรียน (คำถามท้ายคลิปที่ตอบถูกครั้งแรก + ดาวรอบแรกของเกมเรียงขั้นตอนและเคส) · E2 = ร้อยละเฉลี่ยคะแนนหลังเรียน · คิดจากผู้ที่ทำแบบทดสอบหลังเรียนแล้ว
   - t-test แบบไม่อิสระ (dependent t-test) ทางเดียว ที่ระดับ .05 · แสดงเมื่อมีผู้ทำทั้งก่อนและหลังอย่างน้อย 5 คน · บอกค่า t, df, p และประโยคสรุปว่ามีหรือไม่มีนัยสำคัญ
   - ร้อยละที่ตอบถูกแยกตามวัตถุประสงค์ 4 ข้อ
   - ตารางรายคน (ก่อน หลัง ระหว่างเรียน ทำครบกี่ขั้น ส่งล่าสุด)
   - วิเคราะห์ข้อสอบรายข้อ: ข้อที่หลังเรียนตอบถูกไม่ถึงครึ่งเป็นสีแดง ควรสอนซ้ำ พร้อมตัวเลือกผิดที่ถูกเลือกบ่อย
   - ความพึงพอใจรายข้อ รายด้าน รวม x̄ (S.D.) เกณฑ์แปลผล 4.51–5.00 มากที่สุด · 3.51–4.50 มาก · 2.51–3.50 ปานกลาง · 1.51–2.50 น้อย · 1.00–1.50 น้อยที่สุด
   - ผู้เรียนประเมินตนเอง (1–5 ดาว) และคำตอบที่ผู้เรียนเขียน
   ปิดท้ายด้วย "ข้อจำกัดที่ควรรู้" จากไฟล์แนบ และ "ปัญหาที่พบบ่อย" แบบถาม-ตอบ 5–6 ข้อ (เช่น ขึ้นว่ารหัสครูไม่ถูกต้อง · ขึ้นว่าติดต่อ Sheet ไม่ได้ · ดูห้องใน Sheet แล้วไม่มีห้อง · นักเรียนบอกว่ายังส่งไม่ได้ · แก้โค้ดแล้วลิงก์เดิมใช้ไม่ได้)

ส่งกลับมาเป็นข้อความ Markdown (หัวข้อ # ## ###) พร้อมนำไปทำเป็นเอกสาร

งานที่ 2 (ทำต่อในข้อความเดียวกัน หลังคู่มือ): ขัดเกลาข้อความบนหน้าครูต่อไปนี้ให้กระชับและสุภาพ เหมาะกับครู · ห้ามเปลี่ยนความหมาย ห้ามยาวกว่าเดิมเกินครึ่งหนึ่ง · ตอบเป็นตาราง 3 คอลัมน์: เดิม | ใหม่ | เหตุผลสั้นๆ (ถ้าดีอยู่แล้วให้เขียน "คงเดิม")
- ตั้ง Sheet และ Apps Script ตามคู่มือครูก่อน แล้ววางลิงก์ Web app ที่ได้ตอน Deploy และรหัสครูที่ตั้งไว้
- คัดลอกโค้ดแล้ว นำไปวางใน Apps Script ของ Sheet
- คัดลอกไม่ได้ ให้กดดาวน์โหลดไฟล์โค้ดแทน
- ลิงก์ Web app ไม่ถูกต้อง: ต้องเป็นลิงก์ที่ได้ตอน Deploy ลงท้ายด้วย /exec
- บันทึกแล้ว (เก็บไว้ในเครื่องนี้)
- ลบการตั้งค่าออกจากเครื่องนี้แล้ว
- รหัสครู (ใช้ดึงผล นักเรียนไม่ต้องรู้)
- ชื่อห้อง (เช่น ปวช.1/2 · ใช้เป็นชื่อแท็บใน Sheet)
- ชื่อห้องใช้ได้เฉพาะตัวอักษร ตัวเลข . / _ - ไม่เกิน 30 ตัว
- ให้นักเรียนสแกน QR หรือเปิดลิงก์นี้ ผลจะส่งเข้า Sheet แท็บ "…" เองทุกครั้งที่ทำขั้นไหนเสร็จ
- ยังไม่มีผลส่งเข้ามาใน Sheet
- ติดต่อ Sheet ไม่ได้ ตรวจอินเทอร์เน็ตและลิงก์ Web app
- รหัสครูไม่ถูกต้อง
- ไม่มีห้องนี้ใน Sheet
- ลากไฟล์ผล (.json) ของนักเรียนมาวางตรงนี้ หรือกดเลือกหลายไฟล์
- ไฟล์ของ … เลขที่ … ถูกแก้ไขหลังดาวน์โหลด ควรตรวจสอบ
- ข้อที่หลังเรียนตอบถูกไม่ถึงครึ่งเป็นสีแดง: ควรสอนซ้ำ
```
