# วัตถุประสงค์เชิงพฤติกรรม

ร่างเมื่อ 25 ต.ค. 2026 · **ผู้ใช้ตกลงแล้ว 25 ต.ค. 2026** · ขยายจาก LO1–LO6 ใน [shop-game-brief.md](../shop-game-brief.md) · รูปแบบตามแผนการสอนตัวอย่าง (แผนการสอน-แข่งสื่อ-69-07-01-69.pdf: K / P / A + การประเมินขั้นสำเร็จผล)

**เรื่อง** การติดตั้งระบบปฏิบัติการ Windows 11
**วิชา** 21910-2001 ระบบปฏิบัติการคอมพิวเตอร์ (ต้องยืนยันรหัสวิชากับอาจารย์) · **เวลา** 60 นาที · **ชั้น** ปวช.

| วัตถุประสงค์เชิงพฤติกรรม | การประเมินขั้นสำเร็จผล |
|---|---|
| **หลังจากจบการเรียนการสอนผู้เรียนควรมีความสามารถดังนี้** | **ระบุในใบคำถามข้อที่** |
| **ด้านความรู้ (K)** | |
| 1. เรียงลำดับขั้นตอนการติดตั้งระบบปฏิบัติการ Windows 11 ได้ถูกต้อง | 1 |
| 2. บอกข้อกำหนดของเครื่องคอมพิวเตอร์ที่ติดตั้ง Windows 11 ได้ | 2 |
| 3. อธิบายรูปแบบพาร์ทิชัน MBR/GPT และระบบไฟล์ NTFS ให้ตรงกับโหมดบูตได้ | 3 |
| **ด้านทักษะกระบวนการ (P)** | **ใบประเมินผลการปฏิบัติงาน** |
| 4. สร้าง USB ติดตั้ง Windows 11 ด้วยโปรแกรม Rufus ให้ตรงกับโหมดบูตของเครื่องได้ | สื่อเกมร้านซ่อมคอม |
| 5. ตั้งค่า BIOS/UEFI (ลำดับบูต, CSM, TPM, Secure Boot) ให้พร้อมติดตั้ง Windows 11 ได้ | สื่อเกมร้านซ่อมคอม |
| 6. สร้างและเลือกพาร์ทิชันสำหรับติดตั้ง Windows 11 ได้ | สื่อเกมร้านซ่อมคอม |
| 7. ตรวจสอบและติดตั้งไดรเวอร์หลังติดตั้งระบบปฏิบัติการได้ | สื่อเกมร้านซ่อมคอม |
| 8. วินิจฉัยและแก้ปัญหาที่เกิดขึ้นระหว่างการติดตั้งได้ | สื่อเกมร้านซ่อมคอม |
| **ด้านเจตคติ (A)** | |
| 9. ละเอียด รอบคอบ ตรวจสอบก่อนลงมือปฏิบัติงาน | ใบสังเกตการณ์ |
| 10. ซื่อสัตย์ มีความรับผิดชอบ ตรงต่อเวลา และมีวินัย | ใบสังเกตการณ์ |

## หมายเหตุ

- **ข้อ 7:** ถ้าใกล้วันนำเสนอแล้วเคส 6 ยังไม่เสร็จ ให้เปลี่ยนช่องประเมินเป็น "ใบงานที่ 1" โดยไม่ต้องแก้ตัววัตถุประสงค์
- **รหัส LO ในไฟล์เนื้อหาเกม** (`lo` ใน problems.json / เคส) ใช้ชุดของ [book-alignment.md](book-alignment.md) ซึ่งเรียงต่างจาก brief (เช่น ไดรเวอร์ = LO6 ในไฟล์เกม แต่ = LO5 ใน brief) ต้องจัดให้เป็นชุดเดียวกับเอกสารนี้ก่อนทำรายงานครู
- brief ระบุว่า LO เป็นร่าง ถ้าอาจารย์ให้จุดประสงค์รายวิชามา ให้ปรับถ้อยคำตามนั้น
- ใบคำถามข้อ 1–3 และใบประเมินผลการปฏิบัติงานยังไม่ได้เขียน
