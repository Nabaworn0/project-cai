# รอบ 1: ลูกค้าและ 5 เคสแรก

**สถานะ (24 ต.ค. 2026):** ผู้ใช้อนุมัติแล้ว · เนื้อหาอยู่ใน `src/content/data/customers.json` และ `cases/c01–c05` (ดูได้ใน ?view=content แท็บเคส) · ภาพลูกค้ารอจาก ChatGPT (art-prompts.md ข้อ 3)

อิงหนังสือ ระบบปฏิบัติการเบื้องต้น 20204-2001 หน่วย 3.3 และแผนใน [book-alignment.md](book-alignment.md)
ทุกเคสลง **Windows 11** (เกมสอน Windows 11 อย่างเดียว ตัดสินใจ 24 ต.ค. 2026) บน **BIOS แบบคลาสสิก** · Windows 10 มีแค่ในเรื่องเล่าของลูกค้า

## 1. หลักการออกแบบ

- **เรียงตามที่นักเรียนเพิ่งเรียน** (บทเรียนบท 4–6): ตั้ง BIOS → ทำ USB → หน้าเลือกพาร์ทิชัน → ข้อกำหนด Win 11 → เคสรวม
  เคส 1 เริ่มที่ BIOS ก่อน Rufus เพราะเปลี่ยนค่าเดียวจบ ง่ายที่สุด และเป็นปัญหาที่ช่างเจอบ่อยที่สุดในชีวิตจริง
- **ความยากขึ้นทีละขั้น** (ตรวจด้วยตัวหาวิธีซ่อมแล้ว):

| เคส | วิธีซ่อมสั้นที่สุด |
|---|---|
| 1 | 1 ขั้น |
| 2 | 1 ขั้น (แต่ต้องตั้งค่าหลายช่องใน Rufus) |
| 3 | 1–2 ขั้น (สุ่มว่ามีปัญหา Product Key เพิ่มไหม) |
| 4 | 1–2 ขั้น (สุ่มว่า Secure Boot ปิดด้วยไหม) |
| 5 | 4–5 ขั้น (เคสรวม ใช้ทุกอย่างที่เรียนมา) |

- **นิสัยลูกค้าต้องเข้ากับปัญหา** ลูกค้าเล่าอาการตามที่คนทั่วไปเห็น ไม่ใช้ศัพท์เทคนิค ช่างต้องแปลเอง
- **ครอบคลุม LO1–LO4** (LO5 หลังติดตั้ง และ LO6 ไดรเวอร์ อยู่รอบ 2 ตามแผน)
- ใช้แต่เรื่องในหนังสือ หรือที่ Windows 11 เพิ่ม ไม่มีเรื่องนอกหนังสือ

## 2. ลำดับในแต่ละเคส (เหมือนต้นแบบ shop-case1)

1. **รับเคส:** ลูกค้าเดินเข้าร้าน เล่าอาการ ตั๋วเครื่องแสดงยี่ห้อ สเปก และรุ่น Windows ที่ต้องการ
2. **เดาสาเหตุก่อนลงมือ:** เลือก 1 จาก 4 ข้อ (ฝึกวินิจฉัย ถ้าเดาผิดเสียดาว 1 ดวง แต่ยังซ่อมต่อได้)
3. **ซ่อมบนหน้าจอจำลอง:** Rufus / BIOS / Windows Setup ตามเคส มีคำใบ้ 2 ครั้ง
4. **อธิบายให้ลูกค้าฟัง:** ลูกค้าถามว่า "ทำไม" เลือกคำอธิบายที่ถูก (เสียดาวถ้าผิด)
5. **สรุป:** ดาว 1–3 (ความแม่นยำมาก่อน), เหรียญ, ความพอใจลูกค้า, บันทึกช่าง (สรุปสิ่งที่เรียน + หน้าในหนังสือ)

## 3. ลูกค้า 5 คน

| ลูกค้า | ใคร | นิสัย | ทำไมเหมาะกับเคส |
|---|---|---|---|
| **ป้าสมศรี** (มีภาพแล้ว) | อายุ 60 ขายขนมออนไลน์ ใช้คอมสั่งของและดูยอดขาย | ใจดี ขี้กังวล ถ่ายรูปหน้าจอมาให้ดูทุกครั้ง | ทำตามคลิปแล้วเสียบ USB แต่เครื่องเข้า Windows เดิม ไม่รู้จัก BIOS |
| **น้องบีม** | นักเรียน ม.5 ชอบเกม ทำ USB เองจากคลิปในยูทูบ | มั่นใจในตัวเอง พูดเร็ว ใช้ศัพท์ผิดๆ ถูกๆ | ทำ USB ผิดค่าใน Rufus เพราะดูคลิปเก่า |
| **ลุงชัย** | เจ้าของร้านถ่ายเอกสารหน้าโรงเรียน | ใจร้อน อยากได้เครื่องคืนเร็ว แต่ใส่ใจเรื่องเงิน | ลง Windows ใหม่ทับเครื่องเก่าที่เป็น MBR และลืมเอา Product Key มา |
| **พี่ต้น** | พนักงานออฟฟิศ อายุ 28 ซื้อคอมมือสองมาทำงานที่บ้าน | สุภาพ ชอบเปรียบเทียบสเปก คิดว่าเครื่องแรงพอแล้ว | สเปกผ่าน แต่ร้านเดิมปิด TPM/Secure Boot ไว้ |
| **ครูวิไล** | ครูคอมพิวเตอร์ ดูแลห้องปฏิบัติการของโรงเรียน | ละเอียด ถามเหตุผลทุกขั้น อยากเอาไปสอนต่อ | เครื่องแล็บรุ่นเก่าที่ลง Windows 10 แบบ Legacy ไว้ จะอัปเป็น 11 ต้องแก้หลายจุด |

ทุกคนมี 4 สีหน้า: `neutral` ปกติ · `worried` กังวล · `happy` พอใจ · `angry` ไม่พอใจ
(สีหน้าเปลี่ยนตามแถบความพอใจ: ช่างทำพลาดหรือใช้คำใบ้มาก ลูกค้าจะกังวลหรือไม่พอใจ)

## 4. รายละเอียด 5 เคส

### เคส 1 · ป้าสมศรี · "เสียบแล้วก็เข้าวินโดวส์เดิม" ★☆☆☆☆

- **บทพูด:** "ป้าดูคลิปแล้วทำตามนะ เสียบแฟลชไดรฟ์แล้วเปิดเครื่อง แต่มันก็ขึ้นหน้าจอ Windows อันเดิมทุกที ป้าทำผิดตรงไหนคะ"
- **ปัญหา:** `usb-not-first` (หนังสือ น.48–51) · **LO3**
- **ซ่อม:** เข้า BIOS (F2) → Boot → Boot Device Priority → USB เป็นอันดับแรก → F10 → OK
- **เดาสาเหตุ:** (ก) แฟลชไดรฟ์เสีย (ข) **เครื่องตั้งให้บูตจากฮาร์ดดิสก์ก่อน USB** ✓ (ค) RAM ไม่พอ (ง) ต้องติดตั้งไดรเวอร์ USB ก่อน
- **ลูกค้าถาม:** "ทำไมเสียบแล้วมันไม่ไปเองล่ะคะ" → ✓ "เครื่องจะเลือกบูตตามลำดับที่ตั้งไว้ใน BIOS ต้องเลื่อน USB ขึ้นก่อนและบันทึกด้วย F10"
- **กับดัก:** ออกจาก BIOS ด้วย Esc (ไม่บันทึก) → เครื่องยังเข้า Windows เดิม เสียคะแนนความแม่นยำ แต่ลองใหม่ได้

### เคส 2 · น้องบีม · "USB ไม่ขึ้นในเมนูบูต" ★★☆☆☆

- **บทพูด:** "ผมทำ USB เองครับพี่ ทำตามคลิปเป๊ะเลย แต่กด Boot Menu แล้วไม่มี USB ให้เลือก สงสัยแฟลชไดรฟ์ปลอม"
- **ปัญหา:** `usb-wrong-scheme` (หนังสือ น.45–48) · **LO2**
- **ซ่อม:** เปิด Rufus → Partition scheme **GPT** · Target system **UEFI** · File system NTFS → เลือก ISO Windows 11 → Start
- **เดาสาเหตุ:** (ก) แฟลชไดรฟ์ปลอม (ข) ISO เสีย (ค) **USB ทำแบบ MBR แต่เครื่องบูตแบบ UEFI** ✓ (ง) ต้องเปิด Secure Boot
- **ลูกค้าถาม:** "แล้วคลิปที่ผมดูผิดเหรอครับ" → ✓ "คลิปทำสำหรับเครื่องเก่าที่บูตแบบ BIOS เครื่องนี้บูตแบบ UEFI ต้องเลือก GPT ให้ตรงกับเครื่อง"
- **กับดัก:** เลือก MBR ซ้ำ หรือเลือก ISO ผิดไฟล์ (มีไฟล์ Windows 10 กับ Ubuntu ปนอยู่ในโฟลเดอร์ ให้เลือกให้ถูก)
- **มินิเกม:** จับคู่ MBR/GPT กับโหมดบูต (ก่อนเปิด Rufus)

### เคส 3 · ลุงชัย · "ขึ้นตัวแดง กดต่อไม่ได้" ★★☆☆☆

- **บทพูด:** "ลุงให้หลานลงวินโดวส์ใหม่ ไปติดตรงหน้าเลือกที่ลง มันขึ้นตัวแดงยาวเหยียด ข้อมูลในเครื่องลุงก๊อปใส่แฟลชไดรฟ์ไว้แล้ว เอาให้เร็วนะ เดี๋ยวลูกค้ามาถ่ายเอกสาร"
- **ปัญหา:** `uefi-mbr` (น.47, 55) + สุ่มเพิ่ม 0–1: `no-product-key` (น.54) · **LO4**
- **ซ่อม:** หน้าเลือกพาร์ทิชัน → ลบพาร์ทิชันเดิมทั้งหมด → เลือกพื้นที่ว่าง → Next (Setup สร้าง GPT ให้)
  ถ้าสุ่มได้ Product Key: ลุงลืมเอาคีย์มา → กด "I don't have a product key" ไม่ต้องหยุดงาน
- **เดาสาเหตุ:** (ก) ดิสก์เสีย (ข) **ดิสก์เป็น MBR แต่เครื่องบูตแบบ UEFI** ✓ (ค) USB ทำผิด (ง) RAM ไม่พอ
- **ลูกค้าถาม:** "ลบหมดเลยเหรอ ข้อมูลลุงจะหายไหม" → ✓ "ข้อมูลในดิสก์หาย แต่ลุงสำรองไว้แล้ว ต้องลบเพื่อให้ Setup ทำดิสก์เป็น GPT ที่เครื่อง UEFI ใช้ได้"
- **กับดัก:** ก่อนลบต้องเช็กว่าลูกค้าสำรองข้อมูลแล้ว (มีปุ่มถาม) ถ้าลบโดยไม่ถาม เสียคะแนนความรอบคอบ (จุดประสงค์ข้อ 4 ของรายวิชา)
- **มินิเกม:** พาร์ทิชัน (ลบ/สร้าง/ฟอร์แมต ให้ถูกลำดับ)

### เคส 4 · พี่ต้น · "เครื่องแรงแต่ลง 11 ไม่ผ่าน" ★★★☆☆

- **บทพูด:** "ผมซื้อคอมมือสองมาครับ i5 แรม 16 สเปกน่าจะเหลือๆ แต่ตัวติดตั้งบอกว่าเครื่องไม่ผ่านข้อกำหนด Windows 11 ผมโดนหลอกหรือเปล่า"
- **ปัญหา:** `tpm-disabled` + สุ่มเพิ่ม 0–1: `secure-boot-off` (เพิ่มสำหรับ Win 11) · **LO1, LO3**
- **ซ่อม:** BIOS → Advanced → Trusted Computing → เปิด TPM · (ถ้าสุ่มได้) Security → เปิด Secure Boot → F10
- **เดาสาเหตุ:** (ก) CPU เก่าเกินไป (ข) RAM ไม่พอ (ค) **ฟีเจอร์ความปลอดภัยใน BIOS ถูกปิดไว้** ✓ (ง) ต้องใช้ Windows 10 เท่านั้น
- **ลูกค้าถาม:** "แล้วทำไม Windows 10 ลงได้ แต่ 11 ไม่ได้" → ✓ "Windows 11 บังคับต้องมี TPM 2.0 และ Secure Boot ส่วน Windows 10 ไม่บังคับ เครื่องนี้มีครบแต่ร้านเดิมปิดไว้"
- **มินิเกม:** เครื่องนี้ผ่านข้อกำหนด Windows 11 ไหม (เทียบสเปกทีละข้อ)

### เคส 5 · ครูวิไล · "อัปเครื่องแล็บเป็น Windows 11" ★★★★☆ (เคสรวม)

- **บทพูด:** "เครื่องในห้องแล็บลง Windows 10 ไว้หลายปีแล้วค่ะ ครูอยากอัปเป็น 11 แต่ทำไม่ผ่านสักเครื่อง ช่วยทำให้ดูทีละขั้นได้ไหม ครูจะได้เอาไปสอนเด็กต่อ ข้อมูลในเครื่องไม่ต้องเก็บนะคะ"
- **ปัญหา:** `legacy-mbr` (BIOS ตั้งเป็น Legacy/CSM, Secure Boot ปิด, ดิสก์ MBR, USB ทำแบบ MBR) + สุ่มเพิ่ม 0–1: `tpm-disabled` หรือ `no-product-key` · **LO1–LO4**
- **ซ่อม (4–5 ขั้น):** BIOS ปิด CSM (เปลี่ยนเป็น UEFI) → เปิด Secure Boot (→ เปิด TPM) → F10 → ทำ USB ใหม่เป็น GPT → ในหน้าเลือกพาร์ทิชัน ลบพาร์ทิชันเดิมแล้วติดตั้ง
- **เดาสาเหตุ:** (ก) เครื่องเก่าเกินลง 11 ไม่ได้ (ข) **เครื่องตั้งค่าไว้สำหรับ Windows 10 แบบ Legacy ต้องเปลี่ยนเป็น UEFI** ✓ (ค) ไวรัส (ง) USB เสีย
- **ลูกค้าถาม (ครูถามหลายข้อ):** "ทำไมต้องทำ USB ใหม่ด้วยคะ" · "ทำไมต้องลบพาร์ทิชัน" → ทบทวน LO2 และ LO4
- **จุดเด่น:** ทุกอย่างที่เรียนมาจากเคส 1–4 กลับมาครบในเคสเดียว ถ้าผ่านเคสนี้ถือว่าเข้าใจทั้งเส้นทาง

## 7. ภาพที่ต้องขอจาก ChatGPT

ลูกค้าใหม่ 4 คน คนละ 4 สีหน้า + สีหน้าที่เหลือของป้าสมศรี 3 ภาพ = **19 ภาพ**
พรอมต์อยู่ใน [art-prompts.md](art-prompts.md) ข้อ 3 (จะเพิ่มให้ครบทุกคนหลังยืนยันรายชื่อ)

## 8. ต้องการจากผู้ใช้

- ยืนยัน/แก้ ลูกค้า 5 คน (ชื่อ นิสัย) และ 5 เคส
- ยืนยันคำตอบ "เดาสาเหตุ" และ "คำอธิบายให้ลูกค้า" (หรือให้ครูช่วยดู)
- ถ้าอยากให้ลูกค้าบางคนมาจากชีวิตจริงของนักเรียน (เช่น ครูในโรงเรียน) เปลี่ยนชื่อได้ตามสะดวก
