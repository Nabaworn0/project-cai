# แผน: เคส 4 (พี่ต้น) "เครื่องแรงแต่ลง 11 ไม่ผ่าน"

รอบ 1 ขั้นที่ 5 · เขียนเมื่อ 25 ต.ค. 2026 · **อนุมัติแล้ว 25 ต.ค. 2026 ตามข้อเสนอในข้อ 5 ทุกข้อ**
**งาน A–E เสร็จ 25 ต.ค. 2026** · เช็กลิสต์ลองบนมือถือ: [case4-phone-test.md](case4-phone-test.md) · เปิดเคสด้วย `?case=c04-security-chip` (`&seed=s1` ปิด TPM, `&seed=s3` ปิด TPM + Secure Boot)
อ้างอิง: [phase1-cases.md](phase1-cases.md) เคส 4 · [real-screens.md](real-screens.md) ข้อ 2 (เมนู TPM / Secure Boot ใน BIOS) และข้อ 3 (หน้า "can't run") · `src/content/data/cases/c04-security-chip.json` · วัตถุประสงค์ข้อ 2, 5, 8 ([behavioral-objectives.md](behavioral-objectives.md))

เป้าหมาย: นักเรียน**รู้ข้อกำหนดของ Windows 11** และแยกได้ว่าเครื่องไหน "ลงไม่ได้จริง" (ฮาร์ดแวร์ไม่พอ) กับ "ลงได้ แต่ปิดไว้ใน BIOS" แล้ว**เปิด TPM (และ Secure Boot) ใน BIOS** ได้เอง
ใช้ของที่มีแล้วเกือบทั้งหมด: เมนู Trusted Computing และ Secure Boot มีใน BIOS คลาสสิกแล้ว ภาพพี่ต้นมีแล้ว

## 2. ช่วงซ่อม

### หน้า "This PC can't run Windows 11" ฉบับเต็ม (แทนแบบสั้นของเคส 2)

บอกเหตุผล**ตามเครื่องจริง** ทีละข้อ ข้อความสืบค้นแล้ว 25 ต.ค. 2026 (ที่มาอยู่ใน [real-screens.md](real-screens.md) ข้อ 3):

**This PC can't run Windows 11**
This PC doesn't currently meet Windows 11 system requirements. ✅
(รายการเหตุผล)
For more information, visit: https://aka.ms/WindowsSysReq ✅

| เครื่องเป็นแบบนี้ | เหตุผลบนจอ | ความมั่นใจ |
|---|---|---|
| TPM ปิดอยู่ | The PC must support TPM 2.0 | ✅ แหล่งเดียว |
| Secure Boot ปิด หรือบูตแบบ Legacy (CSM) | The PC must support Secure Boot | ⚠️ ไม่เจอจาก Setup ใช้รูปแบบเดียวกับข้อ TPM |
| RAM น้อยกว่า 4 GB | There must be at least 4 GB of system memory | ✅ แหล่งเดียว |
| CPU ไม่อยู่ในรายชื่อที่รองรับ | The processor isn't supported for this version of Windows | ✅ แหล่งเดียว |

- เคส 4 ใช้แค่ 2 ข้อแรก ข้ออื่นเตรียมไว้ให้ระบบลูกค้าสุ่มและเคสหลังๆ (เช่น ลูกค้าที่ต้องแนะนำว่าเครื่องลงไม่ได้จริง)
- ดิสก์เล็กกว่า 64 GB: ไม่เจอข้อความจริงเลย จึงไม่ทำในขั้นนี้
- ถ้าสุ่มได้ทั้ง TPM และ Secure Boot: จอบอกทั้ง 2 ข้อ · เปิดแค่ TPM แล้วบูตใหม่ จอเหลือข้อ Secure Boot ข้อเดียว (เห็นความคืบหน้า)
- ปุ่ม Back บนจอเป็นของจริงแต่ไม่ช่วยอะไร · ใต้จอบอก "รีสตาร์ตเครื่องแล้วเข้า BIOS"

### ทางที่ถูก (หนังสือไม่มี เพิ่มสำหรับ Windows 11)

1. รีสตาร์ต → F2 → Advanced → **Trusted Computing → Security Device Support = Enabled**
2. (ถ้าสุ่มได้) Security → **Secure Boot → Secure Boot = Enabled**
3. F10 → Ok → บูต USB → กดปุ่มใดก็ได้ → Setup ขึ้นหน้าแรก = ซ่อมสำเร็จ

### ทางที่ผิด (กับดัก)

| ผู้เล่นทำ | ผล | นับพลาด |
|---|---|---|
| เห็นหน้า "can't run" ครั้งแรก | คืออาการที่ลูกค้าเจอ | 0 |
| **กลับมาเจอหน้า "can't run" ด้วยเหตุผลเดิม** (แก้ใน BIOS แล้วกด Esc ไม่บันทึก / เปิดผิดเมนู) | จอเหมือนเดิม พี่ต้นทัก | 1 (ดูข้อ 5) |
| เปิด TPM แล้วยังเหลือ Secure Boot (สุ่มได้ 2 ข้อ) | จอเหลือเหตุผลข้อเดียว | 0 (มีความคืบหน้า) |
| เปิด **CSM Support** (คิดว่าช่วย) | USB แบบ GPT บูตไม่ขึ้น เครื่องเข้า Windows 10 ตัวเดิม | 1 (เหมือนเคส 1) |

## 3. ตารางเทียบข้อกำหนด Windows 11 (มินิเกม "win11-check" แบบง่าย)

วัตถุประสงค์ข้อ 2 (บอกข้อกำหนดของ Windows 11) ยังไม่มีกิจกรรมในเกมเลย จึงเสนอทำแบบง่ายในขั้นนี้:

- อยู่ในช่วงใบงาน ใต้สเปกเครื่อง: ตาราง 6 แถว **ข้อกำหนด · ของเครื่องพี่ต้น · ผ่านไหม**
  CPU 64 บิต 2 คอร์ 1 GHz ขึ้นไป (รุ่นที่รองรับ) · RAM 4 GB ขึ้นไป · พื้นที่ 64 GB ขึ้นไป · UEFI + Secure Boot · TPM 2.0 · การ์ดจอ DirectX 12
- ผู้เล่นแตะ ✓ หรือ ? ทีละแถว: แถวที่ดูจากใบงานได้ (CPU, RAM, ดิสก์) ตอบ ✓ · แถวที่ใบงานบอกไม่ได้ (Secure Boot, TPM) ตอบ "?" = ต้องไปดูใน BIOS
- ตอบแล้วขึ้นเฉลยสั้นๆ ทีละแถว · **ไม่หักดาว** (เป็นการฝึก) แต่ตอบถูกได้เหรียญเพิ่มเล็กน้อย
- **ทำแล้ว 25 ต.ค. 2026 (งาน C):** ใช้ 5 แถว ตัดแถวการ์ดจอ DirectX 12 ออก เพราะเครื่องในเกมไม่มีข้อมูลการ์ดจอให้ดูบนใบงาน · ปุ่มคำตอบ 3 แบบ: ผ่าน / ต้องดูใน BIOS / ไม่ผ่าน · ถูก 1 แถวได้ 10 เหรียญ · ต้องตอบครบทุกแถวก่อนกดรับงาน
- ข้อกำหนดเป็นข้อมูลจริงของไมโครซอฟต์ (มีในบันทึกวัตถุประสงค์แล้ว) · เก็บเป็นข้อมูลในไฟล์ ไม่ฝังในโค้ด ใช้ซ้ำในเคส 5 และลูกค้าสุ่ม

## 5. ต้องการให้ตัดสินใจ

| เรื่อง | ผมเสนอ | ทางเลือก |
|---|---|---|
| **หน้า "can't run" ขึ้นตอนไหน** | ทันทีหลังกดปุ่มใดก็ได้ (ก่อนหน้าเลือกภาษา) แบบเดียวกับเคส 2 ตอนนี้ · ง่าย ไม่ต้องไล่หน้า Setup ทุกรอบที่รีสตาร์ต · สืบค้นแล้วไม่เจอแหล่งที่บอกว่าของจริงขึ้นหน้าไหน | รอรูปจากเครื่องแล็บแล้วค่อยย้ายให้ตรง |
| **นับพลาดตอนเจอหน้า "can't run"** | ครั้งแรกไม่นับ · เจออีกด้วยเหตุผลเดิมนับ 1 · เหตุผลลดลงไม่นับ | ไม่นับเลย (กับดัก Esc ไม่มีผล) |
| **ตารางเทียบข้อกำหนด** | ทำในขั้นนี้แบบง่าย ไม่หักดาว (วัตถุประสงค์ข้อ 2 ยังไม่มีกิจกรรมในเกม) | ทำทีหลังในขั้นมินิเกมตามแผนเดิม |
| **หน้า "can't run" ของเคส 2** | เปลี่ยนเป็นฉบับเต็ม (เหตุผล: The PC must support Secure Boot.) ใช้หน้าเดียวกัน | คงแบบสั้นไว้ |
| **โน้ตบุ๊กร้านในเคส 4** | ไม่มี (USB ของพี่ต้นถูกต้อง ถ้ามีจะชวนให้ติ๊ก "ข้ามการตรวจ TPM" ใน Rufus ซึ่งไม่ใช่วิธีที่ถูก) | มี และนับพลาดถ้าทำ USB แบบข้ามการตรวจ |

## 6. ไม่อยู่ในขั้นนี้

ลูกค้าที่เครื่องลงไม่ได้จริง (CPU เก่า / ไม่มีชิป TPM ต้องแนะนำลูกค้า) · BIOS ยี่ห้ออื่น (ASUS/Acer/HP) และกับดักรหัสผ่าน Secure Boot ของ Acer · เคส 5–6 · ระบบลูกค้าสุ่ม

## 7. ความเสี่ยงที่รู้อยู่

- **หน้า "can't run":** หัวจอ ข้อความหลัก และเหตุผลเรื่อง TPM / RAM / CPU เจอจากการสืบค้นแล้ว (บางข้อมีแหล่งเดียว) · ที่ยังไม่ยืนยัน: เหตุผลเรื่อง Secure Boot และหน้านี้ขึ้นตอนไหนของ Setup · ถ้าครูถ่ายรูปจากเครื่องแล็บได้ (ปิด TPM → บูต USB → ถ่ายรูป → เปิดคืน) จะยืนยันได้ทั้งหมด
- **ชื่อเมนู TPM ต่างกันตามยี่ห้อ** (TPM, PTT, fTPM, Security Device Support) · เกมใช้ชื่อแบบ AMI Aptio คำใบ้และบันทึกช่างจะบอกชื่ออื่นที่อาจเจอ
- **ตารางเทียบข้อกำหนดบนจอเล็ก** 3 คอลัมน์อาจแน่น: จะเรียงเป็นการ์ดทีละข้อบนจอแคบ
