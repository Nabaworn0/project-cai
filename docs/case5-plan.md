## 2. ช่วงซ่อม

### เครื่องของครูวิไลตอนรับมา
BIOS เปิด CSM (บูต Legacy) · Secure Boot ปิด · ดิสก์ MBR มี Windows 10 · แฟลชไดรฟ์ของครูทำแบบ MBR · สุ่มเพิ่ม 0–1: TPM ปิด หรือ ไม่มี Product Key

### ทางที่ถูก
1. เปิดเครื่อง → บูต USB ของครู → กดปุ่มใดก็ได้ → **"This PC can't run Windows 11"** (เหตุผล Secure Boot และ TPM ถ้าสุ่มได้) = อาการที่ครูเจอ
2. รีสตาร์ต → F2 → Boot → **CSM Support = Disabled** → Security → **Secure Boot = Enabled** → (Advanced → Trusted Computing → **TPM = Enabled**) → F10
3. บูตใหม่: USB แบบ MBR บูตแบบ UEFI ไม่ขึ้น และ Windows 10 เดิมก็บูตไม่ขึ้น (ลงไว้แบบ Legacy) → จอ **ไม่มีอุปกรณ์บูต** (ข้อ 5 เรื่องที่ 2)
4. **โน้ตบุ๊กร้าน** → Rufus → Partition scheme **GPT** · Target system **UEFI (non CSM)** → START → เสียบคืน
5. บูต USB → Setup: ภาษา → Install → (Product Key หรือ "I don't have a product key") → รุ่น → License → **ตัวแดง MBR** → **ถามครูเรื่องข้อมูล** → Delete Partition ทุกอัน → Next → ติดตั้ง
6. OOBE (ข้อ 3) จนถึงเดสก์ท็อป

### ทางที่ผิด (กับดัก)

| ผู้เล่นทำ | ผล | นับพลาด |
|---|---|---|
| หน้า "can't run" ครั้งแรก (บูต Legacy ด้วย USB ของครู) | อาการที่ครูเจอ | 0 (**ต้องแก้กฎเดิม** ที่นับบูต Legacy เป็นพลาดทุกครั้ง ข้อ 5) |
| เจอหน้า "can't run" อีกด้วยเหตุผลเดิม (กด Esc ไม่บันทึก / ลืมปิด CSM) | ครูทัก | 1 |
| ปิด CSM แล้วบูตใหม่ เจอ "ไม่มีอุปกรณ์บูต" ครั้งแรก | เห็นว่า USB เดิมใช้ไม่ได้แล้ว | 0 (ข้อ 5) · ครั้งต่อไป 1 |
| ทำ USB เป็น MBR อีก / ติ๊ก "ข้ามการตรวจ TPM" ใน Rufus | บูตไม่ขึ้น / นับพลาด | 1 (เหมือนเคส 2) |
| ลบพาร์ทิชันก่อนถามครู | ครูทัก "ยังไม่ได้ถามครูเลยนะคะ" | 1 (เหมือนเคส 3 · ข้อ 5) |
| ลบพาร์ทิชันของแฟลชไดรฟ์ | ตัวติดตั้งหาย ต้องทำ USB ใหม่ | 1 (เหมือนเคส 3) |
| เลือกรุ่นไม่ตรงใบงาน | ติดตั้งได้ แต่หักดาว | 1 (เหมือนเคส 3) |
| **ช่างพิมพ์อีเมล/รหัสผ่านแทนครู** หรือ **ขอรหัสผ่านครู** | ครูไม่สบายใจ บันทึกช่างเตือน | 1 (ตกลงแล้ว 25 ต.ค. · วัตถุประสงค์ข้อ 10) |
| เปิดตัวเลือกความเป็นส่วนตัวทั้งหมดโดยไม่ถามครู | ไม่หัก แค่บอกในบันทึกช่าง (ข้อ 5) | 0 |

## 3. หน้าตั้งค่าเริ่มต้น (OOBE) แบบ Windows 11 24H2

พื้นหน้าจอเต็ม สีฟ้าเข้มมีภาพประกอบด้านซ้าย การ์ดขาวมุมมนด้านขวา หัวข้อตัวใหญ่ ปุ่ม Yes / Next ล่างขวา (ทำตามภาพจริงที่ดูมา ไม่ใส่ที่มาในเกม เหมือนหน้า Setup)

| # | หน้า | ผู้เล่นทำ | ใครทำ |
|---|---|---|---|

| 2 | Is this the right keyboard layout or input method? | US → Yes | ช่าง |

| 12 | Hi · This might take a few minutes | รอ → **เดสก์ท็อป Windows 11** | — |

- **เดสก์ท็อป:** วอลเปเปอร์ Bloom (วาดด้วยโค้ด) · แถบงานไอคอนกลาง · ปุ่ม Start · นาฬิกา ไม่ต้องกดอะไรได้ในเคส 5 (เคส 6 จะใช้ต่อ)
- **ตัดออกเพื่อให้ไม่ยาวเกิน:** หน้า "Restore from your previous PC" · การยืนยันตัวตนด้วยโค้ดทางโทรศัพท์ · หน้าเลือกพื้นหลัง/ธีม
- ⚠️ ข้อความและลำดับบางหน้าเปลี่ยนตามรุ่นอัปเดต จะดูเทียบภาพจริงทีละหน้าในงาน B แล้วติด ⚠️ ข้อที่ไม่เจอ (เหมือนหน้า Setup)
- เรื่องเน็ตกับบัญชี: ของจริง 24H2 บังคับต่อเน็ตและลงชื่อบัญชี Microsoft (ทางเลี่ยงด้วยคำสั่งไม่สอนในเกม)

## 5. ต้องการให้ตัดสินใจ

| เรื่อง | ผมเสนอ | ทางเลือก |
|---|---|---|
| **"can't run" ครั้งแรกบนเครื่อง Legacy ของลูกค้า** | ไม่นับพลาด (เป็นอาการที่ครูเจอ) · นับเฉพาะครั้งต่อไปที่เหตุผลเดิม หรือเมื่อผู้เล่นเปิด CSM เอง | นับทุกครั้งเหมือนเดิม |
| **ปิด CSM แล้วเครื่องบูตอะไร** | "ไม่มีอุปกรณ์บูต" (ตรงของจริง: Windows 10 ที่ลงแบบ Legacy บูต UEFI ไม่ได้ และ USB แบบ MBR ก็ไม่ขึ้น) · ครั้งแรกไม่นับ เพราะเป็นทางที่ต้องผ่าน | เข้า Windows 10 เดิมเหมือนเคสอื่น |
| **ต้องถามครูเรื่องข้อมูลก่อนลบไหม** (ครูบอกแล้วตอนเข้าร้านว่าไม่ต้องเก็บ) | ไม่ต้องถามซ้ำ (ครูพูดชัดแล้ว) ลบได้เลยไม่หัก · บันทึกช่างชมถ้าฟังลูกค้า | ต้องกดถามทุกครั้งเหมือนเคส 3 (นิสัยรอบคอบ) |
| **รุ่น Windows บนใบงาน** | **Pro** (เครื่องโรงเรียน ได้ฝึกหน้า "personal / work or school" ด้วย) | Home เหมือนเคสอื่น · Education (ของจริงในโรงเรียน แต่ต้องมีคีย์องค์กร) |
| **คีย์บอร์ดภาษาที่สอง** | ต้อง **Add Thai** (ถ้า Skip ไม่หัก แต่ครูทัก "เด็กๆ พิมพ์ไทยไม่ได้นะคะ" และบันทึกช่างบอก) | Skip ได้ ไม่มีผล |
| **หน้าความเป็นส่วนตัว** | ไม่หักคะแนน · มีปุ่ม "ถามครู" ได้เหรียญเพิ่มเล็กน้อย · บันทึกช่างอธิบายแต่ละข้อสั้นๆ | ไม่มีปุ่มถาม แค่กด Accept |
| **เคส 6 เริ่มที่ไหน** (ตกลงแล้วว่าเริ่มที่เดสก์ท็อป) | ใช้เดสก์ท็อปที่ทำในงาน C · เคส 6 ไม่ต้องไล่ OOBE ซ้ำ | — |

## 6. ไม่อยู่ในขั้นนี้

บัญชี Local (ทางเลี่ยงด้วยคำสั่ง) · Windows Hello หน้า/นิ้ว · ลงหลายเครื่องในแล็บพร้อมกัน (ทำทีละเครื่องพอ) · ปุ่มบนเดสก์ท็อปที่ใช้ได้ (เคส 6) · ลูกค้าซื้อคีย์แท้ (งาน G ในระบบลูกค้าสุ่ม) · BIOS ยี่ห้ออื่น

## 7. ความเสี่ยงที่รู้อยู่

- **เคสยาว:** ซ่อม 5 ขั้น + OOBE 12 หน้า อาจเกิน 10 นาทีสำหรับมือใหม่ · ถ้ายาวเกิน จะรวมหน้า 1–3 (ประเทศ/คีย์บอร์ด) ให้กดต่อเนื่องเร็ว และตัดหน้า 11 เหลือ Skip ทีเดียว
- **หน้า OOBE เปลี่ยนบ่อยตามอัปเดต:** ทำตามรุ่น 24H2 ที่ดูภาพมา ข้อที่ไม่แน่ใจติด ⚠️ ใน real-screens.md · ถ้าครูถ่ายรูปจากเครื่องแล็บระหว่างลงจริงได้ จะแก้ให้ตรง
- **กฎ "can't run" ครั้งแรก** ที่แก้ในงาน A ต้องไม่ทำให้กับดัก CSM ของเคส 1–2 และ 4 หายไป: เทสต์เดิมทั้งหมดต้องผ่าน
- **โลโก้/ภาพ Bloom:** วาดเองด้วยโค้ดแบบประมาณ ไม่ใช้ไฟล์ภาพของไมโครซอฟต์ (เหมือนโลโก้ในหน้า Setup)
