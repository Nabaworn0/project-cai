# แผนแก้ข้อ 1: แยกหน้าเรียนกับหน้าร้าน + ฉากคุยกับพี่ช่าง · อนุมัติ 28 ต.ค. 2026

ผู้ใช้ขอ (28 ต.ค.): หน้าเรียนเป็นคนละหน้ากับร้าน เรียนเสร็จแล้วค่อยโหลดไปหน้าร้านที่ผู้เล่นเป็นเด็กฝึกงาน และมีคัตซีนคุยกับพี่ช่างว่าจะทำอะไรบ้าง
ผู้ใช้เลือกแล้ว: (1) ร้านเปิดเมื่อเรียนครบ (2) คัตซีนครั้งแรก + ก่อนทุกเคส (3) พี่ช่างเป็นตัวละครพิกเซลในร้าน

## ภาพรวม

```
เปิดเกม → หน้าเรียน (ไม่มีร้านด้านหลัง)
            ฟอร์มชื่อ → ทดสอบก่อนเรียน → บทเรียน 1–2 → เรียงขั้นตอน
            → ปุ่ม "ไปฝึกงานที่ร้าน" (เปิดเมื่อเรียนครบ)
                 ↓ หน้าโหลด "กำลังไปที่ร้าน…"
          หน้าร้าน: คัตซีนต้อนรับ (ครั้งแรก) → คัตซีนสั้นก่อนเคส → ลูกค้าเดินเข้าร้าน → เคส
                 ↓ "☰ เมนู" / จบเคส
          กลับหน้าเรียน → ทดสอบหลังเรียน → สะท้อนผล → สรุปผล
```

## รายละเอียด

| เรื่อง | ทำอย่างไร |
|---|---|
| หน้าเรียน | หน้าของตัวเอง พื้นหลังลายพิกเซล (กระดานไม้ก๊อก/สมุดจด สีเดียวกับเกม) การ์ดขั้นตอนแบบเดิม · ขั้น "ฝึกงานที่ร้าน" เป็นปุ่มใหญ่ "ไปฝึกงานที่ร้าน" พร้อมรายการเคสและดาว |
| เงื่อนไขเปิดร้าน | ต้องทำทดสอบก่อนเรียน บทเรียน 2 เรื่อง และเรียงขั้นตอนครบ (ขั้นที่ยังไม่ได้สร้างไม่ล็อก ตอนนี้จึงยังเข้าร้านได้เลย) · ?unlock=all ข้ามได้ |
| โหลดร้านทีหลัง | ไม่โหลดฉากร้าน (Phaser) จนกว่าจะกดไปร้าน มือถือเปิดหน้าแรกเร็วขึ้น · หน้าโหลดแสดงระหว่างรอ · กลับหน้าเรียนแล้วไปร้านอีกครั้งไม่ต้องโหลดใหม่ |
| พี่ช่าง | ตัวละครพิกเซลใหม่ขนาดเท่าตัวเดิม **ภาพจาก ChatGPT ตามพรอมต์ใน art-prompts.md ข้อ 2.1 แล้ว `npm run pixelize`** (ผู้ใช้ทัก 28 ต.ค.: ภาพต้องเจนด้วย ChatGPT) · ผู้ใหญ่กว่า ผ้ากันเปื้อนสีไม้ ไขควงในกระเป๋า 3 สีหน้า: ปกติ ยิ้ม คิด · ระหว่างรอภาพ ใช้ตัวช่างเดิมเปลี่ยนสีเสื้อเป็นตัวแทนชั่วคราว · ยืนข้างเด็กฝึกงานหลังเคาน์เตอร์ · ตัวเดิมคือเด็กฝึกงาน (ผู้เล่น) |
| พี่ช่างนั่งทำงาน | (ผู้ใช้เลือก 28 ต.ค. แบบ ข) พี่ช่างไม่ได้ยืนที่เคาน์เตอร์ตลอด นั่งซ่อมคอมในห้องซ่อมหลังร้าน เห็นผ่าน**หน้าต่างกระจกบนผนัง** (แทนหน้าต่างวิวเดิม ภาพจาก ChatGPT art-prompts.md 4.2) · เมื่อต้องคุย: หน้าต่างเปลี่ยนเป็นเก้าอี้ว่าง พี่ช่างเดินหลังเคาน์เตอร์มายืนข้างเด็กฝึกงาน คุยจบเดินกลับ · เดินมาเมื่อ: คัตซีนต้อนรับ คัตซีนก่อนเคส ผู้เล่นกดคำใบ้/พลาด (ข้อ 3 ใบงาน) และจบเคส · ระหว่างรอภาพ ใช้หน้าต่างเดิมและให้พี่ช่างเดินเข้าจากขอบจอ |
| คัตซีน | กล่องคำพูดด้านล่าง ชื่อคนพูด ตัวที่พูดขยับเล็กน้อย แตะ/Enter ไปประโยคต่อไป ปุ่ม "ข้าม" · บทอยู่ในไฟล์เนื้อหา (`cutscenes.json`) ตรวจด้วย schema เหมือนเคส |
| คัตซีนต้อนรับ | ครั้งแรกที่เข้าร้าน 6–10 ประโยค: ต้อนรับ ร้านทำอะไร ขั้นทำงาน (ฟังลูกค้า → รับงาน → เดาสาเหตุ → ซ่อม → อธิบายลูกค้า) พี่ช่างคอยช่วย ดาวคิดอย่างไร · ดูซ้ำได้จากหน้าเรียน |
| คัตซีนก่อนเคส | 2–4 ประโยคก่อนลูกค้าเดินเข้า: เคสนี้ได้ฝึกเรื่องอะไร (ไม่บอกเฉลย) · ข้ามได้ · เป็นจุดเดียวกับที่ใบงานของพี่ช่าง (ข้อ 3) จะมาโชว์รายการขั้นตอนในภายหลัง |
| ครูเปิด/ปิดคลิป | **เลื่อนไปทำทีหลัง (ผู้ใช้ 28 ต.ค.: เป็นระบบฝั่งครู)** · แนวคิดเดิม: เกมไม่มีเซิร์ฟเวอร์ จึงใช้**ลิงก์ของห้อง**: หน้า "สำหรับครู" (`?view=teacher`) มี 2 ลิงก์พร้อม QR · "ดูคลิปในเกม" (ค่าเริ่มต้น) และ "ครูสอนเอง ข้ามคลิป" (`?lessons=teacher`) · นักเรียนเปิดลิงก์แล้วเครื่องจำค่าไว้ · ปิดคลิปแล้ว: บทเรียน 1–2 ไม่ล็อกร้าน การ์ดขึ้น "ครูสอนในห้องแล้ว · ดูทบทวนได้" (ยังเปิดดูได้ เพื่อทบทวนเอง) · หน้าสรุปผลบอกว่าห้องนี้ครูสอนเอง · เปิด/ปิดได้เฉพาะคลิป แบบทดสอบและเรียงขั้นตอนยังต้องทำ |
| บท | ChatGPT ร่างบทตามพรอมต์ที่ผมให้ ผมตรวจกับเคสจริงก่อนใส่ · ระหว่างรอ ผมใส่บทชั่วคราวสั้นๆ |

## ผลงาน A (28 ต.ค. 2026)

- `path.ts`: ร้าน (การ์ดฝึกงานและเคส 1) เปิดเมื่อทำทดสอบก่อนเรียน บทเรียน 2 เรื่อง และเรียงขั้นตอนครบ ขั้นที่ยังไม่ได้สร้างไม่นับ · บทเรียนและเรียงขั้นตอนเปิดหลังทดสอบก่อนเรียนเหมือนเดิม · แบบทดสอบหลังเรียนต้องเรียนครบ **และ**เล่นครบทุกเคส (กันกรณีเล่นเคสผ่านลิงก์ `?case=` แล้วข้ามบทเรียน)
