# ร้านซ่อมคอม

เกมสื่อการสอนเรื่องการติดตั้ง Windows 11 สำหรับนักเรียน ปวช. ภาพพิกเซลอาร์ต 16-bit เล่นบนเบราว์เซอร์ได้ทั้งมือถือและคอม (PWA เล่นออฟไลน์ได้)
สรุปการออกแบบ: [shop-game-brief.md](shop-game-brief.md) · ต้นแบบเดิม (vanilla JS): [shop-case1.html](shop-case1.html)

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` | เปิดเกมโหมดพัฒนา http://localhost:5173 |
| `npm run validate` | ตรวจไฟล์เนื้อหาทั้งหมด (สุ่มเครื่อง 200 แบบต่อเคส ต้องแก้ได้ทุกแบบ) |
| `npm run test:unit` | ทดสอบตัวตรวจเนื้อหา, สไปรต์พิกเซล, และสคริปต์ pixelize |
| `npm run pixelize -- art-source/tech-*.png` | จัดภาพจาก ChatGPT ให้เป็นพิกเซลจริงในชุดสี 32 สี → `src/assets/sprites/` (ดู docs/style-guide.md ข้อ 7) |
| `npm test` | Playwright: บิลด์จริงแล้วเล่นบนจอคอม มือถือ มือถือเล็ก มือถือแนวนอน + ทดสอบออฟไลน์ |
| `npm run check` | รันทุกอย่างข้างบนต่อกัน (ใช้ก่อนส่งงาน) |
| `npm run build` | สร้างไฟล์สำหรับขึ้นโฮสต์ใน `dist/` (โฟลเดอร์ย่อย: `BASE_PATH=/ชื่อ-repo/ npm run build`) |

ครั้งแรกต้องติดตั้ง: `npm install` และ `npx playwright install chromium`

## โครงสร้าง

```
src/
  core/         ตรรกะเกมล้วน ไม่ผูกกับหน้าจอ (ทดสอบได้ด้วย Node)
    machine.ts    เครื่องของลูกค้า (โหมดบูต ดิสก์ TPM ฯลฯ)
    win11.ts      อะไรที่ทำให้ลง Windows 11 ไม่ได้ (blocker)
    actions.ts    การซ่อมทุกแบบ (ใช้กับ BIOS, Setup, diskpart, อะไหล่)
    cases.ts      สุ่มเครื่องจากเคส + หาวิธีซ่อม (solver)
    rng.ts        สุ่มแบบกำหนด seed ได้ (เคสรายวัน)
    bus.ts        ส่งเหตุการณ์ระหว่างฉาก Phaser กับหน้าจอ HTML
  content/
    schema.ts     รูปแบบไฟล์เนื้อหา (zod)
    validate.ts   ตัวตรวจเนื้อหา
    data/         เนื้อหาทั้งหมดเป็น JSON (แก้ได้โดยไม่ต้องแตะโค้ด)
  game/         Phaser 4 (pixelArt): ฉากร้าน ตัวละคร
    display.ts    ขนาดผืนพิกเซลและการขยายเป็นจำนวนเต็มเท่า
    art/          ชุดสี 32 สี, สไปรต์ที่วาดเป็นตัวอักษร (ภาพชั่วคราว)
  ui/           Preact: HUD และหน้าจอจำลองที่ซ้อนบนฉาก
tools/          สคริปต์ตรวจเนื้อหา, pixelize + unit test
tests/          Playwright
docs/           คู่มือสไตล์ภาพ, พรอมต์สร้างภาพ, palette.hex
art-source/     ภาพต้นฉบับจาก ChatGPT (ไม่เข้าไปในเกม)
```

## ไฟล์เนื้อหา (`src/content/data`)

| ไฟล์ | เนื้อหา |
|---|---|
| `objectives.json` | วัตถุประสงค์การเรียนรู้ LO1–LO6 (ยังเป็นร่าง) |
| `problems.json` | ปัญหาที่ซ่อนในเครื่อง: เปลี่ยนค่าเครื่องอะไร (`patch`), ต้องมีเงื่อนไขอะไร (`requires`), แก้ด้วยการกระทำไหน (`fixes`), อาการ คำอธิบาย คำใบ้ 2 ขั้น |
| `cases/*.json` | เคสลูกค้า: บทพูด ต้องเก็บข้อมูลไหม (`keepData`), ยี่ห้อที่สุ่ม, สเปกที่สุ่ม, ปัญหาตายตัว + ปัญหาสุ่มเพิ่ม |
| `brands/*.json` | หน้า BIOS ตามยี่ห้อ: ปุ่มเข้า เมนู ตำแหน่งตัวเลือก ข้อแปลกของยี่ห้อ (`verified: false` = ยังไม่เทียบเครื่องจริง) |
| `quizzes/*.json` | แบบทดสอบก่อน/กลาง/หลังเรียน ฟอร์ม A/B ข้อคู่ขนานใช้ `pair` เดียวกัน |
| `cards.json` | การ์ดสะสม ผูกกับปัญหาที่เพิ่งแก้ |

ตัวตรวจจะไม่ยอมให้ผ่านถ้า: ปัญหาสองอย่างขัดกัน, ปัญหาถูกปัญหาอื่นบังจนไม่แสดงอาการ, ลูกค้าห้ามลบข้อมูลแต่ทางแก้มีแต่แบบลบ,
เครื่องพังตั้งแต่ก่อนใส่ปัญหา, BIOS ยี่ห้อนั้นไม่มีเมนูที่ต้องใช้แก้, หรือข้อสอบ A/B ไม่คู่ขนานกัน
